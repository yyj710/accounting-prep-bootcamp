# 00 会计知识竞赛 · 总复习（知识点与易错点）

> 覆盖全部 13 个模块、1385 题。按「模块要点 → 易错对比 → 口诀 → 数字速查」组织，供考前冲刺速查。

## 一、模块知识要点

### 01 会计法
- 单位负责人是会计工作「第一责任人」；国务院财政部门主管全国会计工作。
- 记账本位币可选外币，但**编报报告必折算人民币**。
- 会计核算针对已发生业务（决议未执行不核算）。
- 会计档案安全保护为 2024 版新增要求。
- 法律责任分档（一般 / 严重 / 犯罪），隐匿、销毁是重罪。
- 岗位轮换、交接监交、回避制度。

### 02 企业会计准则
- 8 项信息质量要求；资产减值（可转回 / 不可转回）。
- 收入五步法与履约进度；金融资产三分类（摊余成本 / 其他综合收益 / 当期损益）。
- 投资性房地产两模式；折旧摊销起算规则。
- 政府补助：补以后→递延收益，补已发生→当期损益。

### 03 政府会计准则
- **双基础**（财务会计权责发生制 + 预算会计收付实现制）、**双报告**（决算报告 + 财务报告）。
- 平行记账（仅纳入部门预算管理的现金收支）。
- 财务会计 5 要素 / 预算会计 3 要素；政府特有资产（公共基础设施、储备物资、文物资源）。
- 政府用「净资产、投资损益」，企业用「所有者权益、投资收益」。
- 决算报告供人大，财务报告供公众。

### 04 内部控制规范
- 五要素：内部环境 / 风险评估 / 控制活动 / 信息与沟通 / 内部监督。
- 五原则：全面性 / 重要性 / 制衡性 / 适应性 / 成本效益。
- 风险应对四策略：规避 / 降低 / 分担 / 承受。
- 不相容岗位分离、出纳与印章分管。
- 内控评价报告真实性由董事会负责。

### 05 会计信息化
- 会计软件具备采集、生成、存储转换输出分析利用功能。
- 安全要求：数据加密、身份认证权限、漏洞修复、定期备份。
- 云端数据归用户（单位）所有；境外服务器须境内备份。
- 电子凭证打印件报销须同时保存原文件；合规电子资料可仅以电子形式提供。
- 第一责任人 = 单位负责人；办法由国务院财政部门会同制定。

### 06 管理会计
- 服务**内部管理层**，核心功能 = 提供决策支持信息，核心领域 = 成本控制与优化。
- 含财务与非财务信息；涉及预算编制与战略决策支持。
- 指引体系 = 基本指引 + 应用指引 + 案例库。

### 07 税法相关
- 增值税视同销售两套规则（自产/委托 vs 外购）。
- 计税基础的暂时性差异与递延所得税。
- 个税所得项目分类与专项附加扣除。
- 增值税税率归类与不得开专票情形、优惠减免判定。

### 08 预算法
- 全部收支纳入预算；实行国库集中收付；各级政府不得下达收入指标。
- 预算批准主体 = 人民代表大会；公开及批复有明确期限。
- 派出机关不作为一级预算；超收收入只能冲减赤字 / 补预算稳定调节基金。

### 09 会计档案管理办法
- 归档范围四类：会计凭证、会计账簿、财务会计报告、其他会计资料。
- 按年度、类别分类编号；移交保持原封装；纸质 / 电子两种形式。
- 未结清债权债务凭证不得销毁，保管至未了事项完结。

### 10 会计基础工作规范
- 凭证须真实、完整、及时；原始凭证只认「报销联」。
- 财报由单位负责人、主管会计工作负责人、会计机构负责人**签名并盖章**。
- 交接未办清不得调动离职；接替人继续用原账簿。

### 11 会计职业道德
- 三条核心：①坚持诚信守法奉公；②坚持准则守责敬业；③坚持学习守正创新。
- 制定依据是《会计法》《会计基础工作规范》（非《民法典》）。
- 保密非绝对，法律规定或单位负责人同意可提供。

### 12 数据资产管理
- 五项基本原则；治理模式「市场主导、政府引导、多方共建」。
- 收益分配按「谁投入、谁贡献、谁受益」。
- 配置方式 = 自主采集、生产加工、购置。
- 严抓「从严配置、开放共享、审慎处置、严格收益」。

### 13 综合法规
- 会计政策 vs 会计估计；合并范围仅考虑实质性权利。
- 营业外支出非费用；其他权益工具投资公允变动计入其他综合收益。
- 应付账款按贷方余额填列、长期借款需分析填列。
- 划转撤并 = 划转、合并、撤销、解散（不含「转型」）。

## 二、易错点 / 陷阱对比表（跨模块）

### 2.1 减值能否转回
| 资产 | 减值能否转回 |
|------|------------|
| 存货、应收款项、债权投资、合同资产 | ✅ 可转回 |
| 固定资产、无形资产、投资性房地产（成本模式）、长期股权投资、商誉 | ❌ 不可转回 |
| 持有待售 | 划分**前**不可、划分**后**可 |

> 口诀：**流动可转回，长期不能回**

### 2.2 盘盈盘亏去向
| 事项 | 处理 |
|------|------|
| 存货盘盈 | 冲管理费用 |
| 存货盘亏（正常/一般） | 管理费用 |
| 存货盘亏（自然灾害） | 营业外支出 |
| 现金溢余 | 营业外收入 |
| 固定资产盘盈 | 以前年度损益调整 |
| 固定资产盘亏 | 营业外支出（先待处理财产损溢） |

### 2.3 会计政策 vs 会计估计
| 类型 | 判断 | 变更处理 |
|------|------|----------|
| 会计政策 | 换方法（计价方法、计量模式、费用化↔资本化） | 追溯调整 |
| 会计估计 | 换数字（折旧方法、年限、残值、坏账比例、估值） | 未来适用 |
| 难以区分 | — | 按**估计** |

### 2.4 收入 / 利得 / 费用 / 损失
| 项目 | 性质 |
|------|------|
| 收入 | 日常 + 总流入 |
| 利得 | 非日常 + 净流入（接受捐赠、政府补助） |
| 费用 | 日常（营业外支出**不属于**费用） |
| 损失 | 非日常 |

### 2.5 折旧 / 摊销起算
| 资产 | 起算规则 |
|------|----------|
| 企业固定资产 | 当月增不提、**次月**起提、当月减仍提 |
| 无形资产 | **当月**起摊、处置当月不摊 |
| 政府资产 / 公共基础设施 | **当月增当月折** |

### 2.6 出纳不得兼管（与人数无关）
- 不得兼管：稽核、会计档案保管、收入/费用/债权债务账目登记。
- **可以**登记现金、银行存款日记账（本职）。
- 现金/银行日记账**必须订本式**。

### 2.7 任职条件「或」vs「且」
| 岗位 | 条件 |
|------|------|
| 会计机构负责人 | 会计师以上资格 **或** 3 年以上经历 |
| 代理记账负责人 | 会计师以上资格或 3 年，**且**专职从业 |

### 2.8 增值税视同销售（自产/委托 vs 外购）
| 用途 | 自产/委托加工 | 外购 |
|------|------------|------|
| 对外投资/分配/赠送 | 视同 | 视同 |
| 集体福利/个人消费 | 视同 | **不视同（进项转出）** |

### 2.9 税金扣除去向
| 去向 | 税种 |
|------|------|
| 进成本分期扣 | 契税、耕地占用税、车购税、进口关税 |
| 当期扣（税金及附加） | 消费税、印花税、房产税、城建税 |
| 不得扣 | 企业所得税本身、可抵扣增值税 |

### 2.10 个税所得项目（看雇佣关系）
| 项目 | 典型 |
|------|------|
| 工资薪金 | 本单位奖金、全年一次性奖金 |
| 劳务报酬 | 无雇佣关系的咨询/讲学 |
| 特许权使用费 | 专利/商标/著作权/非专利技术使用权 |
| 经营所得 | 个体户、个人独资/合伙 |

### 2.11 政府采购方式
| 方式 | 特点 |
|------|------|
| 公开招标 | **主要方式**；招标公告邀请**非特定**供应商 |
| 邀请招标 | 投标邀请书邀请**特定**供应商 |
| 单一来源 | 添购≤原合同 10% |

### 2.12 数据资产 / 职业道德要点
- 公共治理/公益事业→**无偿**；产业发展/行业→**有偿**。
- 数据资产**不得用于担保**；研究阶段**费用化**、开发阶段符合条件才**资本化**。
- 职业道德：「懒惰拖」违背勤勉尽责；「理万金分文不沾」体现守法奉公。

## 三、记忆口诀汇总

**减值与盘盈**
- 流动可转回，长期不能回
- 现金溢余营业外、存货盘盈冲管理、固资盘盈调前期
- 划分前不减回、划分后能回

**会计政策 / 估计 / 研发**
- 政策变更追溯调整、估计变更未来适用
- 研究费用化、开发可资本化、分不清全费用化
- 佣金才资本化，其他全费用化

**折旧 / 投资性房地产**
- 持有待售不折旧，租入按孰短
- 成本能转公允、公允不能转成本
- 加速折旧才谨慎

**收入 / 处置去向**
- 存货走收入、固资无形走处置损益、其他权益工具走留存收益、投房走其他业务
- 累积提供服务时确认、非累积实际缺勤才确认
- 先扣利息再还本，本金才会往下减

**内控 / 政府**
- 规避=放弃停止、降低=控制减少、分担=转移、承受=不采取
- 出纳管钱不管账，档案核算债务都不沾
- 结转按原用途、结余可重安排；政府资产当月增当月折；纳入预算才平行

**税法**
- 商业折扣先打折，现金折扣后入账
- H股持有满一年，股息免税不用钱
- 花茶香、海内陆（减半）；蔬菜谷物油料、远洋捕捞——免征
- 契耕购进成本，其余税走当期
- 独托差误（独生子女、托儿补助、差旅津贴、误餐补助）不征税
- 资源动因→作业，作业动因→产品

**综合法规**
- 起征点全额征，免征额超额征
- 法＞法规＞规章＞文件（法律>行政法规>部门规章>规范性文件）
- 购券收息、转让债券是投资；发券付息是筹资

## 四、高频数字 / 期限 / 比例速查

### 4.1 会计法罚款（2024 版）
| 情形 | 个人 | 单位 |
|------|------|------|
| 一般违法 | ≤5 万 | ≤20 万 |
| 严重违法 | 5 万–50 万 | 20 万–100 万 |
| 隐匿/销毁（严重） | 50 万–200 万 | — |
| 编制虚假财报 | 轻 10 万–50 万 / 重 50 万–200 万 | — |
| 授意、指使、强令 | 轻 20 万–100 万 / 重 100 万–500 万 | — |

- 任用会计人员不符规定（非情节严重）：对单位并处**20 万元以下**。
- 禁业：未犯罪严重 5 年；犯罪**终身**。

### 4.2 会计档案保管期限
| 档案 | 期限 |
|------|------|
| 年度财务会计报告 | 永久 |
| 原始凭证、记账凭证、总账/明细账 | 30 年 |
| 固定资产卡片 | 报废清理后 5 年 |
| 定期保管最低档 | 10 年 |

### 4.3 继续教育
- 每年参加，学分≥**90 学分**；专业科目不少于总学分**三分之二**。
- 学分**当年度有效、不得结转**（全国范围内有效）。
- 独立出版会计类书籍每本 90 学分；会议每天 10 学分；独立发表 CN 论文每篇 30 学分；合作发表第一作者 15 学分。

### 4.4 税 / 预算相关
- 先进制造业加计抵减 **5%**；房地产预收款预征率 **3%**。
- 个税比例税率 20%；公益捐赠一般限额 30%。
- 首套房贷利息 1000 元/月、最长 240 月、仅一次；住房租金省会 1500 元/月。
- 林木类生产性生物资产 10 年；研发加计计税基础=账面 200%。
- H 股连续持有满 12 个月股息免税。

### 4.5 政府采购 / 时限
- 招标文件发出至投标截止 ≥**20 日**。
- 质疑答复 = 收到书面质疑后 **7 个工作日**。
- 投诉 = 答复期满后 **15 个工作日**。
- 履约保证金 ≤ 合同金额 **10%**；补充合同 ≤ 原合同 **10%**。
- 回避：参加采购活动前 **3 年**内有劳动关系应回避。
- 废标：实质响应供应商不足 **3 家**。

### 4.6 预算法 / 公开时限
- 部门预决算公开：批复后 **20 日**内；财政批复预算 **20 日**内、部门再 **15 日**内批复单位。
- 财政部每年 **6 月 15 日**前部署下年预算草案。

### 4.7 其他
- 房产税减除比例 10%~30%（减规定比例，非减折旧）。
- 减资弥补亏损：法定+任意公积金累计达注册资本 **50%** 前不得分配。
- 资本公积金弥补亏损**无 25% 限制**。
- 无住所个人境内工作不足 24 小时按**半天**计。
- 借款费用资本化：非正常中断连续**超 3 个月**暂停资本化；资本化资产门槛 **1 年以上**。
- 信息化备份频率不低于**每月一次**。
- 递延所得税率 25%。

## 六、备考策略提醒

1. **对比表优先记**：减值可/不可转回、盘盈盘亏去向、政策 vs 估计、折旧起算、视同销售两套规则，是高频易混点。
2. **数字题抓高频**：90 学分、20 日、10%、30 年、20 万以下罚款、3 家废标、15/7 个工作日。
3. **口诀串联**：把散落各题的对比表/口诀（见第三节）集中记忆，效率最高。
