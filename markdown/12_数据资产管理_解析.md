### 第3题（不属于基本原则）

**答案**：C（坚持依法合规与应急管理相结合）

**解析**：五项原则：①安全与合规利用相结合；②创新方式与试点先行相结合；③有效市场与有为政府相结合；④分类分级与平等保护相结合；⑤权利分置与赋能增值相结合。无"依法合规与应急管理"。

**逐选项**：C ✗ 不属于（本题答案）；A、B、D ✓。

### 第7题（会计处理错误）

**题目**：关于数据资源会计处理，错误的是（ ）。

**答案**：B（研究阶段支出满足条件计入无形资产成本）

**解析**：**研究阶段支出应费用化**计入当期损益；只有**开发阶段**满足资本化条件才资本化。

**逐选项**：A ✓ 外购无形资产含评估登记等费用；B ✗ 研究阶段应费用化（本题答案）；C ✓ 估计寿命关注业务模式、时效性等；D ✓ 出售存货结转成本。

### 第10题（开放共享）

**题目**：关于开放共享，不正确的是（ ）。

**答案**：B（探索产业发展、行业发展的数据资产有条件无偿使用）

**解析**：公共治理、公益事业→**无偿**使用；产业发展、行业发展→**有偿**使用。B 把产业发展说成"无偿"，错误。

**逐选项**：A ✓ 确保公共安全保护隐私；B ✗ 产业发展应"有偿"（本题答案）；C ✓ 公益事业无偿；D ✓ 明确授权范围。

### 第11题（收益分配）

**题目**：关于收益分配，不正确的是（ ）。

**答案**：C（处置收入由本级财政部门规定具体管理办法）

**解析**：处置收入应**按照国家有关规定执行**（非由本级财政部门规定）；事业单位使用收入才由本级财政部门规定具体办法。

**逐选项**：A ✓ 行政单位使用收入按非税收入管理；B ✓ 事业单位使用收入由财政规定；C ✗ 处置收入按国家规定（本题答案）；D ✓ 不得违规处置收入。
