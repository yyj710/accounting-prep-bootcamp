## 单选题（124题）

### 第1题（条文·责任主体）

**题目**：应当对本单位的会计工作和会计资料的真实性、完整性负责的人员是（ ）。

- A. 单位负责人
- B. 财务总监
- C. 总会计师
- D. 内审人员

**答案**：A

**解析**：会计法第四条规定，**单位负责人**对本单位的会计工作和会计资料的真实性、完整性负责。这是"第一责任人"原则。

**逐选项**：
- A ✓ 单位负责人是法定责任主体
- B ✗ 财务总监只是分管，不是法定第一责任人
- C ✗ 总会计师是行政领导成员，不是责任主体
- D ✗ 内审人员更不承担此责

> 记忆：**会计第一责任人＝单位负责人**，其他人都不是。

### 第2题（条文·注册会计师审计监督）

**题目**：对于须经注册会计师进行审计的单位，下列说法中错误的是（ ）。

- A. 应当向受委托的会计师事务所如实提供会计资料及有关情况
- B. 任何单位或个人不得要求或示意注册会计师出具不实或不当的审计报告
- C. 财政部门有权对会计师事务所出具审计报告的内容进行监督
- D. 财政部门无权对会计师事务所出具审计报告的程序进行监督

**答案**：D

**解析**：财政部门对审计报告**内容和程序**都有权监督，D 说"程序无权监督"错误。

**逐选项**：A ✓ 如实提供资料；B ✓ 不得示意出假报告；C ✓ 内容有权监督；D ✗ 程序也有权监督。

> 记忆：**财政对审计报告"内容＋程序"双重监督**。

### 第3题（条文·会计核算范围）

**题目**：单位发生的下列经济业务事项中，不进行会计核算的是（ ）。

- A. 新增加的银行借款
- B. 董事会决议通过利润分配方案
- C. 购置的机械设备
- D. 公益性捐赠支出

**答案**：B

**解析**：会计核算针对已发生的经济业务。**董事会决议**只是内部决策，尚未形成资金变动，不需核算。

**逐选项**：A ✗ 借款需核算；B ✓ 决议未实际发生；C ✗ 购设备需核算；D ✗ 捐赠需核算。

> 记忆：**决议未执行不核算，资金实际变动才核算**。

### 第4题（记账本位币）

**题目**：下列关于我国企业记账本位币的说法中错误的是（ ）。

- A. 通常应当选择人民币作为记账本位币
- B. 记账本位币只能是人民币
- C. 无论采用哪种货币记账，编报的财务报告均应当折算为人民币
- D. 记账本位币一经确定，不得随意变更

**答案**：B

**解析**：业务收支以外币为主的企业可选其中一种外币作记账本位币，但**编报报告必须折算为人民币**。

**逐选项**：A ✓；B ✗ "只能"绝对化；C ✓；D ✓。

> 记忆：**记账可选外币，报告必折人民币**。

### 第5题（中期财务报告）

**题目**：下列各项关于中期财务报告的表述中，正确的是（ ）。

- A. 中期计量以年初至本中期末为基础，财务报告的频率会影响年度结果的计量
- B. 季节性、周期性或偶然性收入，应在中期财务报表中预计或递延
- C. 年度中不均匀发生的费用，年末允许预提或待摊的，中期不允许预提待摊
- D. 报告中期内新增子公司的，中期末应将其纳入合并范围

**答案**：D

**解析**：中期报告原则——频率**不影响**年度计量；季节性收入不递延；年末可预提的、中期也允许。

**逐选项**：
- A ✗ 频率"不影响"年度结果
- B ✗ 季节性收入不应在中期预计或递延
- C ✗ 年末可预提待摊的，中期也允许
- D ✓ 新增子公司中期末即纳入合并

> 记忆：**中期三不：不影响年度计量、不递延季节性收入、不搞差别预提**。

### 第6题（增值税纳税期限）

**题目**：关于增值税纳税期限，下列说法正确的是（ ）。

- A. 不能按固定期限纳税的，可以按次纳税
- B. 按固定期限纳税的小规模纳税人，一个会计年度内可以变更纳税期限
- C. 银行、财务公司、信托投资公司、信用社的纳税期限为一个月
- D. 具体纳税期限由主管税务机关根据纳税人的身份来核定

**答案**：A

**解析**：B"可变更"错（一经选择年内不得变更）；C 银行等为"一个季度"；D 应据"应纳税额大小"核定。

**逐选项**：A ✓；B ✗；C ✗ 一个季度；D ✗ 据税额大小。

> 记忆：**小规模年内不变、金融机构按季度、按次纳税是兜底**。

### 第7题（记账本位币）

**题目**：下列有关我国会计核算记账本位币的说法中，正确的是（ ）。

- A. 我国会计核算必须以人民币为记账本位币
- B. 业务收支以人民币为主的单位，应当以人民币为记账本位币
- C. 业务收支以人民币以外的货币为主的单位，应当折算为人民币进行核算
- D. 编报的财务会计报告可以选定一种常用的外币进行展示

**答案**：B

**逐选项**：A ✗ 不是"必须"；B ✓；C ✗ 可选定外币；D ✗ 报告必折人民币。

> 记忆：**日常记账可外币，对外报告必人民币**。

### 第12题（记账本位币确定因素）

**题目**：企业在确定记账本位币时不应当考虑的因素是（ ）。

- A. 该货币主要影响商品劳务销售价格
- B. 该货币主要影响人工、材料等费用
- C. 注册地使用的法定货币
- D. 融资活动获得的货币

**答案**：C

**逐选项**：A、B、D ✓ 均应考虑；C ✗ 注册地法定货币不是因素。

> 记忆：**看经济环境三货币，不看注册地**。

### 第13题（原始凭证审核）

**题目**：下列有关会计机构、会计人员对原始凭证的取得、审核等相关说法中，错误的是（ ）。

- A. 对不真实、不合法的原始凭证有权不予接受，并向主管会计师报告
- B. 对记载不准确、不完整的原始凭证予以退回
- C. 原始凭证记载的各项内容均不得涂改
- D. 原始凭证金额有错误的，应当由出具单位重开，不得在原始凭证上更正

**答案**：A

**解析**：对不真实不合法的凭证不予接受，应向**单位负责人**报告（不是"主管会计师"）。

**逐选项**：A ✗ 报告对象错；B ✓ 退回；C ✓ 不得涂改；D ✓ 金额错误须重开。

> 记忆：**不真实不合法→拒收报告单位负责人；金额错→重开不更正**。

### 第17题（境外经营记账本位币）

**题目**：关于境外经营记账本位币的确定，下列表述中正确的是（ ）。

- A. 活动视同企业延伸的，应选与企业相同的货币
- B. 活动不能拥有极大自主性的，应根据主要经济环境选择
- C. 交易比例较高的，应自主选择适合的货币
- D. 现金流量间接影响、不可随时汇回的，应选与企业相同的货币

**答案**：A

**解析**：判断境外经营是"延伸"还是"独立"——延伸则与企业同币，独立则按自身经济环境选币。

**逐选项**：
- A ✓ 延伸→同币
- B ✗ 无自主性应与企业同币
- C ✗ 交易比例高→应与企业同币
- D ✗ 现金流量间接、不可汇回→按自身环境选币

> 记忆：**延伸同币、独立自选；与企业关联紧→同币，关联松→自选**。

**题目**：关于检举会计违法行为的说法，正确的有（ ）。

- A. 只有会计机构负责人有权检举
- B. 收到检举的部门有权处理的，应当依法按职责分工及时处理
- C. 收到检举的部门、负责处理的部门应当为检举人保密
- D. 收到检举的部门应将检举材料转给被检举单位进行核对

**答案**：B、C

**解析**：任何单位和个人都有权检举（A 错）；不得将材料转给被检举单位（D 错）。

**逐选项**：A ✗ 人人可检举；B ✓；C ✓；D ✗ 不得转被检举单位。
