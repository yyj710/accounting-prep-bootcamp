**1. 法规依据与总则（共5题：单选3 / 多选1 / 判断1）**
- 制定依据：会计档案管理以《会计法》为立法依据
- 新增要求：2024版《会计法》新增会计档案安全保护要求（第23条）
- 期限规定主体：保管期限由《会计档案管理办法》统一规定，企业不得自定
- 期限决定依据：保存期限和销毁期限均由《会计档案管理办法》等国家法律法规决定
- 适用范围：国家机关、社会团体、企业、事业单位均适用本办法
- 企业自定禁止：企业不得随意决定会计档案的保存期限

**2. 归档范围与归档整理移交（共9题：单选4 / 多选2 / 判断3）**
- 归档范围：会计凭证、会计账簿、财务会计报告、其他会计资料四大类
- 非归档资料：租赁合同等业务合同不属于会计资料，不予归档
- 财务会计报告种类：包括月度、季度、半年度、年度四类（第6条）
- 归档责任主体：归档由会计管理机构（财务部门）负责，先临时保管整理后移交
- 分类与编号：应按类别和年度分类编号保存，不得随意存放或随时更改
- 移交清册内容：列明会计档案名称、档案编号、应保管期限，不含档案管理人
- 机构变动保管：合并后由存续/合并单位统一保管；分立未了事项凭证由业务相关方保存
- 建设单位移交：项目建设期档案需移交的，办理竣工财务决算后及时移交

**3. 保管期限（共5题：单选3 / 多选0 / 判断2）**
- 期限体系：会计档案保管期限分永久、30年、10年、5年
- 定期两档：定期保管期限为10年和30年
- 凭证期限：原始凭证、记账凭证的保管期限均为30年
- 最低期限：企业会计档案保管期限一般不少于10年
- 特殊期限：固定资产卡片在固定资产报废清理后保管5年
- 永久期限：年度财务报告属永久保管
- 易错点：不存在"3年"期限，也不能笼统称"不少于10年"

**4. 保管、存放与安全保密（共6题：单选1 / 多选3 / 判断2）**
- 保存地点：应存放在档案室等专门场所，不能随意存放或放办公桌
- 存放环境：远离高温潮湿，做到防潮、防高温、防火、防蛀
- 保密要求：既要防止丢失，也要保密，须采取安全防护措施
- 外部存储限制：不得由外部公司随意存储档案，涉及安全保密
- 安全存储条件：应提供安全存储条件并进行分类编号管理
- 加密防泄漏：可加密防泄漏、可云端存储，但须保障安全
- 保存基本要求：保存期不少于10年、分类整理、妥善保管避免损毁
- 禁止公开：不得对外公开会计档案内容

**5. 管理基本要求与职责（共11题：单选5 / 多选4 / 判断2）**
- 管理原则：坚持完整性、准确性和保密性
- 基本要求：确保会计档案真实、完整、保密，及时性不属核心要求
- 档案属性：采安全防护措施，保证真实、完整、可靠、安全
- 管理环节：包括收集、整理、保管、使用、销毁（含鉴定）等
- 基本工作：含收集、整理、保管、保密管理、销毁管理等，不含"销售"
- 分类要求：应按年度分类（非按会计科目分类）并保证安全性
- 销毁禁止：会计档案不得随便销毁，须按法定程序鉴定、审批
- 出纳兼管禁止：出纳人员不得兼管会计档案，与单位人手多少无关

**6. 鉴定与销毁（共12题：单选3 / 多选2 / 判断7）**
- 鉴定组织：由单位档案管理机构牵头，组织会计、审计、纪检监察等共同进行
- 鉴定意见书：应定期对已到保管期限的档案鉴定并形成鉴定意见书（第16条）
- 鉴定主体：非档案机构单独鉴定，其他机构人员应共同参与
- 销毁依据：按国家规定的保存期限鉴定后销毁，非企业自定
- 销毁条件：须保管期满、经企业相关部门审核、不违反法律法规
- 销毁程序：编制销毁清册5人签署，档案机构组织、会计机构共同监销，前后清点签章
- 未了事项凭证：保管期满但未结清债权债务的凭证不得销毁，保管至未了事项完结
- 销毁禁止与审批：任何人和财务人员不得随意销毁，无需财政部门批准但须按程序

**7. 电子会计档案（共5题：单选2 / 多选0 / 判断3）**
- 保存形式：会计档案包括纸质档案和电子档案两种形式
- 电子归档条件：外部接收电子会计资料附符合《电子签名法》的签名且满足条件，可仅以电子形式归档
- 可电子保存：会计档案可以电子方式保存，并非只能以纸质存储
- 纸质移交：纸质档案移交应保持原封装
- 保管期限起算：保管期限从会计年度终了后第一天算起
- 接收检测：接收电子会计档案应检测其准确性、完整性、可用性、安全性（第12条）
- 电子化管理：《会计档案管理办法》对会计档案电子化管理提出要求

## 7. 电子会计档案
