## 使用说明

### 文档结构

每份文档都包含以下五个部分：

1. **知识框架总览** — 用思维导图式结构展示整个知识体系的全貌
2. **核心考点精讲** — 按模块逐一讲解重点知识点，包含定义、对比表格、记忆口诀、易错提示
3. **易错陷阱TOP 10** — 总结最容易出错的知识点，用"错误说法 vs 正确说法"对比
4. **核心要点速查表** — 把关键数字、比例、期限、分类等整理成表格，考前快速复习
5. **全部题目练习** — 按题型分类列出所有题目，附答案和出处

### 学习建议

- **第一轮（框架学习）**：先看知识框架和核心考点，建立整体认知
- **第二轮（重点突破）**：聚焦易错陷阱和速查表，攻克薄弱点
- **第三轮（刷题巩固）**：通过全部题目练习检验学习效果
- **考前冲刺**：直接看"易错陷阱"和"要点速查表"，效率最高
