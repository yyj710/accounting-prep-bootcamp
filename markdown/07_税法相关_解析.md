**1. 增值税（共12题：单选10 / 多选0 / 判断2）**
- 视同销售：自产或委托加工货物用于投资、集体福利视同销售；外购用于集体福利不视同，作进项转出
- 加计抵减：先进制造业按当期可抵扣进项5%计提，出口及跨境不得计提，政策择优不叠加，可补提
- 简易计税：县级及以下小水电自产电力、水泥混凝土、生物制品、自来水及文化体育等服务可选简易
- 税率适用：卫星电视落地转接按增值电信6%；建筑服务9%、有形动产租赁13%、无形资产9%
- 服务税目归类：游船属文化体育、植物养护属生活服务、市场调查属咨询、财务担保属直接收费金融
- 免税项目：集团内无偿借贷、金融机构小额贷款利息、科普门票免征；城市电影放映仅简易计税
- 专用发票：向消费者个人销售、免税项目、零售消费品不得开具，劳保专用品除外
- 出口退税与贷款进项：出口退税率与适用税率不一定一致；与贷款直接相关的顾问费、手续费不得抵扣

**2. 企业所得税（共7题：单选7 / 多选0 / 判断0）**
- 居民企业：依中国法律成立，或外国法律成立但实际管理机构在境内的为居民企业
- 视同销售：货物所有权发生转移（捐赠、偿债、赞助、广告、样品、职工福利等）视同销售，自用不视同
- 税金扣除：契税、耕地占用税、车购税、进口关税计入资产成本；消费税、印花税、房产税当期扣除
- 不得扣除：企业所得税本身、可抵扣增值税不得税前扣除；不得抵扣增值税可计入成本扣除
- 商誉与折旧摊销：自创商誉不得摊销扣除；固定资产次月折旧、无形资产当月摊销、林木类10年
- 减半征收：海水、内陆养殖及花卉茶饮料作物香料作物种植减半；农产品初加工、油料种植免征
- 转让定价方法：交易净利润法看净利润水平，另有可比非受控价格、再销售价格、成本加成、利润分割法

**3. 个人所得税（共8题：单选3 / 多选5 / 判断0）**
- 个税纳税人：个人独资企业、合伙企业、个体工商户交个税；法人型公司交企业所得税
- 工资薪金所得范围：全年一次性奖金属工资薪金；独生子女补贴、托儿补助、差旅津贴、误餐补助不征税
- 劳务报酬所得：以雇佣关系判断，有雇佣属工资薪金，无雇佣的独立劳务属劳务报酬
- 特许权使用费所得：转让专利权、商标权、著作权、非专利技术使用权；出租房屋属财产租赁
- 经营所得：个体工商户生产、个人独资、合伙、办学医疗咨询、彩票代销属经营所得
- 计征方式：综合所得、经营所得按年计征；利息股息红利、财产租赁转让、偶然所得按次计征
- 税率：利息股息红利、财产租赁转让、偶然所得适用20%比例税率；劳务报酬七级、经营所得五级超额累进

**4. 个人所得税扣除与申报（共5题：单选2 / 多选3 / 判断0）**
- 公益捐赠扣除：一般按应纳税所得额30%限额，向红十字、农村义务教育、青少年活动场所捐赠可全额扣除
- 住房贷款利息扣除：首套每月1000元，最长240个月，只能享受一次，夫妻可约定一方扣除
- 住房租金扣除：工作城市无自有住房可扣，省会1500元/月；贷款利息与租金不能同时享受
- 专项附加扣除时间：婴幼儿照护出生当月至满3周岁前一月；学历教育含休学；赡养老人至义务终止年末
- 纳税申报情形：取得境外所得、注销户籍、无扣缴义务人或未扣缴、综合所得需汇算等应办理申报

**5. 税收征收管理（共4题：单选4 / 多选0 / 判断0）**
- 增值税纳税期限：按月或季纳税期满15日内申报；按1至15日纳税期满5日内预缴、次月15日内申报
- 房地产预征率：一般纳税人预收款销售自行开发项目，按3%预征率预缴增值税
- 汇总纳税：新设分支机构第2年起分摊、撤销自注销之日起不参与，税款50%由总机构分摊
- 税法原则：禁止对特定纳税人歧视性对待、禁止无正当理由特别优惠体现税收公平原则

**6. 所得税会计（共7题：单选4 / 多选1 / 判断2）**
- 递延所得税：暂时性差异×未来转回时税率，不折现；为递延所得税负债与资产的当期净变动
- 暂时性差异与永久性差异：账面与计税基础可转回差额为暂时性差异；国债利息属永久性差异
- 递延所得税资产：可抵扣暂时性差异×25%确认，如计提减值、商标权摊销形成
- 计税基础：资产计税基础为未来可税前扣除总金额；账面大于计税基础形成应纳税暂时性差异
- 预计负债计税基础：一般预计负债计税基础为0；债务担保预计负债计税基础等于账面价值
- 商誉递延所得税：免税合并商誉计税基础为0，形成应纳税暂时性差异但不确认递延所得税负债
- 其他权益工具投资：公允价值变动计入其他综合收益，对应递延所得税也计入其他综合收益

**7. 收入确认与计量（共5题：单选1 / 多选2 / 判断2）**
- 五步法：识别合同、识别单项履约义务、确定交易价格、分摊交易价格、履行义务时确认收入
- 商业折扣：直接冲减交易价格，按不含税打折后金额确认收入
- 现金折扣：实际发生时计入财务费用，不冲减收入
- 交易价格：按预期有权收取的对价确认，不包括代第三方收取的款项和预期退还客户的款项
- 买一赠一：不属捐赠，按各项商品公允价值比例分摊确认收入

**8. 会计业务处理（共7题：单选4 / 多选2 / 判断1）**
- 投资性房地产公允模式：不计提折旧，租金收入与公允价值变动损益均影响营业利润
- 政府补助：具无偿性与直接转移经济资源特征，无偿划拨土地使用权属政府补助
- 现金流量：销售商品收到现金＝营业收入－应收账款增加额
- 债务重组：债务人以资产偿债，损益＝应付债务账面－（资产账面价值＋销项税额），计入其他收益
- 非同一控制合并初始成本：个别报表按付出对价公允价值确认长投，发行证券承销佣金冲减股本溢价
- 存货采购成本：含买价、相关税费、运输装卸保险费、合理损耗、仓储费，不含可抵扣进项税
- 继续教育：含公需科目与专业科目，涵盖会计理论、政策法规、业务技能，不只是税法

## 1. 增值税

> 共 12 题（单选题 10 题、判断题 2 题）

### 单选题（10题）

#### 第1题　视同销售

**题目**：需要视同销售征收增值税的是（ ）。

**答案**：C（将委托加工收回的卷烟用于对外投资）

**解析**：增值税视同销售分"自产/委托加工"和"外购"两套规则：
- 自产/委托加工的货物用于**对外（投资、分配、赠送）和集体福利/个人消费**→视同销售。
- 外购货物用于**对外投资、分配、赠送**→视同销售；外购用于**集体福利/个人消费**→不视同（进项转出）。

**逐选项**：A ✗ 外购空调用于职工食堂（集体福利）→不视同；B ✗ 用于生产应税产品（正常应税）→不视同；C ✓ 委托加工用于对外投资→视同销售；D ✗ 无偿提供法律咨询（服务，金融商品除外一般不视同）。

#### 第2题　加计抵减

**题目**：先进制造业加计抵减政策，正确的是（ ）。

**答案**：D（可计提但未计提的加计抵减额，可在确定适用当期一并计提）

**解析**：先进制造业按当期可抵扣进项税额**5%**计提；出口及跨境应税行为**不得**计提；多项政策**择优不得叠加**；未计提的可**补提**。

**逐选项**：A ✗ 是5%非15%；B ✗ 跨境不适用；C ✗ 不得叠加；D ✓ 可补提。

---

#### 第3题　增值税征税范围

**题目**：不符合增值税征税范围规定的是（ ）。

**答案**：C（邮政公司包裹邮寄按物流辅助服务缴税）

**解析**：邮政包裹邮寄属**邮政普遍服务**，**免征**增值税（非物流辅助）。其他：植物养护→其他生活服务；市场调查→咨询服务；财务担保→直接收费金融服务。

**逐选项**：A、B、D ✓ 表述正确；C ✗ 邮政普遍服务免税（本题答案）。

---

#### 第4题　简易计税

**题目**：不得选择简易计税的是（ ）。

**答案**：A（省级水力发电单位销售自产电力）

**解析**：可简易计税的水电是**县级及县级以下小型水力发电单位**自产电力；**省级**水电单位不适用。

**逐选项**：A ✗ 省级→不得简易（本题答案）；B ✓ 水泥混凝土可简易；C ✓ 生物制品可简易；D ✓ 自来水可简易。

#### 第5题　增值税视同应税交易

**题目**：应视同应税交易缴纳增值税的是（ ）。

**答案**：B（将自产饮料发放给员工）

**解析**：自产货物用于**集体福利/个人消费**→视同销售；外购货物用于集体福利→不视同（进项转出）。无偿提供服务（金融商品除外）→不视同。

**逐选项**：A ✗ 免费视听课程（无偿服务不视同）；B ✓ 自产饮料发员工（视同销售）；C ✗ 以固定资产入股（用固定资产投资不视同应税交易，另有规定）；D ✗ 外购食品发福利（不视同）。

#### 第6题　生活服务

**题目**：按"生活服务"缴纳增值税的是（ ）。

**答案**：D（在公园内向游客提供游船服务）

**解析**：生活服务含文化体育、教育医疗、旅游娱乐、餐饮住宿、居民日常等。游船（游览场所经营）→**文化体育服务**（生活服务）。

**逐选项**：A ✗ 会议场地及配套→会议展览服务（现代服务）；B ✗ 收派服务→物流辅助（现代服务）；C ✗ 车辆停放→不动产经营租赁（现代服务）；D ✓ 游船→文化体育服务（生活服务）。

#### 第7题　增值税专用发票

**题目**：允许开具增值税专用发票的是（ ）。

**答案**：D（商贸公司向一般纳税人销售劳保鞋帽）

**解析**：不得开专票：①向**消费者个人**销售；②适用**免税**规定；③商业零售**消费品**（烟酒食品服装鞋帽化妆品等，但**劳保专用**除外）。

**逐选项**：A ✗ 向个人销售电器；B ✗ 零售食品（消费品）；C ✗ 零售蔬菜（免税）；D ✓ 劳保鞋帽（劳保专用除外）。

#### 第8题　6%税率

**题目**：适用6%税率的是（ ）。

**答案**：A（卫星电视信号落地转接服务）

**解析**：卫星电视落地转接→**增值电信服务**（6%）。建筑施工设备出租配操作员→建筑服务9%；飞机广告位→有形动产租赁13%；土地使用权转让→销售无形资产9%。

**逐选项**：A ✓ 增值电信6%；B ✗ 建筑服务9%；C ✗ 有形动产租赁13%；D ✗ 无形资产9%。

#### 第9题　简易计税

**题目**：可选择简易计税的是（ ）。

**答案**：D（文化体育服务）

**解析**：一般纳税人提供**电影放映、仓储、装卸搬运、收派、文化体育服务**可选择简易计税。

**逐选项**：A、B、C ✗ 均不可简易；D ✓ 文化体育服务可简易。

#### 第10题　免征增值税

**题目**：不得享受免征增值税的是（ ）。

**答案**：D（城市电影放映服务）

**解析**：城市电影放映服务只能**简易计税**，无免税优惠。企业集团内无偿借贷、金融机构小额贷款利息、科普单位门票收入均可免征。

**逐选项**：A ✗ 集团内无偿借贷免征；B ✗ 小额贷款利息免征；C ✗ 科普门票免征；D ✓ 城市电影放映无免税（本题答案）。

## 2. 企业所得税

> 共 7 题（单选题 7 题）

### 单选题（7题）

#### 第1题　转让定价方法

**题目**：按无关联交易各方相同/类似业务往来取得的"净利润水平"确定利润的方法是（ ）。

**答案**：C（交易净利润法）

**解析**：五种转让定价方法各看不同指标：可比非受控价格法→**价格**；再销售价格法→**销售毛利**；成本加成法→**成本+毛利**；交易净利润法→**净利润率**；利润分割法→**合并利润分配**。

**逐选项**：A ✗ 利润分割法（分利润）；B ✗ 再销售价格法（减毛利）；C ✓ 交易净利润法（净利润水平）；D ✗ 可比非受控价格法（价格）。

---

#### 第2题　企税视同销售

**题目**：应当视同销售确认收入的是（ ）。

**答案**：C（将自产货物用于赠送客户）

**解析**：企业所得税视同销售关键是**所有权转移**。用于捐赠、偿债、赞助、集资、广告、样品、职工福利、利润分配等→视同销售。用于本企业生产/办公（未转移）→不视同。

**逐选项**：A ✗ 用于生产卷烟（继续生产）；B ✗ 门市房转自用（用途改变非转移）；C ✓ 赠送客户（所有权转移）；D ✗ 用于财务办公（自用）。

---

#### 第3题　减半征收

**题目**：减半征收企业所得税的是（ ）。

**答案**：C（内陆养殖）

**解析**：农林牧渔"种植、饲养"多免征，但**海水养殖、内陆养殖**及**花卉、茶、饮料作物、香料作物种植**减半征收。远洋捕捞免征。

> 口诀：**花茶香、海内陆**——减半；蔬菜谷物油料等种植、远洋捕捞——免征。

**逐选项**：A ✗ 农产品初加工免征；B ✗ 油料种植免征；C ✓ 内陆养殖减半；D ✗ 林木培育免征。

---

#### 第4题　税金扣除

**题目**：发生当期不得直接在税前扣除的税金是（ ）。

## 6. 所得税会计

#### 第1题　递延所得税

**题目**：关于递延所得税会计处理，正确的是（ ）。

**答案**：A（将当期发生的满足条件的可抵扣暂时性差异确认为递延所得税资产）

**逐选项**：A ✓ 可抵扣暂时性差异→递延所得税资产；B ✗ 递延所得税是两者"当期发生额"的净额，非直接相加；C ✗ 应用**未来转回期间**税率，非当期税率；D ✗ 递延所得税**不折现**。

#### 第2题　暂时性差异

**题目**：不产生暂时性差异的是（ ）。

**答案**：D（国债利息收入）

**解析**：暂时性差异＝账面价值与计税基础的**可转回**差额；**永久性差异**＝永远不转回（免税收入、不得扣除项目）。国债利息是免税收入，产生**永久性差异**，不产生暂时性差异。

**逐选项**：A ✗ 自行研发加计扣除→可抵扣暂时性差异（计税基础=账面200%）；B ✗ 坏账准备→可抵扣暂时性差异；C ✗ 公允模式投资性房地产→应纳税暂时性差异；D ✓ 国债利息→永久性差异。

#### 第3题　其他权益工具投资

**解析**：其他权益工具投资公允变动计入**其他综合收益**，且递延所得税也对应其他综合收益。账面600万，计税基础400万，应纳税暂时性差异200万→递延所得税负债50万（冲其他综合收益）。其他综合收益 = (600−400) − 50 = 150 万。

**逐选项**：A ✗ 50 是递延税负债额；B ✓ 150；C ✗ 200 是暂时性差异；D ✗ 0。

**题目**：关于交易价格，错误的有（ ）。

**解析**：可变对价按**期望值或最可能发生金额**估计（不是只能期望值，A错）；对价金额可固定也可**可变**（B错）；交易价格**不包括**代第三方收取款项（C错）、不包括预期退款（D对）。

**逐选项**：A ✗ 也可用最可能金额；B ✗ 可可变；C ✗ 不含代收款；D ✓ 正确表述。

## 8. 会计业务处理

> 共 7 题（单选题 4 题、多选题 2 题、判断题 1 题）

### 单选题（4题）

#### 第1题　投资性房地产公允模式

**题目**：经营租赁出租商铺（公允模式），账面5000万，6/30公允5100万，12/31公允5200万，年租金300万，对营业利润影响（ ）万元。

**答案**：B（500）

**解析**：公允模式下两笔都进营业利润：①租金收入 300（其他业务收入）；②公允价值变动损益 = 5200−5000 = 200。合计 500 万。

> 关键：公允模式**不计提折旧**，期末按公允价值调整，差额计入"公允价值变动损益"。

**逐选项**：A ✗ 0 漏了；B ✓ 300+200=500；C ✗ 300 只算租金；D ✗ 200 只算公允变动。

---

#### 第2题　政府补助

**题目**：关于政府补助，正确的是（ ）。

**答案**：D（政府无偿划拨的土地使用权属于政府补助）

**解析**：政府补助特征：**无偿性**（但有条件）、**直接转移经济资源**。三个易混点：投资者投入资本（互惠）→非补助；增值税直接减免/即征即退中"直接减免"不涉及资产直接转移→非补助；无偿划拨→补助。

**逐选项**：A ✗ 无偿但通常有条件；B ✗ 投资者投入是互惠交易；C ✗ 直接减免不涉及资源直接转移；D ✓ 无偿划拨土地是政府补助。

---

#### 第3题　现金流量

**题目**：营业收入300万，应收账款年末50万、上年末40万，销售商品收到现金（ ）万元。

**答案**：A（290）

**解析**：销售收现 = 营业收入 − 应收账款**增加额** = 300 − (50−40) = 290 万。应收增加10万，说明有10万挂在账上没收现。

> 口诀：**收入减应收增加，才是真金白银**。

**逐选项**：A ✓ 290；B ✗ 310 方向反了（加应收增加）；C ✗ 300 忽略应收；D ✗ 350。

---

#### 第4题　债务重组

**题目**：乙公司以无形资产偿债，应付1600万，无形资产账面960万（原价1200、摊销240），公允1200万，增值税72万，影响损益（ ）万元。

**答案**：B（568）

**解析**：债务人以资产清偿债务，损益 = 应付债务账面 −（资产账面 + 销项税额）= 1600 − 960 − 72 = 568 万，计入**其他收益**。注意用的是**账面价值**960，不是公允价值1200。

**逐选项**：A ✗ 400 用公允算错；B ✓ 568；C ✗ 640 漏税；D ✗ 328。
