# CPA 税法：把碎条文做成能自测的站

> **直接下载用**：[税法CPA复习站.html](./税法CPA复习站.html)（离线可开）

## 我遇到的问题

税法条文碎、数字多、期限多，看书很容易「眼睛过了脑子没过」。而且本学期优先级很清楚：**初级会计期末 > 12 月 10/11 日的 ACCA FR / FM > CPA 税法**，所以这条线不能占太多时间，得用最少动作维持手感。

## 我怎么提的需求

- 不做大部头讲义，做成**能自测的网页**：按章做题、当场看答案、错题留痕。
- 把高频的数字、比例、期限收进速查，考前扫一眼就够。
- 教辅里的题目要能进来练，但答案必须配上解析，不能只甩一个字母。

## 最后做成什么

- **1–5 章复习站**：题库、考点速查、做题记录，单文件离线。
- **第五章个人所得税**单独补齐，章节收尾时把该章题目和答案逐条对完。
- 题目从扫描件里整理出来时，处理过选项横排、答案框是图片这类问题——这类脏活最后都收进结构化题库，页面上只留能用的题。

## 怎么用 / 注意

这条线是顺手维持的，不是主战场：按章刷一遍，考前只看速查和错题。税法政策会变，**税率、优惠、申报期限一律以最新法规和官方教材为准**，仓库里的整理只作复习框架。教材与扫描原件不在仓库里。
