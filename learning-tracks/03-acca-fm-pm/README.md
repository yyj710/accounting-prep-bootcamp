# ACCA FM / PM：刷题站 + 文字题模板

> **直接下载用**：[ACCA_FM_刷题站.html](./ACCA_FM_刷题站.html)（离线可开）
> 配套笔记：[FM_文字题模板.md](./FM_文字题模板.md)

## 我遇到的问题

FM (F5) 也是 12 月全球统考。计算题练着练着会了，但**文字题**没抓手：知道意思，写不出得分点，答完也不知道自己漏了什么。另外题目和答案散在好几个文件里，做完一章回头找错题很麻烦。

PM 我已经考过，但笔记还是散的——想把 FR 那边跑通的方法直接搬过来，不再重新设计一套。

## 我怎么提的需求

- 做题要有反馈闭环：**错题能自动回到对应知识点速查**，不是做完就翻篇。
- 文字题要给模板：常见问法、得分点怎么写、哪些词必须出现。
- 题库按章节切好，答案单独放着，方便一批一批对。
- 笔记按课本大纲整理，同时保留一版「讲逻辑、讲为什么」的理解版。

## 最后做成什么

- **FM 刷题站**：分章节刷题、错题与速查联动、进度记录，单文件离线。
- **结构化题库与答案**：题目、答案按章节拆开存放，方便核对和后续补充。
- **文字题模板 + 全科笔记**：按大纲整理的全科文档、逻辑理解版、PM 冲刺英文短句版。

## 怎么用 / 注意

先按章刷题 → 错题回速查补知识点 → 考前集中过文字题模板。FR 与 FM 共用同一套「五块模板 + 精简版」的整理方法，所以两个目录看起来是一家人。

12 月 FM 统考还在备考，题目与讲义原件不在仓库里，解析以 ACCA 官方口径为准。
