## 为什么不做成三份复习

2026 年秋天我同时在做：会计知识竞赛（队长，11 月底决赛）、初级财务会计学期末（目标满绩）、12 月 ACCA FR / FM 全球统考。时间不够分成三份复习，而这三条线用的是同一套会计知识，所以我把整理出来的东西按「课程相关」排序，**一份资料同时服务三件事**。

竞赛、期末、ACCA 是三条主线；CPA 税法是顺手维持手感的第四条，一共四个工具。

具体怎么和 AI 协作、我在对话里提了什么需求、哪里做错了又怎么改回来 → [HOW-I-WORK-WITH-AI.zh-CN.md](../HOW-I-WORK-WITH-AI.zh-CN.md)

## 关于这些资料

- 全部是**我个人整理的成品**：网页、笔记、题库结构。过程日志、临时脚本、历史版本留在私有留痕仓库，不塞在这里。
- 教材、题库原件（PDF / Word / 扫描件）**不在这个仓库**，题目与考点来自公开渠道与课堂材料，仅作学习交流。
- 期末站的题库答案已对照两章官方作业参考答案逐题核过（198/198 一致）；其他科目的解析是学习整理，考试请以官方口径为准。
