# 第1章 概念框架（Conceptual Framework）

> 考试形式：Section A 选择题（单选/多选/判断/匹配）；基础必考章。一句话重点：CF 是"指导性理论原则"，**不是 IFRS**，与准则冲突时以准则为准。

**框架结构总览**

```
Conceptual Framework（指导性，非准则）
├── Ch1 通用目的财务报告的目标
├── Ch2 质量特征（基本：相关/如实反映；增强：可比/可验证/及时/可理解；+成本约束）
├── Ch3 财务报表与报告主体（持续经营、权责发生制）
├── Ch4 财务报表要素（资产/负债/权益/收入/费用）
├── Ch5 确认与终止确认
├── Ch6 计量（历史成本 vs 现行价值）
├── Ch7 列报与披露
└── Ch8 资本与资本保全
```

## 1.1 概念框架的含义与目的

* 含义：一套**公认的理论原则**，构成财务报告参考框架，用于确定：核算**哪些事项**、**如何计量**、**如何传达**。
* **目的（4条）**：①协助 IASB 制定/修订准则；②避免"灭火式（fire-fighting）"制定准则；③协助**编制者**在"无适用 IFRS 的特定交易"或"准则允许选择会计政策"时制定一致的会计政策；④协助**各方**理解与解释 IFRS。

**⚠️易错**：

* CF **不是一项 IFRS Standard**；与 IFRS/IAS 冲突时**以 IFRS/IAS 为准**，CF 不凌驾于任何 IFRS 或其任何要求。
* CF 修订**不会自动**导致 IFRS 变更；修改 IFRS 须由 IASB 重走完整 **due process**。
* &#x20;**code of ethics and conduct**，**不属于** CF。
* CF 是**原则导向（principles-based）**，但本身不是一项准则。

## 1.2 通用目的财务报告的目标（CF Ch1）

* 提供关于报告主体**财务状况、财务业绩、现金流量**的信息，对**广泛使用者**（现有及潜在投资者、贷款人、其他债权人）做出**资源决策**有用。
* 报表同时展示管理层对受托资源的**经营责任（stewardship）**&#x5C65;行结果。

**📌考点**：决策有用观 + 受托责任（stewardship）观；使用者是"**广泛使用者**"而非仅股东。

### 1.2.1 权责发生制（Accruals basis）

* 交易及其他事项的影响在其**发生时**确认（非现金收付时）；也即**配比（matching）**&#x6982;念。（现金流量表除外）

### 1.2.2 持续经营（Going concern）—— 唯一基础假设

* 假设主体在可预见未来**持续经营**；否则须改用**其他基础**（如清算/break-up basis）编制。

## 1.3 质量特征（Qualitative Characteristics）—— ⭐核心考点

### 1.3.1 基本特征（Fundamental，每个都**必须**满足 / must）

| **特征**                           | **要点**                                                                                  |
| -------------------------------- | --------------------------------------------------------------------------------------- |
| **Relevance 相关性**                | 能影响使用者决策；具**预测价值**和/或**确认价值**；门槛=**重要性**                                                |
| **Faithful representation 如实反映** | 反映**经济实质而非法律形式**；须**完整（complete）+ 中立（neutral，由审慎 prudence 支持）+ 无重大差错（free from error）** |

* **重要性（Materiality）**：遗漏或错报可合理预期影响使用者决策即为重要；是相关性的**主体特定**方面，基于**性质（nature）、金额（magnitude）或两者兼有**。
* **审慎（Prudence）**：在不确定条件下作判断时谨慎；**不得高估资产/收入，不得低估负债/费用**；但**不允许**建立隐藏准备。
* **实质重于形式**：经济实质 > 法律形式（例：IFRS 16 确认使用权资产；对被起诉的或有事项按很可能流出确认负债）。

### 1.3.2 增强特征（Enhancing，**最大化** / maximum）

| **特征**                     | **要点**                                   |
| -------------------------- | ---------------------------------------- |
| **Comparability 可比性**      | 识别并理解项目间**相似性与差异**；**≠ 统一性（uniformity）** |
| **Verifiability 可验证性**     | 不同的、有知识的独立观察者能就"如实反映"**达成共识**（不要求完全一致）   |
| **Timeliness 及时性**         | 信息在能影响决策的**时间范围内**可用                     |
| **Understandability 可理解性** | 清晰、简洁地分类/描述/列报；面向具合理商业知识、勤勉分析的使用者        |

**📌考点（可比性真题）**：

* **能提高**可比性的做法：政策变更时**重述**以前年度报表；除非准则要求或为提供更相关可靠信息否则**禁止政策变更**；**披露终止经营**。
* **不能提高**可比性：把主体**当前政策**应用于其**从未发生过的交易**（新交易无"与过去比较"的基础）。
* **满足可比性**的要求：①**披露会计政策**；②财务报表提供**对应（比较）信息**。（③"每期必须用同一政策"、④"同一类资产同一折旧率" **不是**可比性要求）

**⚠️易错**：可比性 ≠ 一致性（consistency）≠ 统一性；允许合理范围内的政策差异，但变更须充分披露并按 **IAS 8** 处理。

### 1.3.3 成本约束（Cost constraint）

* 信息**效益须超过取得与列报的成本**（Benefit ≥ Cost）。

**⚠️易错**：成本约束是**普遍约束（pervasive constraint）**，**不是质量特征**。

## 1.4 财务报表与报告主体（CF Ch3）

* **报告主体**：被要求或选择编制财务报表的主体；可为单一主体、主体的一部分或由多个主体组成；**不一定是法律主体**。

## 1.5 财务报表要素（CF Ch4）—— ⭐高频

* **资产**：主体因**过去事项**而**控制的现时经济资源**（经济资源=有产生经济利益潜力的权利）。三条件：现时经济资源 + 主体控制 + 因过去事项产生。
* **负债**：主体因**过去事项**转移经济资源的**现时义务**（法律义务或推定义务）；义务=主体**没有实际能力避免**且由过去事项产生。
* **权益**：资产扣除全部负债后的**剩余利益**。Equity = Net assets = Share capital + Reserves（Share premium + Revaluation surplus + Retained earnings）。
* **收入**：**资产增加或负债减少**导致权益增加，**不含与权益持有者出资相关部分**。
* **费用**：**资产减少或负债增加**导致权益减少，**不含与权益持有者分配相关部分**。

**📌考点**：资产核心是"**控制**"非所有权；负债要求"**无法实际避免**"；收入/费用**排除权益交易**。

**⚠️易错**：

* 所有者**出资**（Dr Cash → Cr Share capital/premium）**不是收入**；**股利分配**（Dr Retained earnings → Cr Cash/Payable）**不是费用**。
* "能可靠计量（reliably measured）"**不是**资产/负债的**定义**要素，而是**确认标准**。

## 1.6 确认与终止确认（CF Ch5）

* **确认条件**：①符合要素定义；②确认能向使用者提供**有用信息**（相关 + 如实反映）；并受**成本约束**。
* **2010 旧框架确认标准**：①符合定义；②未来经济利益**很可能**流入/流出；③成本或价值能**可靠计量**。
* **终止确认**：**资产**——丧失全部或部分**控制权**时；**负债**——不再存在全部或部分**现时义务**时。

**⚠️易错**：新旧确认条件对比——**新框架强调"有用性"**，不再要求"很可能 + 可靠计量"。

## 1.7 计量（CF Ch6）—— ⭐必考

### 1.7.1 历史成本（Historical cost）

* 资产：取得或创建时发生的成本（含支付对价 + 交易成本）；负债：发生时收到的对价价值。

| ✅ 优点                | ❌ 局限                               |
| ------------------- | ---------------------------------- |
|  客观、可靠（可验证）、被操纵可能性小 | 价值**过时**；**通胀期间高估利润**（Sales↑而成本偏低） |

### 1.7.2 现行价值（Current value，四种）

| **计量基础**                  | **定义**                                  | **假设视角**   |
| ------------------------- | --------------------------------------- | ---------- |
| **公允价值 Fair value**       | 计量日**市场参与者**间**有序交易**中，出售资产收到/转移负债支付的价格 | **市场**     |
| **使用价值 Value in use**     | 主体预期从资产**使用及最终处置**取得的现金流（或其他经济利益）**现值** | **主体特定** ✅ |
| **履行价值 Fulfilment value** | 主体履行负债时预期须转移的现金/经济资源的**现值**             | **主体特定** ✅ |
| **现行成本 Current cost**     | 计量日购买**同等资产**的成本                        | **市场**     |

## 1.8 列报与披露（CF Ch7）

* 有效列报强调**目标与原则而非规则**；通过**归并相似项目、分离不同项目**对信息分类。

## 1.9 资本与资本保全（CF Ch8）

* 区分**财务资本保全**与**实物资本保全**（概述性内容，选择题辨识即可）。

| ----- | ---------------- | --------------------------------------------------------- |

| 2     | Materiality 判定依据 | 基于 **nature 或 magnitude，或两者**，非仅性质                        |
| 3     | 可比性 = 统一性？       | ✗；可比性允许合理差异，变更须披露并按 IAS 8 处理                              |

# 第2章 监管框架（The Regulatory Framework）

> 考试形式：Section A 选择题。一句话重点：会计准则**不是**完整监管框架；IFRS 原则导向、US GAAP 规则导向；认准各机构角色与 due process 顺序。

## 2.1 为什么需要监管框架

* 目的：确保实现**相关且可靠**的财务报告，满足**股东及其他使用者**需求；若无监管，公司可自由选择披露 → **丧失可比性**。
* **IFRS 相对国家准则**：
  * ✅ 优势：财务报表**全球可比**；**跨境投资与上市**更容易；减少信息不对称、提升**透明度**。
  * ❌ 劣势：**转换成本（cost of transition）高**；IFRS 为**原则导向**，需较多专业判断；不同国家法律/文化差异致**执行不一致**。
* IFRS 的三大好处（benefits of IFRS）：**透明度 transparency、问责/受托责任 accountability、效率 efficiency**。

**⚠️易错**：**会计准则本身不是完整的监管框架**（Accounting standards on their own are NOT a complete regulatory framework）。完整监管还须：**法律（公司法、证券法等）+ 市场规则（上市/交易所规则）**。

## 2.2 原则导向 vs 规则导向 —— ⭐核心

| **维度** | **原则导向（IFRS）**                   | **规则导向（如 US GAAP）** |
| ------ | -------------------------------- | ------------------- |
| 编写方式   | 基于**要素定义**与 CF 的确认计量原则，覆盖多情景     | 针对**特定情景**的具体规则     |
| 专业判断   | ✅ 需大量 **professional judgement** | 较少，按规则操作            |
| 灵活性    | 高                                | 低                   |
| 诉讼保护   | 较低（诉讼风险较高）                       | ✅ **在诉讼中提供更多保护**    |
| 制定方式   | 避免"灭火式（fire-fighting）"           | 易出现"灭火式"            |

* **能否互补**：可以**互补**——原则导向提供概念框架，规则导向提供操作指引；实际中 IFRS 也越来越多包含应用指引。
* 英国例：原则导向=《原则声明》+ IFRS；规则导向=《公司法》+ 证券交易所规则。

**📌考点**：规则导向的**可能优势** = "在发生诉讼时为会计师提供更多保护"；"鼓励专业判断""避免灭火式""确保准则互不冲突"都是**原则导向**的优势。

## 2.3 IFRS Foundation 与各机构

* **IFRS Foundation（IFRS 基金会）**：IASB 的**监督机构（supervisory body）**；负责**治理（governance）**&#x5E76;确保各机构获得**充足资金**；**不直接制定准则**。其目标：①制定高质量、可理解且可执行的**全球统一**准则；②**推广**其使用与严格应用；③推动各国准则与 IFRS 的**趋同（convergence）**。
* **IASB（国际会计准则理事会）**：**独立的准则制定者**，**唯一**负责发布 **IFRSs** 并推动全球趋同；成员来自多国、代表不同专业背景。
* **IFRS Interpretations Committee（IFRS IC，解释委员会）**：对 IFRS 应用出现**分歧**的事项发布**快速指引（rapid guidance）**，**须经 IASB 批准**。职责：①解释 IFRS、对未涉及问题提供及时指引（如新兴议题）；②配合 IASB 推动各国准则与 IFRS 趋同；③**及时审议**新发现但现有 IFRS 未涉及的财务报告问题。
* **ISSB（国际可持续准则理事会）**：2021 年 11 月 IFRS 基金会宣布设立；制定**高质量可持续披露的全球基线（global baseline）**，满足投资者信息需求。
* **IFRS Advisory Council（IFRS AC，咨询委员会）**：就议程/议题向 IASB（Board）或受托人（Trustees）**提供建议**。

**⚠️易错**：

* 把"制定/推广/趋同"三大目标误记到 **IASB** 名下（**教材归属为 IFRS Foundation 的目标**）。
* IFRS IC 的指引**必须经 IASB 批准**。

## 2.4 标准制定流程（due process）—— ⭐高频

| **步骤** | **名称**               | **说明**                                                                                                             |
| ------ | -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Step 1 | Issues paper / 咨询委员会 | 项目早期 IASB 可设立**咨询委员会**就问题提供建议（此前先咨询 **IFRS AC** 是否列入议程）；研究各国做法                                                     |
| Step 2 | Discussion Paper     | **可能**发布以征求公众意见（**非强制**）                                                                                           |
| Step 3 | Exposure Draft       | 发布**征求意见稿**征求公众意见                                                                                                  |
| Step 4 | IFRS                 | 审阅意见并修订后由 IASB **多数通过（majority vote）**；最终准则含**结论基础（basis for conclusions）**&#x53CA;任何**反对意见（dissenting opinions）** |

* **各国准则制定者**：参与 Discussion Paper / Exposure Draft 的制定；IASB 在地方最终决策中给予其**一定自主权**；合作推动**趋同**。

## 2.5 可持续报告（Sustainability reporting）—— 新考点

* 投资者关注主体对环境的**影响（impacts）**&#x4E0E;对可持续因素的**依赖（dependencies）**；可包含于**战略报告**或**单独可持续报告**。
* **不属于财务报表的一部分，也不在 IFRS 会计准则范围内**（⚠️）。
* **ISSB**：提供可持续披露的**全面全球基线（global baseline）**；提高 ESG 报告的**可靠性**与**可比性**。
* ISSB 于 **2023 年 6 月**发布首批两项准则：
  * **IFRS S1**：可持续相关财务信息披露的**一般要求**
  * **IFRS S2**：**气候相关**披露
* **IFRS S1 四大披露支柱**：**治理 Governance、战略 Strategy、风险管理 Risk management、指标与目标 Metrics and targets**。
* 底层原则：主体在**短、中、长期产生现金流的能力**，与其同利益相关者、社会、经济和自然环境之间的相互作用**密不可分**

## 2.6 非营利与公共部门主体（Not-for-profit & public sector entities）—— 补漏重点

* **不以盈利为目标**，但仍须核算其**收入与成本**。
* 绩效考核三维：**经济性 Economy、效率性 Efficiency、有效性 Effectiveness**。

**📌考点**：哪些比率**不适用**于非营利主体——以**盈利**为导向的比率不适用，典型为 **ROCE（资本运用回报率）** 与 **Gross profit %（毛利率）**；而流动性、营运、杠杆类比率（如速动比率、存货天数、Gearing）仍可适用。

## 2.7 易错点速记（Ch2）

| **#** | **易错点**              | **正确理解**                                                                 |
| ----- | -------------------- | ------------------------------------------------------------------------ |
| 1     | 会计准则 = 完整监管框架？       | ✗；还须**法律 + 市场规则**补充                                                      |

# 第3章 财务报表列报（Presentation of Financial Statements: IAS 1 / IFRS 18）

> 考试形式：选择题多考"会计政策变更 vs 会计估计变更 vs 前期差错""可比性""权益/股利""持续经营"；大题考列报格式与分录。一句话重点：**IFRS 18 强制两个小计（Operating profit、PBFI）+ 经营/投资/融资三大类别**；IAS 1 定报表构成与基本特征。

## 3.1 财务报表的构成与基本特征（IAS 1）

* 完整一套财务报表（complete set of financial statements）：
  * 财务状况表 SFP
  * 利润表 SOPL + 其他综合收益表 SOCI（可合并为一张"财务业绩表"）
  * 权益变动表 SOCIE
  * 现金流量表 SOCF
  * 附注（含会计政策、比较信息）
* 基本特征（general features）：`fair presentation 公允列报`、`going concern 持续经营`、`accrual basis 权责发生制`（现金流量表除外）、`materiality & aggregation 重要性/汇总`、`不得抵销 offsetting（除非准则允许）`、`至少每年一次`、`comparative information 比较信息`、`会计政策一致性 consistency`。

**📌考点**：完整一套报表的 5 张表 + 附注；`accrual basis` 只排除现金流量表。

**⚠️易错**：仅**重要（material）**&#x4FE1;息才需列报/披露——不重要的信息无需列示。

## 3.2 财务状况表（SFP）

* 按**流动 / 非流动**（current / non-current）分类列报。
* **须在表内强制单独列报的行项目**（IAS 1.54，IFRS 18 大体沿用）：
  * 资产：不动产厂房设备 PPE、投资性房地产、无形资产、金融资产、权益法核算的投资、生物资产、存货、贸易及其他应收款、现金及现金等价物、分类为持有待售的资产。
  * 权益与负债：贸易及其他应付款、准备 provisions、金融负债、当期税负债、递延税负债、持有待售负债、非控股权益 NCI、已发行股本、各项准备金 reserves。
* 典型分组：权益（股本、股本溢价、留存收益、重估盈余、其他权益成分）；非流动负债（长期借款、递延税）；流动负债（贸易应付款）。
* **备抵科目（累计折旧、减值准备等）不单独列示**，仅作相关资产抵减或附注披露。

## 3.3 财务业绩表（IFRS 18：P/L + OCI）—— ⭐ 最高频

### 利润表结构（强制格式）

```
Revenue 收入
− Cost of sales 销售成本
= Gross profit 毛利
± Other operating income / (expense) 其他经营收入/费用
− Distribution / Selling expenses 销售(分销)费用
− R&D expenses 研发费用
− Administrative expenses 管理费用
= Operating profit 营业利润        ← 强制小计 1
± 投资类别损益（见下）
= Profit before financing and income taxes (PBFI)   ← 强制小计 2
− Financing costs 融资成本（借款及其他负债利息、租赁负债与准备利息）
+/− Share of profit of associate 联营损益（属投资类别，在 PBFI 之上）
= Profit before tax 税前利润（自愿小计）
− Income tax expense 所得税
= Profit for the year 本年利润
+ Other comprehensive income 其他综合收益
= Total comprehensive income 综合收益总额
```

* **两个强制小计**：`Operating profit`（营业利润）与 `PBFI`（融资和所得税前利润）。口诀：**营业利润 + PBFI**。
* **三大类别（categories）**：
  * **经营 Operating**：主营业务成果；**未归入其他类别的收支**（兜底）；如 PPE、贸易应收款。
  * **投资 Investing**：**联营企业成果**；**现金及现金等价物成果**；**独立产生回报的资产**——债务/权益投资、投资性房地产、该投资性房地产产生的租金应收款。
  * **融资 Financing**：**筹资形成的负债**产生的收入/费用；**其他负债的利息费用**——租赁负债、具有延长付款期限的贸易应付款、合同负债、长期准备金折现的转回。

### 特殊分类规则

* **处置/持有待售**：对资产终止确认、或其被分类为持有待售（含 IFRS 5 减值）及持有待售期间后续计量产生的收支，**归入与该资产终止确认前相同的类别**（IFRS 18.B60）。
* **汇兑差额 FX**：归入**产生该差额的项目所在的同一类别**（除非成本不合理）。→ 融资相关负债的汇兑差额入**融资类别**；税务余额的汇兑差额入**所得税类别**。

### OCI 与 P/L 的划分（高频对比）

| **计入 OCI（other comprehensive income）** | **计入 P/L（profit or loss）** |
| -------------------------------------- | -------------------------- |
| PPE 重估利得 revaluation surplus           | **公允价值模式投资性房地产**公允价值变动     |
| FVOCI 权益工具公允价值变动                       | FVTPL 金融资产公允价值变动           |
| 设定受益计划精算损益                             | 处置损益（资产处置利得/损失）            |
| 外币报表折算差额                               | —                          |

**⚠️易错**：

* **PPE 重估 → OCI；投资性房地产公允价值模式 → P/L**（最高频区分点）。
* **租赁负债利息**属**融资类别**（在 PBFI 之后），**漏计**是常见错误。
* **联营企业损益属投资类别**，列在 **Operating profit 之后、PBFI 之前**（**不是**放在融资/税前利润处）。
* 权益工具投资的股利收入、投资收益须按类别正确归类。

## 3.4 权益变动表（SOCIE）

* 主要行项目：期初余额 → 会计政策变更影响 → **重述后期初余额** → 综合收益总额（分别在留存收益、重估盈余等列示） → 重估盈余转入留存收益 → 已付股利 → 发行股本 → 期末余额。
* 重估盈余转入留存收益为权益内部结转，**合计为 0**；股利作为股东交易**直接冲减权益**。

**📌考点**：SOCIE 各行的列示顺序与列向；本期综合收益在各权益成分间的分配。

**⚠️易错**：

* 会计政策变更需**单独一行**列示并重述期初余额。
* 首次应用新准则**不是**会计政策变更（须区分）。

## 3.5 会计政策、估计变更与前期差错（IAS 8）—— 列报相关

> 完整内容见 **第 11 章 11.1**。

* **政策变更**：**追溯**（重述比较数 + 调整期初留存收益），在**权益变动表单独一行**列示。
* **估计变更**：**未来适用**，不追溯、不重述比较数。
* **前期差错**：**追溯重述**。
* ⚠️ 折旧方法/年限/残值变更=**估计变更**；存货 **FIFO→AVCO**=**政策变更**；"合并调整""现金购买改融资租赁"**不是**政策变更。

## 3.6 持续经营、比较信息与可比性

* **持续经营 going concern**：报表按持续经营基础编制，除非管理层意图清算或停止交易、无其他现实选择。
* **比较信息 comparative information**：所有金额均需提供**上期比较数**。
* **可比性 comparability**（enhancing characteristic）：

**📌考点**：什么行为能提高/不提高可比性；持续经营受破坏时的处理。

**⚠️易错**：

* **不**提高可比性：将主体现行会计政策**应用于以前从未发生的新类型交易**（"新交易无可比性"问题）。
* 会计政策变更后**重述前一年报表**、禁止随意变更政策、披露**终止经营**——都**有助于**可比性。
* **持续经营被破坏**：报告期后发生的、使公司无法继续经营的事项（如无保险的火灾），即使属非调整事项，也**导致报表不能再以持续经营基础编制**（这是非调整事项影响持续经营的**例外**）。
* 报告期日**已存在**情况的新证据 → 调整事项（如客户破产确认应收减值、诉讼结案确认期末义务）；报告期日**之后新出现**的情况 → 非调整事项（如期末股利宣告、收购完成）。

# 第4章 非流动资产（Non-current Assets：IAS 16 / IAS 40 / IAS 36 / IAS 23 / IAS 20 / IFRS 5）

> 考试形式：Section A 单选 + Section B 案例计算题（重估模型分录、组件折旧、CGU 减值分摊、持有待售计量、政府补助列报是高频计算点）。
> 一句话重点：**同一资产在不同准则下"增值/减值去哪"是本章命门**——IAS 16 重估增值→OCI(RS)、IAS 40 公允价值变动→P/L、IAS 36 减值先冲 RS 再进 P/L、借款费用和政府补助要判断"资产化还是收益化"。

***

## 4.1 IAS 16 不动产、厂场和设备（Property, Plant and Equipment, PPE）⭐重中之重

### 4.1.1 定义与确认

* **定义**：**有形资产（tangible）**，须同时满足：①为生产/供应商品或服务、出租或行政目的持有（business use）；②预期**超过一个期间**使用（>12个月）。
* **确认条件**（初始成本与后续支出均适用）：①相关未来经济利益**很可能**流入；②成本能**可靠计量**。
* **单独组件（separate components）**：寿命/折旧率不同的组件应作为**单独资产**分别资本化、分别折旧。

**📌考点**：组件折旧（如土地/建筑结构/空调、飞机机身/引擎/内饰分别计提）是高频计算题；土地不计提折旧。

**⚠️易错**：不能把各组件成本加总后再统一折旧；必须**分组件**计算各自折旧。

### 4.1.2 初始计量——成本构成

✅ **计入成本**：购买价（扣商业折扣/回扣）、进口关税及**不可退还**购买税费、直接可归属成本（场地准备、初始运输装卸、**安装成本**、**测试成本**、专业服务费、生产间接费用、**借款费用**）、**弃置费用**（拆卸/移除/恢复场地的初始估计不可避免成本）。

❌ **不计入成本（费用化）**：行政管理及一般间接费用、**培训员工**费用、开办费/初始经营亏损（达到使用状态后发生）、异常成本（浪费的材料/人工/停工）。

* 测试成本中**测试期间产出的销售收入计入 P/L**（2020年5月修订）。

**📌考点**：运输费、安装费、测试费→资本化；维护协议、培训费→费用化。

**⚠️易错**：测试期销售产成品收入进 P/L，不能冲减资产成本。

**⚠️易错**：折旧通常计入 P/L；但资产**用于自建自用资产**（如自建厂房、自建 held-for-use 物业）时，其折旧应**资本化计入该资产成本**。安全设施/设备/检查支出必须作为直接成本资本化。

### 4.1.3 后续支出（subsequent expenditure）

* 判断标准：**增加**获利能力（↑earning capacity）→**资本化**；**维持**现有获利能力→**费用化**（P/L）。
* 具体：更换/更新组件（须**同时终止确认旧组件 CA**）→资本化；超出原定性能标准的改进→资本化；**重大检修/大修**（构成资产继续使用必要条件）→作为**单独组件**资本化并单独折旧；**日常维修、检修、大修**→通常费用化。

**⚠️易错**：更换组件时必须**终止确认被替换组件的账面价值**，不能只加不减。

### 4.1.4 折旧（Depreciation）

* 应折旧金额在寿命内**系统分摊**；方法应反映经济利益消耗模式。
* 方法：直线法（成本−残值)/寿命；余额递减法（期初 CA × 固定比率%）。
* 起始：**资产达到可供使用状态之日（available for use）** 起提；**即使资产闲置仍须继续计提**。
* **土地**寿命无限，**不计提折旧**。
* 残值、寿命、折旧方法须**至少每年末复核**；其变更属**会计估计变更**（非会计政策变更，未来适用）。

**📌考点**：年内购置/处置须**按时间分摊**（time apportionment）。

**⚠️易错**：改变折旧方法/寿命/残值→会计估计变更，不是政策变更，不追溯。

### 4.1.5 后续计量模型

**① 成本模型**：CA = Cost − 累计折旧 − 减值。

**② 重估模型**：CA = 公允价值 − 累计折旧 − 减值。

* 重估**足够规律**（确保 CA 与 FV 无重大差异即可，**不要求每年**）；FA 能**可靠计量**时方可采用；**整类（whole class）资产必须同时重估**（或滚动重估）。

**📌考点**：IAS 16 允许选用重估模型，但只要求"同一**类别**"整体重估，不是"全部非流动资产"、也不是"所有类型资产"。

**⚠️易错**：重估后**仍须折旧**（按重估后 CA ÷ 剩余寿命）；"每年重估就不用折旧"是错的。

### 4.1.6 重估的会计处理 ⭐⭐计算核心

**增值（Increase）**

| **情形**          | **处理（分录）**                                        |
| --------------- | ------------------------------------------------- |
| 此前无减值，或曾减值已转回   | Dr PPE / Cr **OCI→重估盈余(RS)**                      |
| 此前同一资产减值已计入 P/L | 先 Dr PPE / Cr **P/L**（以恢复原减值金额为限），剩余部分 Cr OCI(RS) |

**减值（Decrease）**

| **情形**    | **处理（分录）**                        |
| --------- | --------------------------------- |
| 此前有 RS 余额 | 先 Dr **RS**（冲减至零为限），剩余 Dr **P/L** |
| 此前无 RS    | Dr **P/L**（费用）                    |

* **核心规律**：增值→OCI(RS)↑；减值→费用↓；减值**先冲同一资产已有 RS**，增值**先转回同一资产先前计入 P/L 的减值**。
* **重估后折旧**：按新 CA 与剩余寿命重算，折旧额变化。
* **超额折旧结转（⚠️）**：超额折旧 = 按重估金额折旧 − 按原始成本折旧；**可选**从 RS 转入留存收益（Dr RS / Cr RE），**不通过 P/L**；**仅当题目明确公司政策时才做**。
* **处置时**：处置资产账上剩余 RS 可作**权益内部转移**转入留存收益（Dr RS / Cr RE）。

**📌考点**：分步计算——先算重估前的折旧，再算重估后按新 CA/剩余寿命的折旧；注意重估盈余余额随超额折旧转出而减少。

**⚠️易错**：超额折旧结转 **NOT through P/L**；是"可选择"而非"每年必须"。

**⚠️易错**：**首次采用重估模型**时，同一类资产中单个资产增值→OCI、单个资产减值→P/L，**不得相互抵销**（须按单一项资产分别处理：增值部分计入 RS，减值部分计入 P/L）。

### 4.1.7 处置（Disposal）

* 资产**永久退出使用/出售/报废且无未来经济利益**时终止确认。
* 处置利得/损失 = 净处置收入 − 账面金额（CA）；计入 **P/L**（不作为收入）。

**⚠️易错**：处置利得是**净额**，直接进 P/L（可列作其他收入或冲减行政/营业费用），不是营业收入。

***

## 4.2 IAS 40 投资性房地产（Investment Property）

### 4.2.1 定义与计量

* **定义**：为**赚取租金**和/或**资本增值**（而非自用或正常经营销售）持有的房地产。**未确定未来用途的土地**视为以资本增值为目的→投资性房地产。
* **初始计量**：成本，**含交易成本**。
* **后续计量**（二选一）：
  * **公允价值模型（FV model）**：每年年末重估至 FV；公允价值变动**直接计入 P/L**；**不计提折旧**。
  * **成本模型（Cost model）**：同 IAS 16 成本模型，**须计提折旧**。
  * 若 FV 无法可靠计量→必须采用成本模型。

### 4.2.2 IAS 40 FV 模型 ⚔ IAS 16 重估模型（最高频区分点）

| **对比项** | **IAS 40 — FV model** | **IAS 16 — Revaluation model** |
| ------- | --------------------- | ------------------------------ |
| 重估频率    | **必须每年**              | 足够规律即可，**不必每年**                |
| 增值处理    | **→ P/L**             | **→ OCI→RS**                   |
| 减值处理    | → P/L                 | 先冲 RS，超出部分→P/L                 |
| 折旧      | **不计提**               | **仍须计提**                       |

### 4.2.3 用途转换（Transfer）

* 资产用途变化时，**必须先重估该资产，再改变分类**。转换日差额去向：
  * **PPE → 投资性房地产（FV）**：增值→**OCI(RS)**；减值→P/L（除非转回先前重估）。
  * **投资性房地产（FV）→ PPE**：差额直接计入 **P/L**（**不走 OCI**）。
  * **存货 → 投资性房地产（FV）**：差额→**P/L**。
* 转换完成后，后续每年公允价值变动→P/L。
* **处置**：利得/损失 = 净处置收入 − CA，计入 P/L。

**⚠️易错**：方向决定去向——PPE→IP 是 OCI，IP(FV)→PPE 是 P/L，切勿混。

***

## 4.3 IAS 36 资产减值（Impairment of Assets）⭐高频

### 4.3.1 适用范围与关键定义

* 适用于**几乎所有非流动资产**：PPE（成本&重估模型）、无形资产（成本&重估模型）、**成本模型**的投资性房地产、**商誉**、对子公司/联营/合营的投资。
* **不适用**：存货（用 IAS 2 成本与 NRV 孰低）、以 FV 计量的投资性房地产、金融资产等。
* **减值**：CA > **可收回金额（RA）**。**RA = max(FV − 处置费用(FV−CTS), 使用价值(VIU))**。
  * VIU = 预期未来净现金流量的**现值**。

### 4.3.2 减值迹象（Indicators）

| **外部来源**                                 | **内部来源**            |
| ---------------------------------------- | ------------------- |
| 资产市价意外大幅下跌                               | 资产**过时或损坏**         |
| 技术/市场/经济/法律环境重大不利变化                      | 资产**使用方式**发生或即将不利变化 |
| 利率/市场回报率**上升**→折现率↑→VIU↓                 | 内部报告表明经济绩效**低于预期**  |
| 主体净资产 CA > **市值（market capitalisation）** | —                   |

**必须每年做减值测试（无论有无迹象）**：①**商誉**；②**寿命不确定的无形资产**；③**尚未可供使用的无形资产**。

**⚠️易错**：减值迹象的"净资产 CA > 市值"应表述为**账面净资产高于市值**；"账面净资产低于市值"**不是**减值迹象。

**⚠️易错**：结转未完成/满足确认标准但**尚未可供使用**的无形资产（如未完成的软件开发）须**每年**减值测试。

**⚠️易错**：存货按 NRV、不适用 IAS 36，且 NRV>CA 时无减值。

### 4.3.3 减值损失的会计处理

| **计量基础** | **处理**                        |
| -------- | ----------------------------- |
| 成本模型     | Dr **P/L（费用）** / Cr 资产        |
| 重估模型     | ①先冲**同一资产的 RS**；②剩余部分→**P/L** |

### 4.3.4 现金产出单元（CGU）

* **定义**：能产生**基本独立于其他资产或资产组**的现金流入的**最小可辨认资产组**。
* 无法计算单项资产 VIU 时，改用其所属 CGU 的 RA。
* CGU 认定应**各期一致**（同类型资产）；CGU 的 CA 与 RA 应**基础一致**。
* **减值损失分摊顺序**：
  1. 先冲减**已明确发生减值的特定资产**（specific assets known to be impaired）；
  2. 再冲减分摊至该 CGU 的**商誉**；
  3. 最后按 CA 比例分摊至**其他非流动资产**。
* **下限（floor）**：任一资产的 CA **不得减至低于**三者中**最高者**：**max(FV−CTS, VIU, 0)**；超过下限的减值额应在合格资产间继续分摊。
* 净流动资产按 RA 计量，一般不参与分摊。

**📌考点**：典型题——CGU 含"已毁损机器 + 其他设备 + 商誉 + 净流动资产"，减值额先冲**已毁损资产**、再冲商誉、再按比例冲其他设备（须扣掉已毁损部分）。

**⚠️易错**：分摊下限是 FV−CTS、VIU、零的**最高者**（教材简化为仅 FV−CTS，标准为三者最高者）。

### 4.3.5 减值损失的转回（Reversal）

| **资产类型** | **能否转回**                                   |
| -------- | ------------------------------------------ |
| 除商誉外的资产  | ✅ **可以**；但转回后 CA **不得超过**"假设从未减值时的已折旧历史成本" |
| **商誉**   | ❌ **不得转回**                                 |

* 转回通常计入 P/L；若为重估资产，其转回按重估模型处理（相当于增值→OCI/RS，但以先恢复原减值计入 P/L 部分为限）。

**⚠️易错**：商誉减值**永久不可转回**；其他资产可转回但有上限。

***

## 4.4 IAS 23 借款费用（Borrowing Costs）

### 4.4.1 定义与合格资产

* 所有**可直接归属于**合格资产的借款费用**必须资本化**；其他借款费用费用化。
* **合格资产（qualifying asset）**：需要**相当长时间（substantial period of time）**&#x624D;能达到预定可使用/可销售状态的资产（如大型厂房、发电厂、船舶）。

### 4.4.2 利率计算

| **借款类型**                | **可资本化金额**                   |
| ----------------------- | ---------------------------- |
| **特定借款**（专门为该资产借入）      | 实际借款成本 − 该借款**临时投资收入**（配比原则） |
| **一般借款**（从一般借款中支出的项目资金） | 加权平均支出 × **加权平均利率**（不含专门借款）  |

### 4.4.3 资本化期间

* **开始**（须同时满足）：①借款费用已发生；②为使资产达到预定状态的活动**正在进行**；③资产**支出已发生**。
* **暂停**：**较长期间内暂停积极开发活动**（extended period）时暂停资本化。
* **停止**：为使资产达到预定状态所需的**几乎所有活动完成**，或借款费用不再发生。

**📌考点**：自建/扩建资产的资本化计算——把可直接归属的借款费用加进资产成本（如"建造支出 + 可资本化利息"）。

**⚠️易错**：只有**长期停工**才暂停资本化，非所有停工都暂停；仅资本化"期间内"的借款费用。

***

## 4.5 IAS 20 政府补助（Government Grants）

### 4.5.1 定义、分类与确认

* **定义**：政府以资源转移形式提供的援助，以换取主体过去/未来遵守特定条件。
* **分类**：与**资产**相关的补助（主要条件是购买/建造/取得长期资产）；与**收益**相关的补助（其余）。
* **确认**：①**合理保证**主体将遵守附加条件；②**合理保证**补助将收到。

**⚠️易错**：政府提供的**免费市场咨询**等援助**不属于**政府补助定义。

### 4.5.2 与资产相关的补助（两法）

| **方法**                              | **处理**                                        |
| ----------------------------------- | --------------------------------------------- |
| **Method 1 递延收益（Deferred income）**  | 确认为**负债（递延收益）**；在资产寿命内按与折旧相同基础系统转入 P/L（作其他收入） |
| **Method 2 冲减资产成本（Deduct from CA）** | 直接从资产成本扣除→减少未来折旧，间接影响 P/L                     |

* **列报**：递延收益须拆分为**流动负债**（未来12个月内释放部分）与**非流动负债**（其余）。
* **需偿还时**：
  * Method 1：先冲减尚未摊销的递延收益，超出部分确认**费用**。
  * Method 2：**增加资产 CA**（未来按剩余寿命计提额外折旧）。

### 4.5.3 与收益相关的补助（两法）

* 方法一：作为**其他收入**单独列报 P/L；方法二：从**相关费用**中扣除。
* 按补助所补偿的相关成本**所属期间**系统性确认。
* **需偿还时**：先冲减未摊销递延收益，超出部分确认为费用。

**📌考点**：附注"三件套"——与资产相关补助要能算出：①递延收益流动/非流动金额；②资产 CA（Deduct 法）；③P/L 中的净影响（折旧费用 − 转入的其他收入）。

**📌考点**：有条件补助——只有在**条件已满足的期间**才确认收益（如"须租用满1年"则仅确认已满足月份）。

**⚠️易错**：补助**按已满足条件的期间**分期确认，不能一次性全额计入当期收入。

**⚠️易错**：因未满足条件而**需偿还**以前期间已确认的补助收益时——**冲回以前已确认收益、减少当期利润**，**不**作为前期差错追溯调整（非 prior period adjustment）。

* **培训费相关补助**：员工培训不满足资产定义（企业**不控制**员工）→ 培训费全额费用化；相关补助若"几乎确定（virtually certain）"可收回，可予以冲减。

***

## 4.6 IFRS 5 持有待售与终止经营（NCA Held for Sale & Discontinued Operations）

### 4.6.1 持有待售（Held for Sale, HFS）

* **分类条件（须同时满足）**：①资产以**当前状态可立即出售**；②出售**极可能发生（highly probable）**：管理层已**承诺**出售计划、已有**积极寻找买方**方案、以**合理价格**营销、预计**12个月内**完成、计划**不太可能被撤销/重大改变**。
* **计量**：= **min(CA, FV − CTS)**。
  * FV−CTS > CA：不调整（**不得调增至 FV**）。
  * FV−CTS \< CA：确认**减值损失**至 P/L。
  * 后续 FV−CTS 下降：继续确认减值；**回升可转回，但不超过累计已确认减值**。
* **分类当日起停止计提折旧/摊销**（分类日之前仍须计提）。
* **列报**：在 SOFP **流动资产**项下**单独列示**。

**📌考点**：先算分类日前折旧→得分类日 CA→与 FV−CTS 孰低；分类后不再折旧，年末 FV−CTS 即使下降，只要仍高于 CA 就不再调整。

**⚠️易错**：分类为 HFS 前的重估资产——先按重估模型处理（折旧入 P/L、重估增值入 OCI），再按 FV−CTS 计量，**再分类减值**计入 P/L；两项都影响 P/L（折旧 + 分类减值）。

**⚠️易错**：以下情形**不满足 HFS**：①土地尚未拆除、不能"以当前状态立即出售"；②新法规使该资产销售变得不合法→出售非"极可能"；③以**远高于已收到报价**的价格营销→价格不合理。

### 4.6.2 终止经营（Discontinued Operation）

* **定义**：主体的一个**组成部分**（已处置或分类为 HFS），且满足其一：①代表**单独的主要业务线或经营地区**；②是处置该业务线的**单一协调计划**的一部分；③是**专为转售而收购的子公司**。
* **列报**（SPLOCI 表内**单一金额**，列于持续经营之后）：

```
Profit from continuing operations            X
Profit/(Loss) from discontinued operations   X/(X)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Profit for the year                          X
Other comprehensive income                   X
Total comprehensive income                   X
```

* 该单一金额 = ①终止经营**税后损益** + ②按 FV−CTS 计量或处置确认的**税后利得/损失**。附注需进一步分析：收入、费用、税前利润、所得税等。
* **SOFP**：终止经营的**资产**在流动资产中、**负债**在流动负债中**单独列示**。

**📌考点**：终止经营的"员工成本"须按**配比原则**归属——保留并调配到**其他子公司**的员工成本，即使同年发生，也不计入本次关厂费用。

**⚠️易错**：题目问"relating to PPE"时只取 **Plant（厂房设备）** 数据；**Factory（工厂总称）** 含无形资产/存货等，是干扰信息，先读 Requirements 再答。

***

## 4.7 本章易错点速查（⚠️考前必看）

1. 运输/安装成本→**资本化**；培训、维护→**费用化**。
2. 组件折旧须**分组件**计提，不能合计后再折旧。
3. 重估增值：IAS 16→**OCI/RS**；IAS 40 FV model→**P/L**。
4. 重估后**仍需折旧**（按新 CA÷剩余寿命）。
5. 超额折旧从 RS 转 RE **不通过 P/L**，且**可选择**。
6. HFS **停止**折旧/摊销；分类日前仍须提。
7. 开发支出满足条件**必须资本化**（非可选）。
8. **商誉减值不可转回**；其他资产可转回（有上限）。
9. IAS 40 FV 增值入 P/L 与 IAS 16 重估增值入 OCI 是**最高频区分点**。
10. CGU 分摊顺序：**特定已减值资产→商誉→其他非流动资产**；单项资产下限 = max(FV−CTS, VIU, 0)。
11. 政府补助两法列报：Deferred income→**负债**；Deduct from CA→减少**资产 CA**。
12. 借款费用**长期停工**才暂停资本化。
13. 重估只要求**整类**资产，不是全部 NCA。
14. 首次采用重估模型，同类中单项增值与减值**不能相互抵销**。
15. 折旧一般入 P/L，但用于**自建自用资产**的折旧应资本化。

# 第5章 无形资产与商誉（Intangible Assets & Goodwill：IAS 38）

> 考试形式：Section A 单选 + Section B 计算题（研发支出划分、资本化/费用化判断、摊销起点、商誉不摊销等）。
> 一句话重点：**"外购的（基本）都能确认，自创的除达到资本化条件的开发支出外基本都不能确认"**；商誉**不摊销、每年减值测试、减值不可转回**。

***

## 5.1 定义与确认

* **定义**：**可辨认的非货币性资产，无实物形态**，须同时满足：
  1. **可辨认（identifiable）**——满足其一：**可分离**（能单独出售/转让/许可/出租/交换）；或**源自合同/法律权利**。
  2. 由主体**控制**。
  3. 预期带来**未来经济利益**。
* **确认条件**（同 PPE）：①未来经济利益**很可能**流入；②成本能**可靠计量**。

## 5.2 哪些不能确认为无形资产（⚠️极高频）

以下内部产生/不符合定义的支出**必须费用化→P/L**：

* 内部产生的**品牌（brands）**、**报刊刊头（mastheads）**、**出版标题（publishing titles）**、**客户名单（customer lists）**、**开办费（start-up）**、**培训支出（training）**、**广告促销费（advertising & promotion）**、**搬迁重组费（relocation & reorganisation）**、**研究支出（research）**。

**📌考点**：外购品牌/许可证（合同或法律权利、可分离）可确认为 IA；内部产生品牌、客户名单不可确认。

**⚠️易错**：**员工培训成本永远费用化**（员工不可控，不符合资产定义），即使预期带来更高收入。

**⚠️易错**：**样机/模型（prototype）** 虽有实物形态，但其**技术**才是真正的资产——研究阶段费用化，开发阶段满足条件后资本化为 IA（不是 PPE）。

**⚠️易错**：为商标建造的**混凝土模型/实物标志**有实物形态→属于 **PPE（有形资产）**，不是 IA。

## 5.3 内部产生的无形资产——研究 vs 开发 ⭐必考计算

* **研究阶段（Research）**：为获取新科学/技术知识进行的原创性计划调研→**全部费用化**（P/L）；即使项目最终成功也不得资本化。
* **开发阶段（Development）**——满足**全部6项条件**则**必须资本化**：
  1. **技术可行性**（完成并可供使用/销售）；
  2. 有**完成意图**并使用/销售；
  3. 有能力使用或销售；
  4. **未来经济利益很可能**（存在市场或内部用途）；
  5. **资源充足**（技术、财务等）；
  6. **支出能可靠计量**。
* **时点规则**：达到资本化条件**之前**发生的开发支出**全部费用化**，**不得追溯资本化**；已费用化的开发支出**不得再转回为资产（reinstatement prohibited）**。
* 资本化后：从**达到预定可使用状态（开始生产/可供使用）之日**起**摊销**至 P/L。

**📌考点**：研发计算题——按**时间轴**划分"研究期（费用化）／开发未达标期（费用化）／开发达标期（资本化）"，再对资本化额自可供使用日起摊销。

**⚠️易错**：摊销起点&#x662F;**"达到可供使用状态/开始生产"**，**不是"研发完成日"**。

**⚠️易错**：开发的新工艺**即使不增加销售收入**（如仅降低成本）仍可确认 IA，只要满足 6 项条件。

## 5.4 初始计量

| **来源**    | **计量基础**                             |
| --------- | ------------------------------------ |
| 单独外购      | **成本**（购买价 + 直接归属必要费用）               |
| 企业合并取得    | **公允价值**（购买日 FV）                     |
| 内部产生且满足条件 | **发生成本**（development costs incurred） |

* 企业合并中取得的**研发项目**即使含研究部分，也**按成本确认为资产**（后续支出按一般研发处理）。

**⚠️易错**：企业合并取得的研发项目（含研究阶段）按成本确认；但**内部**产生的研究支出仍须费用化。

## 5.5 后续计量

**① 成本模型**：CA = Cost − 累计摊销 − 减值。

**② 重估模型**：**仅当存在活跃市场（active market）时**方可采用（极少）。

| **对比项**  | **IAS 38 IA**  | **IAS 16 PPE** |
| -------- | -------------- | -------------- |
| 重估可用条件   | **仅当有活跃市场**（严） | FV 能可靠计量即可     |
| 活跃市场是否常见 | **罕见**（资产独特）   | 常见             |

* **摊销（Amortisation）**：
  * **有限寿命（finite）**：**系统摊销**，**始于达到可供使用状态**；方法应反映经济利益消耗模式（无法确定时用**直线法**，也可用**产量/销售单位法**）；**残值通常假定为零**（除非有活跃市场且第三方承诺购买）。
  * **不确定寿命（indefinite）**：**不摊销**，但须**每年减值测试**；每期末复核确保仍为不确定寿命。

**📌考点**：品牌/专利/商标因**每项资产独一无二**，其成交价不能证明另一项 FV→**不存在活跃市场→不得重估**，仍按成本摊销。

**⚠️易错**：无形资产重估比 PPE **更严格**——必须**存在活跃市场**（品牌/专利/商标通常无活跃市场）；"任何情况都不许重估"或"必须随 PPE 一起重估"都是错的。

**⚠️易错**：不确定寿命的 IA **不摊销**，但**每年减值测试**。

## 5.6 终止确认（Derecognition）

* (a) **处置**：确认处置利得/损失 = 处置收入 − CA，计入 P/L；
* (b) 预期**无未来经济利益**时终止确认。

***

## 5.7 商誉（Goodwill，IFRS 3）

### 5.7.1 定义与确认

* **商誉 = 转移的购买对价 + 少数股东权益(NCI)公允价值 − 被购买方可辨认净资产**的公允价值\*\*。
* **内部产生的商誉（internally generated goodwill）**：❌ **始终不得确认为资产**（不可辨认、成本不可靠计量）。
* **负商誉（Negative goodwill）**：先**复核**计量是否有误，复核后剩余部分计入 **P/L**。

### 5.7.2 后续计量

| **处理**         | **说明**         |
| -------------- | -------------- |
| ❌ **不摊销**      | 使用寿命不确定        |
| ✅ **每年减值测试**   | 无论有无减值迹象       |
| ❌ **减值损失不可转回** | 其他（非商誉）资产减值可转回 |

**📌考点**：商誉需**分摊到 CGU** 并进行每年减值测试；CGU 减值时商誉**先于**其他非流动资产被冲减。

**⚠️易错**：商誉**不摊销**、**减值不可转回**——这是与一般无形资产/PPE 的关键差别。

***

## 5.8 本章易错点速查（⚠️考前必看）

1. 内部产生**品牌/客户名单**→**不可确认**。
2. **研究支出**→**全部费用化**。
3. 达标前的开发支出**不得追溯资本化**；已费用化**不得转回**。
4. IA 重估**仅在活跃市场下**可用（品牌/专利/商标通常无）。
5. **样机**是辅助研发的支出（满足条件→资本化为 **IA**）。
6. **员工培训**支出→永远费用化。
7. 摊销起点是 **"可供使用/开始生产"**，不是研发完成日。
8. 不确定寿命 IA→**不摊销、每年减值测试**。
9. 商誉→**不摊销、每年减值测试、减值不可转回**。
10. **内部产生商誉**→**始终不确认**。
11. 外购**域名**具有可辨认性→可确认为 IA。
12. 新工艺**不增收但降本**仍可确认 IA（满足 6 条件即可）。
13. 研究阶段的**样机构建成本**→费用化；开发阶段达标后→资本化。
14. 商标的**混凝土实物模型**→属 PPE，不是 IA。
15. 摊销可用**产量/销售单位法**（若反映消耗模式），非必须直线法。

# 第6章 存货与生物资产（Inventory & Biological Assets：IAS 2 / IAS 41 / IFRS 13）

> 考试形式：以选择题（Section A/B）为主，高频考 NRV 计算、存货成本构成、IAS 41 适用范围与 FVLCTS 计量（偶有大题计算）。一句话重点：**存货 = 成本与 NRV 孰低（禁 LIFO、固定制造费用按正常产能分摊）；生物资产 = 初始及后续均按 FV−CTS、变动入损益；IFRS 13 = 输入值三级层级。**

## 6.1 IAS 2 存货（Inventories）

### 定义与范围

* 存货是满足以下之一（三者之一）的资产：
  * 在**正常经营过程中持有待售**（产成品）；
  * **处于生产过程**中（在产品 WIP）；
  * 以**原材料/物料**形式在生产或提供服务过程中消耗。
* 示例：Raw materials、Work in progress、Finished goods、购入待售商品。
* **不得计入存货成本（应费用化）**：非正常损耗（abnormal waste/losses）、非必要的仓储费、一般管理间接费用、销售/分销成本、利润。

**📌考点**：存货三种形态；哪些支出不得进存货成本。

**⚠️易错**：一般管理费用、分销成本、非正常损耗、利润不进存货成本，直接进损益。

### 计量原则与成本构成

* **账面价值 = 成本（cost）与可变现净值（NRV）孰低**（lower of cost and NRV）。
* 成本 = **采购成本 + 转换成本 + 其他使存货达到当前场所和状态所必需的支出**：
  * 采购成本：采购价款（减商业折扣 trade discount）、进口关税、运输费、其他可直接归属支出；
  * 转换成本：直接人工 + 按合理基础分配的固定/变动制造费用；
  * 服务企业存货成本：直接从事服务人员的人工 + 可归属的服务间接费用（如为执行某服务合同而使用的设备折旧），普通行政办公折旧不计入，销售谈判人员成本不计入。
* **固定制造费用按正常产能（normal capacity）分摊**；闲置产能（idle capacity）对应的固定制造费用计入**当期损益**，不进存货。
* **现金折扣（settlement discount）不从成本/售价中扣减**（属融资项目）。

**📌考点**：成本三要素；固定制造费用按**正常产能**分摊；服务企业存货成本口径。

**⚠️易错**：① 未分摊的固定制造费用（闲置产能部分）当期费用化；② 现金折扣不扣减；③ 销售费用、利润不进成本。

### 成本流转假设

* 允许：**FIFO（先进先出）、AVCO（加权平均）**。
* **禁止：LIFO（后进先出）**——企业可能"年末高价进货、年初退货"人为抬高销售成本以规避税负。

**📌考点**：FIFO/AVCO 允许、LIFO 禁止（判断/匹配题）。

**⚠️易错**：LIFO 一律不允许，无例外。

### 可变现净值（NRV）

* **NRV = 估计售价（正常经营销售价，减商业折扣）− 至完工尚需发生的成本（costs to complete）− 估计销售费用（costs to sell）**。
* 与 IFRS 5 对比：IFRS 5 非流动资产持有待售用 **lower of CA and (FV−CTS)**；IAS 2 存货用 **lower of Cost and NRV**——本质相同（"为卖而持有"）。
* 减记至 NRV 的损失计入当期损益（销售成本）。
* **NRV 回升时可转回**，转回上限为**原成本**（对比：IAS 36 对 PPE/无形资产的减值不可转回；IAS 2 存货减值是允许转回的）。

**📌考点**：NRV 三要素公式；减值转损益、可转回且以原成本为上限。

**⚠️易错**：

1. **重置成本（current replacement cost）不参与 NRV 计算**——即使同类新品重置成本更低，只要原存货有确定订单且售价高于成本，就不减值。
2. NRV 只减"完工 + 销售"的增量成本，不减一般管理费、现金折扣、融资费用。
3. 漏盘/未入账存货若以**销售额**被发现，须**还原为成本**（÷(1+mark-up)）方可入账。
4. **mark-up = 毛利/成本；margin = 毛利/售价**，两者不可混用（计算题高频陷阱）。

### 存货实务考点

* 盘点日与报告日不一致时用**倒推调整**：＋报告日至盘点日入库的存货；−其中已售出存货的成本。
* 生产周期长、需大量时间的存货属 qualifying asset，相关**借款费用资本化**计入存货。
* **售后回购**实质为融资，存货仍属本主体资产，不转出。
* **存货计价方法变更（如 FIFO → AVCO）属会计政策变更**→**追溯调整**；对**当期销售成本**的影响 = 期初存货差异与期末存货差异的净影响（期初存货下调→销售成本下降；期末存货下调→销售成本上升）。
* 存货按成本与 NRV 孰低计量，**公允价值的上升不予确认**（公允价上涨信息不影响账面金额）。

**📌考点**：倒推盘点；漏盘还原成本；计价方法变更属政策变更并追溯；存货不确认公允价值上升。

**⚠️易错**：存货不计提公允价值上升，不能因市价上涨调高账面价值。

## 6.2 IAS 41 农业（Agriculture）

### 适用范围（Scope）

* IAS 41 仅覆盖 **生物资产（biological assets）** 和 **农产品（agricultural produce）在收割时点（point of harvest）**。
* 流程：种植/出生 —(IAS 41)→ 收割 —(IAS 2)→ 出售。农产品一旦进入交易/加工环节即**转为存货（IAS 2）**、退出 IAS 41。
* 范围排除：
  * 收割**之后**的农产品 → **IAS 2 存货**；
  * **农业用地** → IAS 16 PPE 或 IAS 40 投资性房地产；
  * 与农业活动相关的**无形资产**（如研发抗病新种子）→ IAS 38；
  * **承载植物（bearer plants：果树、葡萄藤、橡胶树等，本身不收割出售、年年靠其结果）** → **IAS 16 PPE**（视作生产设备）；
  * **承载生物资产（bearer biological assets）** → IAS 16 PPE。
* 活的动物：全部适用 IAS 41（无"载体动物"概念）。
* 活的植物分两类：成熟即收割出售的**农作物**（小麦、生菜）→ IAS 41；**承载植物** → IAS 16。

**📌考点**：判断各项适用哪个准则——活着在长→IAS 41；收割下来→IAS 2；土地/承载植物→IAS 16；研发→IAS 38。

**⚠️易错**：① 承载植物**不适用** IAS 41；② 收割后即适用 IAS 2；③ 收割后再加工（葡萄→酒、羊毛→毛衣、牛奶→奶酪）→ 普通存货 IAS 2。

### 定义与确认

* **生物资产**：活的动物或植物。
* **农产品**：从生物资产上收获的产品。
* **生物转化（biological transformation）**：导致生物资产质/量变化的过程，含四过程——**生长 growth、退化 degeneration、生产 production（繁衍无生命产品，如羊毛）、繁殖生育 procreation（繁衍有生命后代，如小羊）**。
* 确认条件（同时满足）：① 主体因**过去事项控制**该资产；② 相关**未来经济利益很可能**流入；③ 公允价值或成本能**可靠计量**。

**📌考点**：生物转化四过程；确认三条件。

**⚠️易错**：IAS 41 的"控制"还包含控制其**衍生物**（如鸡生蛋、蛋孵小鸡）。

### 计量

* **初始计量 = 后续计量 = 公允价值减销售费用（fair value less costs to sell，FV−CTS）**——FR 中**唯一"初始即按公允价值"**&#x7684;资产准则。
* FV−CTS 的**变动计入损益（P/L）**；生物资产**不存在重估盈余**。
* 为何不用成本：生物资产在生长/退化间价值波动，累计成本无法反映真实价值（退化时成本反而高于繁茂时）。
* **农产品**：在**收割时点**按 FV − CTS 计量，之后按 IAS 2 处理。
* **销售费用（costs to sell）**：直接归属于资产处置的**增量成本**，**不包括融资费用（finance costs）与所得税（income tax）**。
* **兜底规则**：若公允价值无法可靠计量 → 按**成本减累计折旧及减值**计量（视同 PPE）。
* 列报：生物资产通常为**非流动资产**；若养殖周期短（如一年多次产出），可列为流动资产。

**📌考点**：FV−CTS 计量及变动进 P/L；农产品在收割时点按 FV−CTS、之后 IAS 2；销售费用剔除融资费用与所得税。

**⚠️易错**：① 销售费用只含处置增量成本，**剔融资费用与所得税**；② 生物资产**无重估盈余**，变动/减值直接入损益；③ 生物资产初始即 FV−CTS，不是成本。

### 政府补助（Government Grants）

* 与生物资产相关的**无条件**补助：在补助**成为应收（receivable）**&#x65F6;确认收益。
* **有条件**补助：仅在**条件满足**时确认收益。

**📌考点**：无条件=应收即确认；有条件=满足条件才确认。

**⚠️易错**：不要用 IAS 20 的"分摊递延"思路处理 IAS 41 生物资产补助。

# 第7章 金融工具（Financial Instruments：IAS 32 / IFRS 9）

> 考试形式：IAS 32 负债/权益分类、可转债分拆、摊余成本循环表、三分类判断、FVTOCI/FVTPL 处理均为高频。一句话重点：**IAS 32 按"是否存在交付现金的合同义务"分负债/权益；可转债负债按类似无转换权债券的市场利率折现、权益倒挤；IFRS 9 债务工具按 SPPI＋业务模式三分类；权益工具默认 FVTPL，仅非交易性可不可撤销指定 FVTOCI 且不可回拨。**

## 7.1 金融工具的定义（Definition）

* 金融工具：使一方产生**金融资产**、同时使另一方产生**金融负债或权益工具**的**任何合同**。
* 三大要素：
  * **金融资产**：现金；收取现金/其他金融资产的合同权利；在**潜在有利条件**下交换金融资产/负债的合同权利。
  * **金融负债**：交付现金/其他金融资产的**合同义务**；在**潜在不利条件**下交换金融资产/负债的合同义务。
  * **权益工具**：证明在扣除所有负债后享有**净资产剩余权益**的合同。

**📌考点**：三要素定义；权益 vs 负债的本质区别 = **有无强制交付现金/金融资产的合同义务**。

**⚠️易错**：**存货、PPE 不是金融工具**；**预付款（prepayment）不是金融资产**；应收/应付款、贷款、债券、权益股份是金融工具。

## 7.2 IAS 32 金融负债与权益的分类

* 发行方须在**初始确认时**，依合同安排的**实质（substance）**&#x53CA;金融负债/权益工具定义，将其（或其组成部分）分类为金融负债或权益工具。
* 优先股分类取决于**合同条款**（是否强制赎回，见 7.8）。

**📌考点**：初始确认时按实质分类。

**⚠️易错**：分类看实质而非法律形式；一经确认不得随意重分类。

## 7.3 复合金融工具（可转债 Convertible Loan Notes）

* 复合金融工具 = 同时含**负债成分**与**权益成分**（典型：可转换债券/可转换贷款票据）。
* 初始确认分拆：
  * **Step 1 负债成分**：按**类似但不含转换权债券的市场利率（较高利率 higher rate）**&#x6298;现未来本金与利息，得现值（＝负债成分公允价值）。
  * **Step 2 权益成分**：发行总收入 **−** 负债成分公允价值（**倒挤 balancing figure**）。
* 初始分录：Dr Cash（发行收入）；Cr Financial Liability（负债成分）；Cr Equity（权益成分）。
* 后续计量：**负债**按摊余成本法逐年计提利息费用（入 P/L），负债余额逐年滚向到期金额；**权益成分一经确认永不变动（不重估）**。
* 到期：选择转换→负债转权益；选择赎回→付现。

**📌考点**：负债=按市场利率折现的现值、权益=倒挤；折现必须用**类似无转换权债券的市场利率**。

**⚠️易错**：

1. 折现率 **不是**债券票面利率（coupon rate），而是市场利率（higher rate）。
2. 权益成分后续**不再重新计量**。
3. 发行方角度是"负债＋权益"；投资方持有的可转债则是资产。
4. 可转债**负债部分的折价摊销**属 IAS 23 借款成本（融资成本）。

## 7.4 初始确认与终止确认（IFRS 9）

* **初始确认**：主体成为金融工具合同条款一方时，在 SFP 确认。
* **终止确认金融资产**：① 收取现金流的合同权利**到期**；或 ② 已**实质转移**该资产几乎**所有风险与报酬**。
* **应收账款保理（factoring）**：
  * **无追索权（without recourse）**：风险报酬已转移 → **终止确认**（因不再"为收取合同现金流而持有"，而是为出售）；
  * **有追索权（with recourse）**：风险报酬未转移 → **不终止确认**，应收款仍留在表内，并确认等额**金融负债**（融资性质），差额**不作为损失费用化**。

**📌考点**：终止确认两条件；有/无追索权保理的相反处理。

**⚠️易错**：有追索权保理下应收款不转出、另确认一项金融负债；不能当作卖断处理。

## 7.5 金融资产的初始计量与分类

### 初始计量

| **分类**                      | **初始计量**               |
| --------------------------- | ---------------------- |
| **Amortised cost / FVTOCI** | 公允价值 **+** 交易成本        |
| **FVTPL**                   | 仅**公允价值**（**交易成本费用化**） |

### 债务工具三分类（SPPI ＋ 业务模式）

* 判定两步：**合同现金流测试（cash flow test / SPPI）**——合同现金流仅为**本金与利息（solely payments of principal and interest）**；**业务模式测试（business model test）**——持有目的。

```
债务工具（含还款义务）
├─ SPPI 满足 且 业务模式=仅收取合同现金流(hold to collect) → Amortised cost（摊余成本）
├─ SPPI 满足 但 业务模式=收取现金流 + 出售                 → FVTOCI（公允变动入 OCI）
└─ SPPI 不满足 或 业务模式=交易获利                        → FVTPL（公允变动入 P/L）
```

* 口诀：**只收本息 AC；收本息又能卖 FVOCI；纯交易 FVTPL**。
* 债务工具 FVTOCI：利息计损益，公允变动计 OCI，**处置时可重分类（recycle）回损益**。

### 权益工具分类

* **默认 FVTPL**（公允变动入 P/L）。
* 仅当权益工具**非持有交易目的**时，可在初始时作**不可撤销（irrevocable）选择**，指定为 **FVTOCI**。
* 指定 FVTOCI 的权益工具：
  * 期末按**公允价值**计量（**不扣减预计销售费用**）；
  * **股息收入（dividend income）仍计入损益**；
  * 公允变动入 OCI；**处置时 OCI 累计利得/损失不可重分类至损益**（recycling prohibited），只能转入留存收益（Retained Earnings）；
  * **不适用减值**。

**📌考点**：债务三分类两步测试；权益工具"默认 FVTPL / 可选 FVTOCI"；FVTOCI 权益工具处置处理。

**⚠️易错**：

1. **持作交易**的权益工具**必须 FVTPL**，不能指定 FVTOCI。
2. FVTOCI 权益工&#x5177;**"双重不可回拨"**：减值不入损益；处置时 OCI 不可转损益（转留存收益）。
3. 债务 FVTOCI 与权益 FVTOCI 不同：前者处置**可**重分类回损益，后者**不可**。
4. FVTOCI 权益工具期末按公允价值、**不扣销售费用**；交易成本则计入初始成本。
5. 交易性（FVTPL）权益投资的交易成本**费用化**，不进成本。

## 7.6 金融负债的计量与分类

* 初始计量：**公允价值 − 交易成本**（限**非 FVTPL**，即摊余成本类）；FVTPL 类仅按公允价值（交易成本费用化）。
* 分类：**摊余成本（默认，绝大多数借款/贷款/应付债券）** / **FVTPL**（持作交易或指定以 FV 计量）。
* 发行方发行**权益工具**：按**公允价值减发行成本**；名义值计入股本、超出部分入股本溢价，发行成本冲减股本溢价；后续**不再重计量**。

**📌考点**：金融负债初始 = FV − 交易成本；权益工具（发行人）初始 = FV − 发行成本且不重估。

**⚠️易错（符号相反）**：

* 金融**资产**（非 FVTPL）交易成本 **加**到公允价值；
* 金融**负债**（非 FVTPL）交易成本从公允价值中 **减**；
* FVTPL（资产或负债）交易成本一律**费用化**。

## 7.7 摊余成本法（Amortised Cost）

```
期初账面价值 × 实际利率 = 利息费用/收入（入 P/L）
实际现金流（票面）= 名义本金 × 票面利率
差额 = 滚入/滚出负债（或资产）余额
期末账面价值 = 期初 + 利息费用 − 实付（或实收）现金流
```

* 折价发行（discount）与发行成本（issue costs）都会**降低初始入账金额**，从而使按实际利率计算的利息费用**更高**。
* 溢价赎回（premium on redemption）应计入到期现金流并纳入实际利率的计算。
* 用于债务工具投资时：初始 = 买价（含折扣）＋交易成本，逐年按实际利率法滚至到期金额。

**📌考点**：用实际利率法逐年求利息与期末账面（循环表）；初始金额含折价、扣（负债）/加（资产）交易成本。

**⚠️易错**：

1. 利息费用 = **期初账面 × 实际利率**，**不是**票面利息。
2. 折价发行 → 初始账面**低于**面值 → 后续利息费用更高。
3. 发行成本与折价都降低初始负债 → 提高利息费用；发行成本应计入初始金额（**不应直接一次性费用化**）。

## 7.8 可赎回优先股（Redeemable Preference Shares）与投资侧分类

| **类型**                         | **分类**    | **原因**               |
| ------------------------------ | --------- | -------------------- |
| **强制赎回**（mandatory redemption） | **金融负债**  | 存在交付现金/金融资产的合同**义务** |
| **发行方可选择**赎回                   | 可能为**权益** | 无强制交付义务              |

* 分类为金融负债的可赎回优先股，**默认按摊余成本**后续计量；融资成本按实际利率、**按发行在外期间比例**计提（注意发行日与报告日之间的月数）。
* 若划分为权益，其**赎回溢价不属于**借款成本。
* 投资方持有的**可赎回优先股**属**债务工具**（有强制赎回义务）→ 满足条件可按**摊余成本**计量，**并非必然 FVTPL**。

**📌考点**：强制赎回优先股是金融负债，按摊余成本计量。

**⚠️易错**：① 并非所有优先股都是权益；② 按实际利率计息时按**发行在外月数**比例摊销；③ 从发行方看是复合金融工具的情形（可转为固定数量权益）与其他情形要区分。

## 7.9 高频易错汇总（金融工具）

* 可转债折现用**票面利率** ❌ → 用**类似无转换权债券的市场利率**（higher rate）。
* 可转债权益成分后续重估 ❌ → 权益成分**不重计量**。
* 所有金融资产初始都含交易成本 ❌ → **FVTPL 类费用化**，只有 AC/FVTOCI 加交易成本。
* 金融负债交易成本加到 FV ❌ → 非 FVTPL 负债**减**交易成本。
* FVTOCI 权益工具处置时 OCI→P/L ❌ → **不可重分类**，转留存收益。
* 权益工具 FVTOCI 要提减值 ❌ → **不提减值**，变动直接入 OCI。
* 所有优先股都是**权益** ❌ → **强制赎回**优先股是**金融负债**。
* 摊余成本下利息费用 = 票面利息 ❌ → = **期初账面 × 实际利率**。
* 交易性权益投资可选 FVTOCI ❌ →  ❌ → 持作交易者**必须 FVTPL**。
* 交易目的的金融资产/负债交易成本进成本 ❌ → **费用化**。
* 未行权的可赎回优先股融资成本按整年计提 ❌ → 按**发行在外月数**比例计提。

# 第8章 租赁（Leases: IFRS 16）

> 考试形式：计算题（初始计量、利息与折旧、租赁负债滚存、售后租回利得）＋ 概念判断（识别、豁免）。一句话重点：**承租人一律确认使用权资产 ROU + 租赁负债**，仅**短期/低价值**可豁免。

## 8.1 识别与确认

* **定义**：合同若在一段时间内让渡了**控制已识别资产使用**的权利以换取对价，则该合同是或包含租赁。
* **控制的两个条件**（承租人须同时满足）：
  1. 有权获得使用该已识别资产的**几乎全部经济利益**；
  2. 有权**主导**该资产的使用。
* **不构成控制**：出租人在租赁期内可**实质替换**该资产，并从中**获得全部经济利益** → 非租赁。

### 确认

* **租赁期开始日（commencement date）**：承租人确认 **使用权资产 ROU asset** 与 **租赁负债 lease liability**。

### 确认豁免（Recognition Exemptions）—— 可选，非强制

* **短期租赁 short-term leases**：**租赁期 ≤ 12 个月**；**含购买选择权的租赁不能作为短期租赁**。
* **低价值租赁 low-value leases**：标的资产**全新时价值较低（≤ \$5,000）**；且同时满足：①承租人能受益于使用该资产；②该资产**不高度依赖、也不高度关联**于其他资产。
* 采用豁免时：租赁付款额在租赁期内按**直线法（或其他系统性基础）确认为费用**。

**📌考点**：租赁识别两条件；两类豁免的条件。

**⚠️易错**：

* 豁免是"**may（可选择）**"而非"must"——期限 ≤12 个月的租赁**可**（非必须）按直线法费用化，也可正常确认 ROU 与负债。
* **低价值豁免按"逐项租赁（lease-by-lease）"选择**。
* "一类标的资产（class of underlying asset）"指**性质与用途相似**的资产，**不是"公允价值相近"**。
* 仅**无购买选择权**且 ≤12 个月才是短期租赁。

## 8.2 初始计量

**使用权资产 ROU（按成本）** =

* 租赁负债的初始计量金额
* **+** 租赁期开始日或之前支付的租赁付款额（**减**已收到的租赁激励）
* **+** 承租人发生的**初始直接成本**（如中介佣金、法律费）
* **+** 拆卸、移除及复原成本（预计发生额）

**租赁负债** = **未来租赁付款额的现值**（PV of lease payments）

* 折现率：优先用**租赁内含利率（interest rate implicit in the lease）**；无法确定时用**承租人的增量借款利率（incremental borrowing rate）**。

**📌考点**：ROU 成本四项；租赁负债按现值折现。

**⚠️易错**：

* **初始直接成本**须**资本化**进 ROU（不是当期费用）。
* **收到的租赁激励、预付租金**要正确加减。
* 折现率选错（内含利率 vs 增量借款利率）。

## 8.3 后续计量

### 使用权资产（后续）

* 用**成本模型**（参照 IAS 16），除非属**投资性房地产**或适用重估模型的一类资产。
* 折旧期间：
  * 若租赁期结束时**转移所有权**，或成本反映**预计将行使的购买选择权** → 在标的资产**使用寿命**内计提；
  * 若**无所有权转移、无购买选择权** → 自租赁期开始日&#x81F3;**【使用寿命结束日】与【租赁期结束日】两者较早者**计提。

### 租赁负债（后续）

* 账面金额 **+** 未偿负债的**利息（finance cost）**；**−** 已支付的租赁付款额。
* 列报：ROU **折旧 → 经营类别**；租赁负债**利息 → 融资类别**（在 PBFI 之后）。
* 租赁负债在 SFP 中按**流动**（未来 12 个月内到期部分）与**非流动**拆分。

**📌考点**：折旧年限的判定；利息与付款对负债的影响；折旧/利息的类别归集。

**⚠️易错**：

* 折旧期"取租赁期与使用寿命较短者"**仅适用于无所有权转移、无购买选择权**的情形。
* **租赁负债利息属融资类别**（常被漏计或错归经营）。

## 8.4 租赁负债滚存与"先付/后付"陷阱（计算核心）

* **后付（in arrears）**：期初负债 × 利率 = 本期利息；期末负债 = 期初 + 利息 − 付款。
* **先付（in advance）**：租赁期开始日的**首笔付款先冲减负债**，**再**按冲减后的余额计息。

**📌考点**：滚动表（opening liability → +interest → −payment → closing）；先付时"先冲本金再计息"。

**⚠️易错**：

* 先付情形下，**利息基数要扣除首笔付款**（不是直接对期初 PV 计息）。
* 第一期利息即使发生在年内也要按**当年持有月份**比例（不足一年时按月份摊算）。
* 若题中给"**首次付款前的未来租赁付款额现值**"，则该 PV 既含付款也用于算折旧——ROU = 租赁负债 + 首笔付款；利息 = 利率 × (PV − 首笔付款)。
* 把**本属正常租赁错当短期租赁**处理 → 费用被少计、**利润被高估**（应确认折旧 + 利息，合计高于单一直线租金）。

## 8.5 售后租回（Sale and Leaseback）

### 情形一：转让构成销售（meets IFRS 15 销售）

* **终止确认**被转让资产；确认 **ROU 资产**、**租赁负债**，并按**已转让的权利**确认销售损益。
* 只**就实际转移出去的部分**确认盈亏（保留使用权对应部分不确认）。
* **利得公式**：

`确认利得 = 总处置利得 × (公允价值 − 租赁负债现值) ÷ 公允价值`

* 分录方向：借 现金（售价）、借 ROU 资产；贷 租赁负债、贷 PPE 账面价值、贷 处置利得。

### 情形二：转让不构成销售（本质是抵押借款）

* **继续确认**被转让资产；按转让对价确认一项**金融负债**（适用 IFRS 9）。交易实质类似**有担保借款**。

**📌考点**：售后租回是否为销售的判断；只确认"转移部分"的利得；利得公式。

**⚠️易错**：

* 不要把**全部**处置利得确认，只确认**与已转让权利对应**的部分。
* 需先算租赁负债现值，再用 `(FV − 负债)/FV` 求出**已转让比例**。
* 不构成销售时**不得终止确认资产**，处理为借款。

## 8.6 租赁（IFRS 16）易错点速览

| **易错点**   | **正确处理**                          |
| --------- | --------------------------------- |
| 租赁识别的控制条件 | 须**同时**满足"几乎全部经济利益" + "主导使用"      |
| 短期租赁豁免    | **可选（may）**；含购买选择权的不算短期           |
| 低价值豁免     | ≤\$5,000 且不高度依赖/关联其他资产；**逐项选择**   |
| 折旧年限      | 有转移/购买选择权→使用寿命；否则→**租赁期与使用寿命较短者** |
| 利息与折旧的类别  | 折旧→**经营**；利息→**融资**               |
| 先付租金      | **先冲减负债再计息**                      |
| 错当短期租赁    | 低估费用 → **高估利润**                   |
| 售后租回      | 只确认**转移部分**的利得；不构成销售→视同借款         |

# 第9章 报告期后事项与准备（IAS 10 / IAS 37）

> 考试形式：Section A 选择题（判断事项处理、计算准备金额）+ Section B 案例题；一句话重点：**判断"根源是否在年末前"+ 准备三条件/计量 + 或有项目概率梯度**。

## 9.1 IAS 10 报告期后事项（Events after the Reporting Period）

* 定义：发生在**报告期末（资产负债表日）之后**、**财务报表批准报出日（authorised for issue）之前**的事项。
* 时间窗口 = **期末日 → 批准报出日**；**股东大会召开日**不属于该窗口（与判断无关）。
* 两类事项判断核心 = **事项的根源/信息是否在报告期末已存在**：年末**已存在**→ 调整；年末**后才新发生**→ 非调整。

| **类型**                   | **定义**                  | **处理**                                                               |
| ------------------------ | ----------------------- | -------------------------------------------------------------------- |
| **Adjusting（调整事项）**      | 为**报告日已存在**的情况提供**新证据** | **调整报表金额**                                                           |
| **Non-adjusting（非调整事项）** | 表明**报告日后才新出现**的情况       | **不调整金额**；**重大**时披露（性质 nature + 财务影响估计 estimate of financial effect） |
| 影响**持续经营假设**的事项（无论哪种）    | —                       | 须按**非持续经营（清算）基础调整报表**                                                |

**典型调整事项**（记判断逻辑，非背题）：

* 期末前已售资产的售价/收益年后确定（年末已售，只是金额后知）。
* 主要客户破产、其应收余额年末已含在应收中（破产根源通常年末前已持续恶化 → 证明年末已减值）。
* 发现**发生在年末前**的舞弊（fraud）、差错。
* 期后法院判决，对应**年末已存在**的诉讼（确认年末已存在的现时义务）。
* 期后按**低于成本**售出年末存货（证明年末存货已减值）。
* 与利润挂钩、**合同在资产负债表日已存在**的员工奖金。

**典型非调整事项**：

* 报告期后**宣告**的股利。
* 报告期后火灾 / 洪水 / 风暴等毁损资产。
* 报告期后完成的**并购 / 发行股票**（谈判虽始于年末前）。
* 报告期后**新颁布法规**导致资产报废。
* 报告期后**新爆发**的客户经营失败（年末无恶化迹象）。

**📌考点**：判断 = **"根源是否在年末埋下"**：年末已有 → 调报表数字；年后才发生 → 只披露（重大时）。

**⚠️易错**：

* 判断标准是**根源是否年末已存在**，**不是"事件大小"或"是否重大"**——重大只决定**是否披露**，不决定**是否调整**。
* 非调整事项**重大时也必须披露**，不能"装作没发生"。
* 期后事项**只调整报告期报表**；年后新发生的事项不会记入报告期，也不会另设一个年度。
* 期末后**火灾/战争/罢工等新事件** → 非调整（仅披露）；**仅当其影响持续经营** → 才调整。
* **保险索赔类**：火损发生在**期末前**、事后只是确定理赔金额 → **调整**；火损发生在**期末后** → **非调整**。

## 9.2 股利（Dividends）与持续经营（Going concern）

* 报告期后**宣告**的股利 → **不确认为期末负债**（期末不存在现时义务）→ 仅作为非调整事项**披露**。
* 只有**在报告期末前已宣告**的股利才确认为负债。
* 若期后事项表明**持续经营假设不再成立** → **调整报表**（按清算基础编制）并披露。

**📌考点**：火灾后无保险、无法继续经营 → 报表**不能再按持续经营基础编制**（不是"仅披露"或"照常计提减值"）。

**⚠️易错**：即使股利在批准报出日前**宣告并已支付**，也**不确认负债**（非调整）。

## 9.3 IAS 37 准备（Provisions）——定义与确认

* **Provision（准备）**：**时间或金额不确定**的负债（a liability of uncertain timing or amount）。
* **Liability（负债）**：因**过去事件**产生的**现时义务**，需转移经济资源。
* **确认三条件（缺一不可）**：
  1. 因**过去事项**产生**现时义务**（legal 法定义务 或 constructive 推定义务）；
  2. 经济资源**很可能流出**（probable，**> 50%**）；
  3. 金额能**可靠估计**（最佳估计即可，存在不确定性不妨碍确认）。
* **法定义务（legal）**：由合同、法律或法律实施产生。
* **推定义务（constructive）**：企业过去行为 / 公开承诺已向他人表明将承担责任、由此产生**合理预期**（如官网公示的退换货政策）→ 同样构成现时义务。
* 义务必须由**过去事项**产生：**未来事项**（未来经营亏损、未来维修意图）不产生义务。

**⚠️易错**：

* 三条件**须同时满足**，任缺其一都不能确认（如"很可能但金额无法可靠估计" → 仅披露）。
* **推定义务也能确认准备**（不要求必须是法定义务）。
* 只在有**强制的过去事件**时才确认；"意图"本身不构成义务。

## 9.4 概率梯度：准备 / 或有负债 / 或有资产

**义务端（经济资源流出）**

| **概率**        | **名称**   | **处理**                 |
| ------------- | -------- | ---------------------- |
| **> 50%**     | Probable | 确认 **Provision**（SOFP） |
| **5% \~ 50%** | Possible | **或有负债** → **披露**      |
| **\< 5%**     | Remote   | 不处理（不动不露）              |

**权利端（经济资源流入）**

| **概率**         | **名称**            | **处理**             |
| -------------- | ----------------- | ------------------ |
| **> 95%**      | Virtually certain | 确认 **Asset**（SOFP） |
| **50% \~ 95%** | Probable          | **或有资产** → **披露**  |
| **\< 50%**     | Possible          | 不处理（不动不露）          |

* **或有负债（Contingent liability）**：① 因过去事项产生的**可能义务**，其存在只能由**不完全受企业控制**的未来不确定事项确认；**或** ② 因过去事项产生的**现时义务**但**未确认**，因为：流出**不很可能**，或金额**不能可靠计量**。
* **或有资产（Contingent asset）**：因过去事项产生的**可能资产**，其存在只能由不完全受企业控制的不确定未来事项确认；**仅当收到基本确定（virtually certain）**&#x65F6;才确认为资产。

**⚠️易错**：

* **流出端与流入端阈值不同**：流出 **> 50%** 即 probable；流入 **> 95%（virtually certain）** 才确认资产。
* **或有资产绝不确认**（除 virtually certain，此时已不叫"或有资产"）；或有项目只能"披露"或"不动不露"。
* 或有负债若"**很可能（> 50%）但金额不能可靠估计**" → 仍**只披露**（不确认准备）。
* 或有负债 **5%\~50%** 须披露；**\< 5%（remote）** 连披露都不需要。

## 9.5 计量（Measurement）

* 基本规则：**金额 = 报告日清偿现时义务所需支出的最佳估计（best estimate）**。

| **事件类型**                       | **计量方法**                                         |
| ------------------------------ | ------------------------------------------------ |
| **一次性事件**（诉讼、重组、环境清理、单个合同违约索赔） | **最可能金额**（most likely amount）                    |
| **大批量同类事件**（保修、退货、大量客户补偿）      | **概率加权期望值**（probability weighted expected value） |

* 应考虑**合理预期会发生的未来事件**（如新法规、新技术）。
* **货币时间价值（time value of money）**：若影响**重大**，按**现值**计量，折现率为反映货币时间价值与该负债特有风险的**税前折现率**。
* 分录模式：`Dr 费用 / 资产成本`，`Cr Provision`。
* **利息展开（unwinding of discount）**：`Dr Finance cost（期初 Provision × 折现率）`，`Cr Provision`；跨期时按**已过期间比例**计算（如半年用 6/12）。

**📌考点**：时间过了多久，就按比例把折现"摊回"到当前日；**至清偿日**准备余额恰好 = 终值。

**⚠️易错**：

* **一次性事件用最可能金额**（不是概率加权）；概率加权只用于**大批量同类事件**。
* 折现后**利息展开要按时间比例**计算（跨期时）。
* 拆装 / 退役 / 恢复义务（decommissioning / restoration）：若义务源于**资产建造** → 准备初始现值**资本化进资产成本**；后续每年 **计提折旧 + 确认利息展开**，**两笔都进 P/L**。

## 9.6 重估、补偿与后续计量

* **重估（Remeasurement）**：每个报告期末**审查并调整**准备金额。
* 资源流出**不再很可能** → **转回（reverse）** 计入收益（income）。
* **第三方补偿（Reimbursement）**：部分/全部支出预期由第三方补偿时：
  * 仅当补偿**基本确定（virtually certain）** 收到时才确认；
  * **SOFP** 中作为**单独资产**列示，**不得与准备抵销**（单独负债 + 单独资产）；
  * **P/L** 中**可以按净额列示**。

**⚠️易错**：

* SOFP **不能抵销**、P/L **可以净额**——高频陷阱。
* 保修期已过、无未决索赔 → 义务解除 → **冲销 / 转回准备**（不得继续挂负债）。

## 9.7 常见准备场景

* **亏损合同（Onerous contract）**：履行义务的**不可避免成本超过预期经济利益**的（待执行）合同。
  * 准备 = **最低净成本（least net cost）** = **较低者**（履行合同成本 vs 违约的补偿 / 罚款）。
  * **未来经营亏损（future operating losses）不得计提准备**。
* **保修（Warranties）**：触发事件 = 附保修地销售产品（法律义务）；**整体**而言修理支出很可能流出 → 按**概率加权期望值**计提。
  * 保修期内实际发生的**替换件**：**不确认收入**，按**成本**处理（减少存货、增加销售成本）。
* **环境修复 / 退役（Environmental contamination / Decommissioning）**：法定义务或推定义务（公开承诺 / 既定政策）均须确认；源于**建造**的退役成本**资本化**进资产成本。
* **未来维修与翻新（Future repairs / refurbishment）**：仅**意图**而非义务 → **不得确认**。
* **自保（Self-insurance）**：事故实际发生前企业**无义务** → **不得确认**。
* **重组（Restructuring）**：确认须**同时**满足 ——
  1. 有**详细正式的重组计划**；且
  2. 已**开始实施**该计划，或已向受影响方**公告**。
  * **仅董事会决议不够（a board decision alone is insufficient）**。
  * 计量**仅含重组直接引起的增量费用（direct expenditures）**，**不含**与持续经营相关的成本（如员工**再培训**、**搬迁**新址费用）。

**⚠️易错**：

* 亏损合同按**最低净成本**（不是"成本全额"）；**未来经营亏损**不得计提。
* 保修替换件按成本处理，**不确认收入**。
* 自保、未来维修**都不能**提准备。
* 重组**仅董事会决议**不确认；**再培训 / 搬迁**不属重组准备范围。
* **概念边界**：递延所得税（含重估产生的递延税）**不是** IAS 37 意义上的"准备"，不应作为 IAS 37 准备确认。

## 9.8 真题补漏考点（本章）

**📌考点**（真题暴露、底稿未明确）：

* **反诉 / 第三方索赔（counter-claim）**：若仅为 possible（可能但非很可能）→ 属**或有资产**；**既不能确认应收，也不能与准备抵销**（正解是"作为或有资产披露"）。
* **诉讼准备** = **最可能金额**（一次性事件）**叠加**无论输赢都必然发生的额外直接支出（如诉讼费 / 法律费用），再按重大性**折现**；同一时点多项支出用**同一折现因子**。
* **期后事项类型判断**（真题反复考）：
  * 保险索赔：火损在**期末前**、期后只是"理赔结果确定" → **调整**；火损在**期末后** → **非调整**。
  * 期后因**新法规**报废机器 → **非调整**。
  * 期后客户破产（余额年末已存在）→ **调整**。
  * 期后因低质量被起诉（货品在**期末前**提供）→ **调整**。
* **IAS 10 + IFRS 18**：重大非调整事项**仅在附注披露**（TRUE）；**无论重大还是非重大**的调整事项都须调整报表（FALSE——只须处理**重大**信息）。

**⚠️易错**（真题暴露）：

* 用"**销售价值 / 售价**"直接作为退货准备金额 → 错；应按**概率加权期望值**计量。
* 保险公司"很可能赔付"的**水损补偿** = **或有资产**（不确认准备）。
* 单件定制设备保修、索赔概率 **35% \< 50%** → **不确认准备，作为或有负债披露**。
* 官网公示的**退换货政策**（推定义务）→ **确认准备**；员工**不当解雇**诉讼很可能败诉 → **确认准备**。

# 第10章 所得税（Taxation：IAS 12）

> 考试形式：Section A 选择题为主（计算 + 正误判断），偶见 Section B 案例题；一句话重点：**CA vs TB 求暂时性差异 → 判 DTL/DTA → 重估递延税进 OCI → 当期+递延合计**。

## 10.1 当期所得税（Current tax）

* **Current tax（当期所得税）** = 就**当期应税利润（taxable profit）应付 / 可收回**的所得税金额 = 应纳税所得额 × 适用税率。
* 分录：`Dr Income tax expense`，`Cr Current tax liability`。
* **Over / Under-provision（多提 / 少提）**：上年计提数与实际应交数的差异，在本年调整。

| **情形**                  | **含义**                                 | **调整**                                          |
| ----------------------- | -------------------------------------- | ----------------------------------------------- |
| **Over-provision（多提）**  | 上年提多了（Current tax account 有 **Cr** 余额） | **减少**本年费用（`Dr tax liability / Cr tax expense`） |
| **Under-provision（少提）** | 上年提少了（Current tax account 有 **Dr** 余额） | **增加**本年费用（`Dr tax expense / Cr tax liability`） |

**📌考点**：Current tax account 方向：**Dr 余额 = 少提 → 加**；**Cr 余额 = 多提 → 减**。

**⚠️易错**：把 Dr / Cr 余额方向搞反 → under / over provision 加错方向。

## 10.2 递延所得税核心定义

* **Deferred tax（递延所得税）** = 归属于**暂时性差异**的所得税。
* **Permanent differences（永久性差异）**：**不产生递延税**后果（如罚款、超标招待费、免税收入）。
* **Temporary difference（暂时性差异）** = 资产 / 负债的**账面价值（carrying amount, CA）**&#x4E0E;其**计税基础（tax base）**&#x4E4B;间的差额。
* **Tax base（计税基础）** = 为**税务目的**归属于该资产 / 负债的金额（即 TWDV，tax written-down value）。

## 10.3 DTL / DTA 判断（必背）

| **资产 / 净资产** | **负债**       | **差异类型**                    | **结果**                          |
| ------------ | ------------ | --------------------------- | ------------------------------- |
| **CA > TB**  | **CA \< TB** | **Taxable TD**（应纳税暂时性差异）    | **Deferred tax liability（DTL）** |
| **CA \< TB** | **CA > TB**  | **Deductible TD**（可抵扣暂时性差异） | **Deferred tax asset（DTA）**     |

* 记忆：资产端 **CA > TB → DTL**；**负债端规则相反**。
* 分录：DTL 增加 → `Dr Income tax expense / Cr Deferred tax liability`；DTA 增加方向相反。

**⚠️易错**：

* **CA vs TB 计算**：会计折旧得 **CA**；税务折旧得 **TB（TWDV）**；差异 = **CA − TWDV**。
* 固定资产折旧：**会计折旧按（成本 − 残值）**；**税务折旧（tax allowance）按原值 / 成本**——**残值只影响会计折旧**。
* 有**期初递延税余额**时：**本年费用 = 期末 DTL − 期初 DTL**（正数=费用，负数=贷方收益）；只求"**期末余额**"则用期末暂时性差异 × 税率。
* 某些差异**不确认**递延税（如商誉初始确认等）；但**重估增值必确认**。

## 10.4 各类暂时性差异场景

* **资产类（收入先会计、后税务）**：
  * 应收利息（收到时才交税）→ 账面资产 **CA > TB(0)** → **DTL（贷记 deferred tax）**。
  * 已在以前年度税前扣除的**预付费用** → 账面资产 **CA > TB(0)** → **DTL（贷记）**。
* **负债类（费用先会计、后税务）**：
  * 应付利息（支付时才可税前扣除）→ 负债 **CA > TB(0)** → **DTA（借记 deferred tax）**。
  * 还款**无税务后果**的借款 → **无暂时性差异**。
* **开发成本资本化（development cost capitalised）**：账面资本化为无形资产 CA > 0，税法当年**全额扣除** → **TB = 0** → **应纳税暂时性差异 → DTL** → 增加所得税费用。
* **固定资产（会计折旧与税务折旧不一致）**：
  * 会计 CA 用直线法等；税务 TB 用税收优惠 / 递减余额（如首年高比例 + 后续 TWDV 比例）。
  * **税务折旧快于会计折旧**（允许额领前）→ CA > TB → **DTL**；**税务折旧慢** → CA \< TB → **DTA**。
* **可结转弥补的税务亏损（tax losses carried forward）**：税法允许亏损抵减未来应税利润，若预计未来有**足够利润** → 未来少交税 → 确认 **DTA**。

**📌考点**：逐项判断"资产端 / 负债端" → 比较 CA 与 TB → 套 10.3 表格；DTL 增加 = **贷记** deferred tax account。

**⚠️易错**：

* 开发成本看似"资产"就不管税 → 错；资本化 + 税法当年全扣 → **必然产生 DTL**。
* "无税务后果"的借款 → 无差异，不要凭空确认。
* DTA 确认需"**未来很可能有足够利润**"支持（否则不确认）。

## 10.5 重估增值的递延税（Revaluation surplus）🔥最高频

* 资产重估增值：账面 **CA 增加**，税务 **TB 不变**（税务局不认重估）→ **CA > TB → 应纳税暂时性差异 → DTL**。
* 递延税**冲减重估盈余（OCI）**，**不进利润表**：`Dr Revaluation surplus (OCI) / Cr Deferred tax liability`。
* **税后重估盈余 = 重估增值 × (1 − 税率)**。
* 若**减值**且税法允许税前扣除 → 产生 **DTA**。
* **期末 DTL 总额 = 期初 DTL + 本年其他暂时性差异新增 DTL + 重估新增 DTL**（重估部分**单独进 OCI**）。
* **无论是否打算出售 / 长期持有**，只要 CA > TB，就**必须确认 DTL**。
* 联动 IAS 16：某一项 PPE 重估 → 该**整类（entire class）** PPE 都须重估。

**📌考点**：

* 重估产生的 DTL **须单独计入 OCI（Revaluation surplus）**，与 P/L 的递延税**分开**。
* 求"重估盈余期末余额" = 重估增值 − 重估增值 × 税率。

**⚠️易错**：

* 把重估的递延税计入利润表所得税费用 → 错（应进 OCI）。
* 认为"重估不影响递延税负债" → 错（重估产生应纳税暂时性差异，影响 DTL）。

## 10.6 税率变动与折现

* **税率变动（Changes in tax rates）**：递延所得税按**预期资产实现 / 负债清偿期间适用的税率**计量，依据**报告期末已颁布或实质上已颁布（enacted or substantively enacted）**&#x7684;税率与税法。
* **折现（Discounting）**：递延所得税资产与负债**不得折现**（因复杂且困难）。

**⚠️易错**：

* 用**当前税率**计量递延税 → 错；应用**预期转回时的已颁布税率**。
* 递延税**不得折现**（区别于 IAS 37 准备，重大时须折现）。

## 10.7 总所得税费用

* **总所得税费用（Total income tax expense）= Current tax expense + Deferred tax expense**
  * Current tax expense = 本年 provision **±** under / over provision；
  * Deferred tax expense = **期末 DTL 余额 − 期初 DTL 余额**（正数为费用）。

**📌考点**：将"当期（含 under / over provision 调整）+ 递延变动"相加。

**⚠️易错**：遗漏 under / over provision 调整，或遗漏递延税变动。

## 10.8 真题补漏考点（本章）

**📌考点**（真题暴露）：

* **"期末余额" vs "本年费用"**：给期末 CA、TB、税率 → 求**期末 DTL 余额**（差异 × 税率），再与期初比较得**本年 P/L 递延税变动**。
* **多资产汇总**：分别对每项资产算 **(CA − TB) × 税率** 再合计（如 Plant + 已重估的 Land）；**重估盈余 = 重估增值 × (1 − 税率)**。
* **重估当日的重估盈余余额** = 重估增值 − 重估增值 × 税率。
* **期初有 DTL、期末（不含重估）差异下降** → 递延税**贷记**所得税费用：`Dr DTL / Cr income tax expense`。
* **IAS 12 正误判断**：① 递延税考虑暂时性差异（TRUE）；② 递延税负债折现并逐年转回（FALSE，不得折现）；③ 土地重估不影响 DTL（FALSE）。

**⚠️易错**（真题暴露）：

* **看清题目所问**："期末递延税**余额**"（期末差异 × 税率）还是"本年利润表**递延税费用**"（期末 − 期初）——易混。
* **重估与普通差异分账**：重估 DTL 进 OCI，"其他应税差异"变动进 P/L，切勿混在一起。
* **方向勿反**：DTL 减少 → **借记 deferred tax liability**，对应 **贷记 income tax expense**（"减少费用"），不要写成"贷记递延税"。

# 第11章 其他准则（Other Standards：IAS 8 / IFRS 13 / IFRS S1）

> 考试形式：Section A 为主（政策/估计/差错判断、公允价值层级匹配、概念题）。一句话重点：分清"**政策(追溯) / 估计(未来适用) / 差错(追溯重述)**"，认准 **FV 三层级**。

## 11.1 IAS 8 —— 会计政策、会计估计变更与差错

```
IAS 8
├── Accounting policies 会计政策（变更→追溯）
├── Estimates 会计估计（变更→未来适用）
└── Errors 差错（更正→追溯重述）
```

### 11.1.1 会计政策的选择

* 管理层应选择**符合适用准则/解释**的会计政策；**无适用准则时**按 **Conceptual Framework 的原则**选择；可参考**其他准则制定机构**发布的准则。

### 11.1.2 会计政策变更（Changes in accounting policies）

* **仅两种情况允许变更**：①法规或准则制定机构**要求变更**；②变更能使交易/事项的列报**更相关、更可靠**。
* **属政策变更**的判断（任一层面改变即为政策变更）：**确认基础**改变（如原确认资产现确认为费用）、**列报方式**改变、**计量基础**改变。
* **处理**：**追溯（retrospectively）** 应用——调整**期初留存收益**、**重述比较数据**，并在**权益变动表**单独列示"会计政策变更"行。

**📌考点（真题分类，必背）**：

* **属**政策变更：将佣金收入从"其他经营收益"**重分类为"收入"**（列报）；折旧费从管理费**重分类**为销售成本（列报）；存货计价**FIFO → 加权平均成本**（计量基础）；测量模型变更（如历史成本→重估模型）。
* **不属**政策变更：为合并而把**子公司报表调整为集团政策**（=**合并程序**）；**修订可折旧资产的剩余使用寿命**（=估计变更）；因资产负债表日后有效调整事项把存货由成本**减记至 NRV**（=估计/计量事件）；把采购方式由**现金采购改为融资租赁**（业务实质变化）。

**⚠️易错**：把"合并调整""存货减记至 NRV""折旧方法/年限变更"误判为政策变更；政策变更必须**追溯**而非未来适用。

### 11.1.3 会计估计变更（Changes in accounting estimates）

* 源于**新信息、新经验或新判断**，**不是差错更正**。
* **处理**：**未来适用（prospectively）**——只影响当期及未来期间，**不追溯、不重述比较报表**。
* 常见情形：折旧/摊销**年限、残值、折旧方法**变更、坏账准备率、存货 NRV 估计、减值测试方法。

**⚠️易错**：**折旧方法变更 / 剩余寿命修订 = 会计估计变更（未来适用）**，不是政策变更；"政策 vs 估计"区分不清是本章**最高频易错点**。

### 11.1.4 前期差错更正（Correction of prior period errors）

* **追溯重述**：调整**留存收益期初余额**（权益变动表）+ **重述比较数据**。
* 若本期才发现**跨期**差错：**属以前期间**的部分调整**期初留存收益**；**属本期**的部分计入**当期损益**（如舞弊/损失按归属期间拆分处理）。

### 11.1.5 关联列报易错（与权益变动表 / 所有者交易）

* 会计**政策变更**与**前期差错更正**在权益变动表中**单独列示**（调整留存收益期初余额）；**首次应用新准则不是**政策变更。
* **股利（宣告/已付）不进损益**，在**权益变动表**列示。
* **红股（bonus issue）**：股本增加、其他权益成分（股本溢价/留存收益）等额减少，**权益总额不变**。
* **可转换债券**含权益成分 → 发行会**增加权益总额**；**不可转换债券、可赎回优先股**属**负债**，不影响权益总额。

**⚠️易错**：把股利计入损益；误以为红股增加权益总额；把可赎回优先股当作权益。

## 11.2 IFRS 13 —— 公允价值计量

### 11.2.1 定义与核心理解

* **公允价值**：**市场参与者**之间在**计量日**的**有序交易**中，**出售资产收到 / 转移负债支付**的价格。
* 是**市场基础**计量，**非主体特定**；是**脱手价（exit price）**，非买入价。

### 11.2.2 选择市场

| **市场**                             | **说明**                                  |
| ---------------------------------- | --------------------------------------- |
| **主要市场 Principal market**          | 该资产/负债**流动性最强**（交易量与活跃度最大）的市场（**优先使用**） |
| **最有利市场 Most advantageous market** | **无主要市场时**使用；在扣除**交易成本**与**运输成本**后评估    |

### 11.2.3 公允价值的调整

| **项目**                    | **是否调整**               |
| ------------------------- | ---------------------- |
| 交易成本（Transaction costs）   | ❌ **不调整**              |
| 运输成本（Transportation cost） | ✅ **调整**（**地点是资产的特征**） |

**⚠️易错**：把交易成本计入 FV；忘记运输成本需调整。

### 11.2.4 非金融资产的公允价值 —— 最高最佳使用（highest and best use）

* FV 反映资产的**最高最佳使用**，须同时满足：**物理上可能（physically possible）**、**法律上允许（legally allowed）**、**财务上可行（financially feasible）**。

### 11.2.5 估值技术（三种）

| **方法**                  | **核心逻辑**                           |
| ----------------------- | ---------------------------------- |
| **市场法 Market approach** | 使用相同或可比资产/负债的**市场交易价格**（如股价×股数）    |
| **成本法 Cost approach**   | **现行重置**服务能力所需金额（现行重置成本扣除**陈旧贬值**） |
| **收益法 Income approach** | 将**未来金额（现金流）折现**为单一现值              |

### 11.2.6 公允价值层级（Fair Value Hierarchy）—— ⭐高频

按输入参数的**可观察性**建立三级，优先级 **Level 1 > Level 2 > Level 3**：

| **层级**         | **特征**                                                            | **例子**          |
| -------------- | ----------------------------------------------------------------- | --------------- |
| **Level 1** 🥇 | **活跃市场**中**相同**资产/负债的**未经调整报价**（可观察）                              | 交易所股价           |
| **Level 2** 🥈 | **可观察**输入：活跃市场中**相似**资产/负债报价，或**非活跃市场**中相同/相似资产报价；除未调整报价外的其他可观察输入 | 类似房产成交价、利率/波动率等 |
| **Level 3** 🥉 | **不可观察**输入：基于可获得的最佳信息（含**主体自身假设**）                                | 成本+利润估算         |

**📌考点（层级匹配）**：

* 活跃市场**相同**资产/负债报价 → **Level 1**
* 活跃市场**相似**资产/负债报价 → **Level 2**
* **非活跃市场**相同/相似报价 → **Level 2**
* 其他**可观察**输入（除未调整报价，如 market-corroborated inputs）→ **Level 2**
* **不可观察**输入 → **Level 3**

**⚠️易错**：Level 1 必须**相同 + 活跃 + 未经调整**（缺一不可）；只有 Level 3 才依赖主体自身假设。

### 11.2.7 IFRS 13 在 FR 其他准则中的应用

| **准则**  | **涉及公允价值处**                   |
| ------- | ----------------------------- |
| IAS 16  | PPE **重估价模型**                 |
| IAS 40  | **投资性房地产**公允价值模型              |
| IAS 41  | **生物资产**按 FV 减销售费用计量          |
| IFRS 5  | 持有待售资产按**账面价值与 FV 减处置费用孰低**计量 |
| IFRS 15 | 对价中的**非现金**部分按 FV 计量          |

## 11.3 IFRS S1 —— 可持续相关财务信息披露的一般要求

### 11.3.1 背景

* 可持续包含：**环境、社会、经济、治理**。
* ISSB 于 **2023 年 6 月**发布首批两项准则：**IFRS S1**（一般要求）、**IFRS S2**（气候相关披露）；与 IFRS 会计准则并列，**同属 IFRS Foundation 体系**。
* IFRS S1 就特定可持续议题（如气候）**援引其他 ISSB 准则**。

### 11.3.2 目标

* 要求主体披露其**可持续相关风险与机遇**的信息，帮助投资者做出"**是否向该主体提供资源**"的决策。
* 只关注**可合理预期影响主体前景**（影响其**现金流、获取资本、融资成本**）的**重大**风险与机遇；**不要求报告所有**可持续问题。

### 11.3.3 适用范围

* **无论**财务报表按 **IFRS 还是其他 GAAP** 编制，**均可**应用 IFRS S1。
* 术语适合**盈利性实体**；**非营利实体**可能需调整对特定信息的描述。

### 11.3.4 核心内容 —— 四大支柱

| **支柱**                          | **披露内容**                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| ① **治理 Governance**             | 监督、管理、监控可持续相关风险与机遇的**治理流程、控制和程序**；谁负责（**董事会/委员会/个人**）及管理层如何以控制与程序支持监督                 |
| ② **战略 Strategy**               | 应对可持续相关风险与机遇的**战略**；风险机遇对**商业模式与价值链、战略与决策、财务状况/业绩/现金流**的影响；战略与商业模式的**韧性（resilience）** |
| ③ **风险管理 Risk management**      | **识别、评估、优先排序、监控**可持续相关风险与机遇的**流程与政策**；及其**融入整体风险管理**的程度                               |
| ④ **指标与目标 Metrics and targets** | 每项风险/机遇的：适用准则要求的**指标**；用于衡量和监控的**指标**；**目标**及法规要求目标的**进展**                            |

**📌考点（易混归类）**：**resilience → Strategy**；风险识别/评估/管控流程 → **Risk management**；董事会监督 → **Governance**；碳排放等量化指标 → **Metrics and targets**。

**⚠️易错**：把"韧性(resilience)"归入风险管理（应为**战略**）。

### 11.3.5 报告时间与比较信息

* **时间**：与相关**财务报表同时**报告，覆盖**相同的报告期间**。
* **比较信息**：报告期内披露的**所有金额**均须提供比较数据（除非另一准则另有规定）；**叙述性/描述性**信息如有助理解也须提供。

### 11.3.6 概念基础（Conceptual foundations）

* 可持续披露是**通用目的财务报告的一部分**；**CF 的质量特征**（相关、如实反映等）同样适用。
* 应披露**可合理预期影响主体前景的重大信息**；强调**关联信息（connected information）**&#x8981;求。
* 正保版概念基础四项：**fair presentation（真实公允）、materiality（重要性）、reporting entity（报告主体）、connected information（关联信息）**。

**⚠️易错**：**比较信息（comparative information）与报告时点（timing of reporting）**&#x5C5E;**定性质量特征**层面（可比性、及时性），**不属于** IFRS S1 的概念基础。

## 11.4 易错点速记（Ch11）

| **#** | **易错点**          | **正确理解**                                                       |
| ----- | ---------------- | -------------------------------------------------------------- |
| 1     | 政策 vs 估计变更       | 折旧方法/年限/残值变更→**估计**（未来适用）；列报/确认/计量基础变更、存货 FIFO→AVCO→**政策**（追溯） |
| 2     | FV 三层级判断         | L1=**相同+活跃+未调整报价**（缺一不可）；L2=可观察但需调整；L3=不可观察                    |
| 3     | FV 是否含成本         | **不计交易成本**；但**调整运输成本**（地点是资产特征）                                |
| 4     | 政策变更 ≠ 合并调整      | 合并时统一子公司政策属**合并程序**，非集团政策变更                                    |
| 5     | 前期差错处理           | **追溯**调整**期初留存收益** + 重述比较数据，**不进当期损益**                         |
| 6     | 存货减记至 NRV、折旧方法变更 | 均**不是**政策变更                                                    |
| 7     | 非金融资产 FV         | 按**最高最佳使用**（物理可能/法律允许/财务可行）                                    |
| 8     | IFRS S1 范围       | 无论按 IFRS 或其他 GAAP，**均可**应用；非营利实体需调整描述                          |
| 9     | IFRS S1 四支柱易混    | resilience→战略；风险流程→风险管理；董事会监督→治理；量化指标→指标与目标                    |
| 10    | 权益列报关联           | 股利不进损益（进权益变动表）；红股不改权益总额；可转债增加权益                                |

# 第12章 收入（Revenue — IFRS 15）

> 考试形式：Section A 选择/计算（五步法判断、交易价格调整、Principal vs Agent、时点 vs 时段）+ Section B 案例（建造合同四步法、多重履约义务分摊）；一句话重点：以「合同」为单元，按「履约义务」分摊交易价格，在「控制权转移」的时点或过程中确认收入。

## 12.1 收入的定义与范围

* **Revenue（收入）** = income arising in the course of an entity's **ordinary activities**（日常活动产生的收益）。
* **Income（收益）** 概念更宽，还包括利得（gains）。

**📌考点**：收入 = 日常活动收益；Income 范围更大。

**⚠️易错**：处置**非日常活动**资产（如出售闲置车辆）的利得、投资收益等**不计入** revenue。

## 12.2 五步法模型（Five Steps Model）

1. Identify the contract(s) with a customer
2. Identify the performance obligations in the contract
3. Determine the transaction price
4. Allocate the transaction price to the performance obligations
5. Recognise revenue when (or as) it satisfies a performance obligation

## 12.3 Step 1 识别合同

* 合同（contract）= 两方或多方之间具有**可强制执行（enforceable）**&#x6743;利与义务的协议；可为**书面、口头或默示**。
* 属 IFRS 15 范围内须**全部同时满足**：

\| 条件 | 说明 |

\| --- | --- |

\| 各方已批准并承诺履行 | approved and committed |

\| 各方权利义务可识别 | rights identifiable |

\| 付款条款可识别 | payment terms identifiable |

\| 具有商业实质 | commercial substance |

\| **对价很可能收回** | **probable**（不是 possible） |

**📌考点**：五条**全部**满足才适用 IFRS 15。

**⚠️易错**：① 合同**不要求书面**；② 收回与否看 **probable（很可能）**，而非 possible。

## 12.4 Step 2 识别履约义务

* 商品/服务若 **distinct（可明确区分）**，则构成单独的 **performance obligation**，单独核算。
* 判断 distinct：① 企业**经常单独销售**该商品/服务（capable of being distinct）；② 客户能**单独或连同其易得资源**从中获益（distinct within context）。
* 一项履约义务可以是：单一商品/服务、一组、或「**一系列实质相同且转移模式相同**」的商品/服务。

**📌考点**：设备 + 安装 + 售后支持，通常拆为**多项**履约义务（安装/售后支持是否可区分要看其能否单独获益）。

**⚠️易错**：教材此处对 distinct 写作「…**or**…」（两个条件之一），但 IFRS 15 要求两个条件**同时满足**（见文末校验说明）。

## 12.5 Step 3 确定交易价格（Determine the transaction price）

* 交易价格 = 预期有权获得的、因向客户转让承诺商品/服务而取得的对价。构成要素：

\| 要素 | 处理 |

\| --- | --- |

\| **固定对价** | fixed amount of consideration |

\| **可变对价** | 用**期望值（expected value）**&#x6216;**最可能金额（most likely amount）**&#x4F30;计；仅在**极可能（highly probable）不会发生重大转回**时才计入 |

\| **重大融资成分** | 反映**货币时间价值**（见下） |

\| **非现金对价** | 按 **公允价值（fair value）** 计量 |

\| **代第三方收取的款项** | **不计入**交易价格（如代收税额） |

\| **应付给客户的对价** | **冲减**交易价格（reduce the transaction price） |

### 重大融资成分（Significant financing component）★高频

* 若合同含重大融资成分（付款与转让间隔**较长，通常 ≥1 年**），须把交易价格调整为**收款金额的现值（折现）**。
* 实务简化：转让与付款间隔 **≤12 个月**可豁免折现。
* 处理：交易价格 = 现值；差额 = **融资收益/费用**，在期间内分期确认。
* 分录：初始 `Dr Trade receivable（现值） / Cr Revenue（现值）`；每期末 `Dr Trade receivable / Cr Finance income`（利息 unwind）。

**📌考点**：计入 P/L 的总额 = 确认的收入（现值）+ 当期融资收益。

**⚠️易错**：① 未按现值确认收入；② 漏记融资收益；③ 未按**已过月数比例**调整（信息期间为 1 年但当年只过了若干月 → 按比例）；④ 应付款项单向：作为**融资费用**处理。

### 应付给客户的对价（Rebate / Discount / Cashback）

* 直接**冲减交易价格**，减少收入。
* 例：`Transaction price − Cashback = Net transaction price`。

**⚠️易错**：现金返利**不是**单独确认的费用（费用化错），而是冲减收入。

## 12.6 Step 4 分摊交易价格（Allocate the transaction price）

* 合同有**多项**履约义务时，按**各项单独售价（stand-alone selling price, SSP）的相对比例**分摊，**以合同开始日（inception）为准**。
* 若某项无单独售价，可用「成本 + 合理毛利」估计：**SSP = 成本 × (1 + mark-up)**（`mark-up = 利润/成本`）。

**📌考点**：分摊依据 = 合同开始日各项**单独售价的相对比例**。

**⚠️易错**：不是平均分摊、不是按成本分摊；组合（套餐）折扣应**按各项单独售价比例分摊**，而非全部给价格最高/最低的一项。

## 12.7 Step 5 确认收入（时段 vs 时点）

* 通过**转移控制权（transfer of control）**&#x5C65;行履约义务。
* **控制（control）** = 主导资产使用并获取其实质上全部剩余利益的能力。
* **控制权转移的迹象**：① 客户取得实物占有；② 客户已接受资产；③ 客户拥有法定所有权；④ 客户承担所有权的**重大风险和报酬**；⑤ 客户有付款义务。
* **时点（point in time）**：多数商品销售，在交付/控制权转移日确认。
* **时段（over time）**：满足下列**任一**即可 ——

① 客户在企业履约的同时**同时取得并消耗**利益（如服务合同）；

② 履约**创造或改良**客户在过程中**控制的资产**（如在客户场地建造）；

③ 履约**不产生可替代用途**的资产，且企业对已完成部分有**可强制执行的收款权**（建造合同）。

**📌考点**：判断标准是**控制权转移**。

**⚠️易错**：① 误用旧准则 IAS 18 的「**重大风险与报酬转移**」判断 —— IFRS 15 看**控制权**；② 退货权/验收：客户已**签署验收、无条件接受**、或**退货需付罚金** → 控制权已转移，交付时确认。

## 12.8 履约进度（Measuring progress）

| **方法**                                  | **具体做法**                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------ |
| **产出法（Output method）**                  | surveys of performance completed、physical milestones、units produced/delivered、已完工程价值 |
| **投入法（Input method）**                   | costs incurred、labour hours expended、resources consumed                              |
| **⚠️易错**：「成本占收入百分比」「工时数」属**投入法**，不是产出法。 | ​                                                                                    |

## 12.9 建造合同（Construction Contract）— 四步法 ★★★

* **Step 1 合同价格** = 初始金额 + Variations（变更）+ Claims（索赔）+ Incentive payments（奖励款）− Penalties（罚金）
* **Step 2 完工百分比** = 已发生成本 ÷ 预计总成本（投入法）；或 = 已完工程价值 ÷ 合同总价（产出法）
  * **本期完工% = 累计完工% − 上年累计完工%**
* **Step 3 利润表（当年）**：Revenue = 合同总价 × 本期完工%；Cost of sales = 当年为履约发生的成本；Profit = 差
* **Step 4 资产负债表（累计）**：

```
Revenue recognised to date
Less: Amounts invoiced to date
= Contract asset /（liability）
```

* **判断规则**：已确认收入 **>** 已开票 → **Contract asset（合同资产）**（类似 accrued income）；已确认收入 **\<** 已开票 → **Contract liability（合同负债）**（类似 deferred income）。
* **分录逻辑**：按进度 `Dr Contract asset / Cr Revenue`；开票 `Dr Trade receivable / Cr Contract asset`；收款 `Dr Bank / Cr Trade receivable`。

**📌考点**：

* 收入按**累计完工%**&#x8BA1;算；**本期**收入 = 累计 − 上年累计。
* **完工进度无法可靠计量**：收入 = **已发生且可收回的成本**（零利润法），利润 = 0；未开票时形成 contract asset（**不会**出现 contract liability）。
* **亏损合同（Onerous contract）**：预计总损失**立即全额确认**（IAS 37）；已通过 P/L 确认的部分之外，差额计提 **provision**（SOFP 同时出现 contract asset 与 provision）。

**⚠️易错**：

① 合同资产 = **已赚未开票**；trade receivable = **已开票未收款**（两者不同）；

② **已收款金额不影响**合同资产/负债计算（只影响应收与现金）；

③ 已确认收入 \< 已开票是**合同负债**（不是资产）；

④ 合同资产/负债**所有建造合同都要算**，不限于亏损合同；

⑤ 亏损「完工时才确认」—— 错，**立即全额确认**；

⑥ 完工无法可靠计量时误认为收入为 0 —— 错，按可收回成本确认收入。

## 12.10 特殊事项（Special Events）

### Principal vs Agent

| **角色**               | **收入确认**           | **判断标准**       |
| -------------------- | ------------------ | -------------- |
| **Principal（主要责任人）** | **总额 Gross**       | 转让前**控制**商品/服务 |
| **Agent（代理人）**       | **净额 Net（佣金/手续费）** | 不控制            |

* **代理人的迹象**：① 另一方负责履行合同；② 不承担**存货风险**；③ 对价格**无自主权**；④ 对价以**佣金**形式收取；⑤ 不承担**信用风险**。

**⚠️易错**：代理人只确认**佣金（净额）**；判断核心是「**是否控制**」，而非「是否负责交付」。

### 售后回购（Sale and Repurchase）

* 回购价 **\<** 售价 → 视为**租赁（IFRS 16）**。
* 回购价 **≥** 售价 → 视为**融资交易**，确认**金融负债**（**不确认收入**）；回购价与售价差额在期间内确认为**利息费用**，期末计提应付利息。

**⚠️易错**：回购价高于售价时**不得确认收入**，按融资处理（真题补漏）。

### 寄售（Consignment）

* 商品售予最终客户前**不确认收入**。

### 开单持有（Bill and Hold）

客户已付款/同意付款但要求暂不发货，须**同时满足**：

① 该安排的理由具有**实质（substantive）**；② 商品**单独归属于客户**；③ 商品**随时可交付（ready for physical transfer）**；④ 企业**不能**使用该商品或将其转给其他客户。

* 全部满足 → 控制权已转移 → **可确认收入**。

**⚠️易错**：客户暂不取货**不等于**不能确认收入。

## 12.11 合同成本（Contract Costs）（教材补漏）

* **取得合同的增量成本（incremental costs to obtain a contract）**（如销售佣金）：预期可收回时**资本化为资产**，按与履约一致的**系统基础摊销**。
* **无论是否取得合同都会发生的成本**：发生时**费用化**。

**⚠️易错**：合同成本 ≠ 当期费用；只有「增量成本」才可资本化。

## 12.12 质保（Warranty）（补漏）

* **保证类质保（assurance-type，保证产品合格）**：**不**构成单独履约义务；实际维修成本进 cost of sales，可提前计提预计负债。
* **服务类质保（service-type，额外延长保修服务）**：属**单独履约义务**，需分摊交易价格、分期确认收入。

**⚠️易错**：区分两类；只有服务类质保才单独分摊并分期确认。

## 12.13 收入章高频易错清单

| **❌ 常见错误**        | **✅ 正确**                      |
| ----------------- | ----------------------------- |
| 合同必须书面            | 书面/口头/默示均可                    |
| Step1 五条件满足任一     | 五条**全部**满足                    |
| 所有商品都是单独履约义务      | 须满足 **distinct**              |
| 交易价格 = 合同标价       | 需调整可变对价/融资成分/非现金对价/应付客户对价/代收款 |
| 所有合同都要折现          | 仅**重大**（通常 ≥1 年）才折现           |
| 合同资产 = 应收         | 合同资产 = 已赚未开票；应收 = 已开票未收款      |
| 收款影响合同资产          | 收款**不影响**公式                   |
| 已确认收入 \< 已开票 = 资产 | 是**合同负债**                     |
| 合同资产/负债只用于亏损合同    | 所有建造合同都要算                     |
| 代理人按总额确认          | 代理人按**佣金净额**                  |
| 现金返利确认费用          | **冲减交易价格**                    |
| 可变对价全额计入          | 仅「极可能不发生重大转回」部分               |
| 只能用投入法            | 可用**产出法或投入法**                 |
| 亏损完工时才确认          | **立即全额确认**                    |
| 完工无法可靠计量 → 收入 0   | 按**已发生可收回成本**确认（零利润）          |

# 第13章 外币（Foreign Currency — IAS 21）

> 考试形式：Section A/B 计算题（判断汇率使用是否正确、货币性项目期末重算、汇兑差额方向）；一句话重点：**交易用交易日汇率，期末货币性项目用期末汇率，汇兑差额进 P/L；非货币性项目不重算**。

## 13.1 功能货币 vs 列报货币

* **Functional currency（功能货币）** = 企业所处**主要经济环境（primary economic environment）** 的货币。
* **Presentation currency（列报货币）** = 编制财务报表所使用的货币，**可与功能货币不同**。
* 功能货币**只在基础经济环境变化时**才变更，不能随意变更。

**⚠️易错**：功能货币 ≠ 列报货币；**列报货币不能用来判断功能货币**；判断依据是「**主要经济环境**」，不是注册地/母公司所在地。

## 13.2 功能货币的判断指标

① 主要影响**销售价格**的货币；② **竞争力量与法规主要决定售价**的国家的货币；③ 主要影响**人工、材料及其他成本**的货币（另可考虑融资与现金收支货币）。

**⚠️易错**：需**综合判断**，不能只看单一因素。

## 13.3 初始确认（Initial Recognition）

* 使用 **交易日即期汇率（spot rate）**，或
* **平均汇率（average rate）** —— 前提是**汇率没有大幅波动**（has not fluctuated significantly）。

**⚠️易错**：平均汇率不能随意使用；收入/费用**不得**用**期末汇率**折算。

## 13.4 期末重算（Subsequent Measurement）

| **项目类型**                                                                                                                         | **内容**                                           | **期末处理**              |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | --------------------- |
| **货币性项目（Monetary）**                                                                                                              | Trade receivables、Trade payables、Cash、Loans（含借款） | 按 **closing rate 重算** |
| **非货币性·历史成本（Non-monetary at HC）**                                                                                                | PPE、Intangible assets、Inventory                  | 用**交易日汇率**，**不重算**    |
| **非货币性·公允价值（Non-monetary at FV）**                                                                                                | FV 计量的资产                                         | 用**确定公允价值当日汇率**       |
| **📌考点**：区分货币性 / 非货币性是本章核心。                                                                                                      | ​                                                | ​                     |
| **⚠️易错**：① **存货**属非货币性，期末**不重算汇率**（即便减值）；② **预付账款（prepayment）**&#x5C5E;非货币性，**不重算**；③ 货币性项目（TR/TP/现金/贷款）**必须**用 closing rate 重算。 | ​                                                | ​                     |

## 13.5 汇兑差额（Exchange Differences）

* 货币性项目在**结算时**或**期末重算时**产生的汇兑差额，**计入 P/L**。
* （IFRS 18）汇兑差额的分类应与产生该差额的项目列示在**同一类别**（如融资相关负债的汇兑差额列于 financing category）。

**⚠️易错**：① 汇兑差额全部进 P/L；② 判断 **gain/loss** 必须结合**标价方式（A:B 的报价方向）** —— 报价方式反转会改变方向。

## 13.6 结算与多步骤交易

* **赊销外币应收**：初始确认用**交易日汇率**；收款日用**收款日汇率**；差额为汇兑损益。
* **采购外币**：**存货**按**交易日/收货日汇率**计价（**不重算**）；**应付账款**（货币性）**持续重算至结算日**。
* **跨期多步骤**（订货→收货→部分付款→期末→余款）：**逐段**用各自汇率确认汇兑差。

**⚠️易错**：

① 未入账的外币销售，其**毛利**按**交易日汇率**确认收入；期末应收重算的汇兑差额**不影响毛利**（进财务/其他项目）；

② 外币借款属**货币性**项目，每期按期末汇率重算；汇率下降（外币贬值）→ 负债减少 → **汇兑收益**。

## 13.7 外币易错总结

| **考点**       | **易错点**                    |
| ------------ | -------------------------- |
| 功能货币 vs 列报货币 | 可不同；功能货币由**主要经济环境**决定      |
| 初始确认         | 交易日 spot 或平均汇率（不可随意用平均）    |
| 期末货币性项目      | 必须 closing rate 重算，差额进 P/L |
| 期末非货币性（HC）   | 不重算汇率（**存货不调**）            |
| 存货采购         | 存货不调，**应付账款（货币性）要调**       |
| 汇兑差额方向       | 结合**标价方式**判断 gain/loss     |
| 外币借款         | 货币性，期末重算，差额进 P/L           |
| 多步骤交易        | 各步汇率不同，逐段确认汇兑差             |

# 第14章 每股收益（Earnings per Share — IAS 33）

> 考试形式：Section A 选择题高频（WANS 计算、TERP、可转债税后利息、期权库藏股法）；一句话重点：**分子 = 归属普通股股东的利润；分母 = 发行在外普通股加权平均数（WANS）**。

## 14.1 定义与公式

* `EPS = (PAT − Preference dividend − Profit attributable to NCI) ÷ Number of ordinary shares`
* 或简写：`EPS = Profit for the year made for ordinary shareholders ÷ Number of ordinary shares`**⚠️易错**：分子必须为**归属普通股股东**的利润 —— 忘记扣减**优先股股息**、**归属于 NCI 的利润**（合并报表）。

## 14.2 基本每股收益（Basic EPS）

`Basic EPS = 归属普通股股东的利润 ÷ 加权平均股数（WANS）`分三种情形（FR 最高频考点之一）：

### (1) 按市价发行新股（Issue at full market price）

* 新股从**发行日**起做**时间加权**；**不追溯调整对比期**。
* `WANS = Σ（各时点股数 × 该期间占全年比例）`。

### (2) 送股 / 红股（Bonus issue / Capitalisation issue）

* 无对价，仅将留存收益转股本，**净资产不变**（蛋糕只切得更碎）。
* 视同**全部期间**均已发行 → **不做时间加权**。
* 调整系数 = 送股后总股数 ÷ 送股前总股数（如 1 for 4 → 5/4）。
* **对比期（prior year）必须按新股数重述（restated）**。

**⚠️易错**：① 对送股做时间加权（错）；② 忘记重述上年 EPS（重述后变小是正常的）。

### (3) 配股（Rights issue）— TERP 四步法 ★★★

配股含「红利元素」（认购价通常低于市价），既含对价又含折价，需用**理论除权价（TERP）**&#x8C03;整。

* **Step 1** `TERP = (配股前市价 × 配股前股数 + 认购价 × 新增股数) ÷ 配股后总股数`
* **Step 2** 调整系数（bonus factor）= **配股前市价 ÷ TERP**；`调整后配股前股数 = 配股前股数 × 调整系数`
* **Step 3** `WANS = 调整后配股前股数 × 配股前期间占比 + 配股后股数 × 配股后期间占比`
* **Step 4** `EPS = 利润 ÷ WANS`；**对比期用调整后的股数重述**📌考点：送股 = 无对价、全期重述；配股 = 有对价、用 TERP 调整系数 + 对比期重述。

**⚠️易错**：① 调整系数是 **市价/TERP**（**不是** TERP/市价）；② 系数**只调整「配股前」那段股数**；③ 对比期也要用调整后股数重述；④ 与送股调整系数混淆。

## 14.3 稀释每股收益（Diluted EPS）— 概念

* 含义：假设**全部稀释性潜在普通股（dilutive potential ordinary shares）**&#x5728;当期期初/发行日已转换时，**当期**的 EPS 会是多少；**不是对未来 EPS 的预测**。
* 作用：提示股东未来回报可能下降。
* 只有 **dilutive（稀释性）** 的潜在普通股才纳入；**反稀释（anti-dilutive）**&#x7684;忽略。

### (1) 可转换债券（Convertible loan note）

* **分子**：加回**税后**利息 = 利息 × (1 − tax rate)（假设转股后不再付息）。
* **分母**：加**转换新增股数**（按转换条款计算）。
* 年内发行 → 利息与股数均按**时间加权**。

**⚠️易错**：① 加回**利息总额**（错）—— 必须**税后**；② 忘记时间加权；③ 只改分母或只改分子。

### (2) 期权 / 认股权证（Share option）— 库藏股法（Treasury share method）

* 假设期权行权，行权所得按**当年平均市价**回购股份；仅**净增发股数（free shares）**&#x8BA1;入分母：
  * `free shares = 期权股数 −（行权收入 ÷ 平均市价）`
  * **分子不做调整**（无利息节省）。

**⚠️易错**：① 用**期末市价**（错，应**平均市价**）；② 直接把期权股数全部计入分母（未扣回购部分）；③ 对期权做分子调整；④ 未判稀释性（行权价 ≥ 平均市价 → 反稀释，忽略）。

## 14.4 重要性 & 局限性

* 用途：`P/E ratio = 市价 ÷ EPS`；`Dividend yield = DPS ÷ 市价`；`Dividend cover = PAT ÷ 股利`。
* **EPS 趋势比净利润趋势更可靠的原因**：EPS 考虑了**发行新股带来额外资源**创造利润的能力，而净利润绝对值不反映这一点。
* **局限性**：① 未考虑**通胀**（表面增长可能非真实）；② 基于**历史**信息，未必有预测价值；③ 受**会计政策**选择影响，跨公司未必可比（政策/资本结构/规模/市场不同）。

## 14.5 披露（Disclosure，IAS 33）

* 强制披露：所有**潜在稀释工具**（期权、可转债等）。
* 资产负债表日后、报表批准前新发行的普通股需说明（不影响本期计算）。
* 优先股**股利金额**需用/披露；优先股**股数**不强制披露。
* 只要有潜在稀释工具，**稀释 EPS 必须列报**。

## 14.6 EPS 易错总结

| **考点**   | **易错点**                           |
| -------- | --------------------------------- |
| 分子       | 必须扣**优先股股息**与 **NCI**             |
| 市价发行     | 从发行日**时间加权**，对比期**不重述**           |
| 送股       | **全期重述**，系数 = 送股后/送股前             |
| 配股四步法    | TERP → 市价/TERP 系数 → 加权 → 对比期重述    |
| 送股 vs 配股 | 送股无对价；配股用 TERP                    |
| 可转债      | 分子加**税后**利息，分母加潜在股数               |
| 期权       | free shares = 期权数 − 行权收入/**平均市价** |
| WANS     | 按时间加权，**不能用期末数**                  |
| 对比期重述    | 送股、配股都要重述                         |
| 稀释性      | 只有**稀释性**（非反稀释）才纳入                |

# 第15章 现金流量表（Statement of Cash Flows，IAS 7）

> 考试形式：Section A 选择（2–4 分）+ Section C 编制完整现金流量表（14–20 分，间接法）。一句话重点：**以营业利润为起点，用工作底稿把「非现金项目 + 营运资本变动 + 倒挤出的税款/利息/股利」还原为经营活动现金净流量。**

## 15.1 现金及现金等价物（Cash and Cash Equivalents）

* **Cash（现金）**：库存现金 + 活期存款（含可随时偿还的银行透支）。
* **Cash equivalents（现金等价物）**：**短期（≤3 个月到期）**、高流动性、可随时转换为**已知金额现金**、且价值变动风险极小的投资（如 90 天国库券、银行存款账户）。

**📌考点**：哪些项目**不属于**现金及现金等价物——**未提取的短期借款额度（undrawn short-term borrowing facilities）**、非随时偿还的透支。

**⚠️易错**：把"未提取借款额度"当现金等价物（❌）；透支只有**随时偿还（payable on demand）**&#x65F6;才作为现金等价物减项。

## 15.2 格式与三类活动分类（Format & Classification）

* 所有项目**必须归入三类之一**：Operating / Investing / Financing。
* **利息收入、股利收入 → Investing（投资活动）**。
* **利息支付 → Financing（筹资活动）**；但**已资本化的利息（IAS 23）不计入**。
* 股利支付 → Financing；投资性房地产租金收入 → Investing。
* **不涉及现金的投资/融资交易**（以股换股、以股换资产、债转股等）→ **不列入**现金流量表，只在附注披露。

**📌考点**：判断"哪两项陈述正确"型选择题——三类分类齐全、利息/股利归属、资本化利息排除、非现金交易排除。

**⚠️易错**：把利息收入/股利收入归 Financing（❌，应 Investing）；把资本化利息当"利息支付"（❌）；把非现金投资/融资交易列入表内（❌）。

**⚠️易错**：租赁付款——**本金→筹资**；**利息→筹资**（若政策将利息列经营则按经营，须**前后一致**并披露依据）。

## 15.3 间接法调整原理（Indirect Method）

以营业利润（或税前利润）为起点，调整非现金项目、非经营项目与营运资本变动。

| **调整项目**       | **方向** | **原因**      |
| -------------- | ------ | ----------- |
| 折旧/摊销          | ➕      | 非现金费用       |
| 资产减值损失         | ➕      | 非现金         |
| 处置非流动资产**损失**  | ➕      | 非经营损失       |
| 处置非流动资产**利得**  | ➖      | 非经营收益       |
| 利息费用（含在起点利润中时） | ➕      | 随后在筹资活动列支   |
| 存货减少 / 增加      | ➕ / ➖  | 现金回流 / 占用   |
| 应收款减少 / 增加     | ➕ / ➖  | 收回现金 / 占用   |
| 应付款增加 / 减少     | ➕ / ➖  | 延期付款 / 支付现金 |

**📌考点**：调整方向的判断（资产增加=现金流出，负债增加=现金流入）。

**⚠️易错**：折旧、减值加回，处置**损失加回、利得减去**（方向易反）。

## 15.4 编制工作底稿：倒挤法（Workings — Balancing Figures）

以括号内为"倒挤"出的现金数：

```
W-PPE
  期初余额                     X
  购置（倒挤 balancing figure）  X
  重估增值 / 其他非现金增加      X
  转入（投资性房地产等）         X
  折旧                        (X)
  处置（账面价值）             (X)
  期末余额                     X

W-无形资产
  期初 + 购置 - 摊销（倒挤）- 减值 = 期末

W-留存收益
  期初 + 本年利润 - 已付股利（倒挤）= 期末

W-应付利息
  期初 + 利息费用 - 已付利息（倒挤）= 期末

W-应付税款（current tax + deferred tax 合并为一个余额）
  期初(CT+DT) + 所得税费用 - 已付税款（倒挤）= 期末(CT+DT)
```

**📌考点**：购置 PPE/无形资产、已付股利/利息/税款**全部用倒挤法**；处置所得现金 = **处置资产账面价值 + 处置利得（− 处置损失）**。

**⚠️易错**：

* PPE 倒挤时**漏掉"非现金增加项"**：重估增值、**以非现金方式资本化的成本**（如资本化的环境准备/借款成本）、投资性房地产或在建工程转入——这些都要在倒挤购置前从期末余额"扣除"。
* 税款工作底稿要把**流动税与递延税合并**为一个余额（期初、期末均取合计）。
* 无形资产摊销**同样倒挤**（期初 + 购置 − 摊销 = 期末），无减值时可直接倒算。
* 已付股利用留存收益底稿倒挤；若年内有新股发行/重估，需先排除再倒挤。

## 15.5 现金流量表解读（Interpretation）

* **经营活动**：与营业利润对比；**过度交易（overtrading）信号** = 高利润但低现金生成 + 存货/应收/应付**大幅上升**。讨论时联系营运资本管理及其对供应商/客户关系的影响。
* **股利与利息支付**：与经营现金对比，若经营现金**不足以覆盖** → 持续经营（going concern）风险；若能覆盖，剩余为**自由现金（free cash）**，分析其用途（购置资产/还款/分红）。
* **投资活动**：出售资产后**替换**是好事；但变卖厂房改为租赁会削弱财务状况（可抵押资产减少，银行不愿贷款）；**绝不能用出售资产的钱维持经营或支付股利**（不可持续）。
* **融资活动**：新借款 → 未来利息与定期还款压力；偿还借款 → 减轻未来现金流压力；发行股份 → 无需偿还、无利息，但股东预期无限期股利。
* **现金净变动**：不要单看此数——减少可能源于上年现金盈余，或时点因素（如借款发生在年末之后）；须结合报表其他部分判断，且存在**操纵空间**。

**📌考点**：判断经营现金是否用于购建非流动资产；识别过度交易信号。

**⚠️易错**：孤立解读"现金减少"就断言公司有问题。

## 15.6 高频易错对比表

| **易错点**    | **正确理解**                                    |
| ---------- | ------------------------------------------- |
| 现金等价物范围    | ≤3 个月到期、高流动性、价值变动风险极小；**未提取借款额度不含**         |
| 利息/股利分类    | 利息收入、股利收入 → **投资**；利息支付、股利支付 → **筹资**       |
| 资本化利息      | 不计入"利息支付"                                   |
| 非现金投资/融资交易 | **不列表内**，仅附注披露                              |
| 间接法调整      | 折旧、减值、处置损失 → 加回；处置利得 → 减去                   |
| 营运资本方向     | 资产增加 = 流出（−）；负债增加 = 流入（+）                   |
| PPE 倒挤     | 期末 + 折旧 + 处置 − 期初 − 重估 − **非现金资本化/转入** = 购置 |
| 税款倒挤       | 流动税 + 递延税**合并**一个工作底稿                       |
| 过度交易       | 高利润低现金 + 存货/应收/应付大幅增加                       |

# 第16章 合并财务状况表（Consolidated Statement of Financial Position，IFRS 10）

> 考试形式：Section A 选择（控制判断、商誉/NCI/合并 RE 单点计算）+ Section C 编制完整合并 SOFP（14–20 分）。一句话重点：**P + S 逐行相加、抵消对 S 的投资与 S 的权益、差额进商誉，按持股比例分出 NCI，并把所有内部交易抵销。**

## 16.1 集团定义与控制（Group & Control）

* **Group（集团）** = Parent（母公司）+ 所有 Subsidiaries（子公司）。
* **Parent**：控制一个或多个主体的主体；**Subsidiary**：被另一主体控制的主体。
* **Control（控制）三要素——必须同时满足**：
  1. **Power（权力）**：对被投资方相关活动拥有现时可主导的能力；
  2. **Exposure/rights to variable returns（可变回报）**：享有/承担被投资方回报变动；
  3. **Link（联动）**：能运用权力影响自身回报金额。
* **权力来源**：多数表决权或**潜在表决权**；任免关键管理人员；任免主导相关活动的主体；主导/否决交易；管理合同约定的其他权利。

**📌考点**：控制三要素的辨认——"取得 50% 以上股权"**不是**控制要素（只是常见情形）；少数股权也可能因**可立即行使的期权（currently exercisable options）**、**投票权委托协议（voting agreement）**、任免多数董事等构成控制。

**⚠️易错**：仅凭持股比例机械判断控制/合并；忽略潜在表决权与协议安排。

## 16.2 合并豁免、报告日与会计政策

* **豁免合并（IFRS 10）须同时满足全部条件**：① 母公司自身为全资子公司或部分持有且其他所有者已知悉并不反对；② 其证券**未公开交易**；③ **未在**公开市场**发行证券过程中**；④ 最终/中间母公司按 IFRS 公布合并报表。
* **子公司纳入**：全部纳入，**仅当"失去控制"才排除**。
* **报告日**：母子公司通常应一致；若不同，子公司须为合并另编同日数据；**确不可行时**用最近报表并按重大交易调整，**差异不得超过 3 个月**且各期一致。
* **会计政策**：合并报表中须**统一**为母公司政策（仅在合并层面调整，**不要求**子公司单体报表改政策）。
* 母公司**单体报表**中，对子公司/联营按成本 / IFRS 9（FVTPL、FVTOCI）/ 权益法核算。

**📌考点**：以下情形**仍须合并**——子公司**亏损**、**经营活动差异很大**（如银行并入制造集团）、**当地会计准则与 IFRS 不兼容**、**拟出售但仍控制**；**不合并**的唯一情形是**失去控制**（如政局动荡丧失控制权）。**非持有待售**的拟出售不影响合并。

**⚠️易错**：以"经营性质不同""想出售""当地准则不同"为借口不合并（❌）；或对未公开交易豁免条件乱套。

## 16.3 合并基本原理表（Basic Principle）

**核心原则**：集团 = **单一经济实体（single economic entity）**，母子资产/负债逐行相加并消除内部交易。

| **项目**      | **Parent** | **Subsidiary** | **Consolidated**                    |
| ----------- | ---------- | -------------- | ----------------------------------- |
| 非流动资产       | X          | X              | **P + S**                           |
| 对 S 的投资成本   | X          | —              | **0（抵消）**                           |
| 商誉 Goodwill | —          | —              | **对价 + NCI − S 可辨认净资产 FV**          |
| 流动资产        | X          | X              | **P + S**（消除内部往来）                   |
| 股本 / 股本溢价   | X          | X              | **仅列 P**（S 的股本全额抵消）                 |
| 留存收益        | X          | X              | **= P + S 购后 RE×S% − 商誉减值×S%**      |
| 其他权益成分 OCE  | X          | X              | **= P + S 购后 OCE×S%**               |
| **NCI**     | —          | —              | **S 年末净资产×NCI% + 商誉中 NCI 部分**（FV 法） |
| 流动/非流动负债    | X          | X              | **P + S**（消除内部往来）                   |

**口诀**：P 的"投资成本"→0；S 的"全部权益"→0；差额进**商誉**；非 100% 控股 → 差额分**NCI**。

**📌考点**：合并**总权益** = 母公司股本 + **合并留存收益**（+ 合并 OCE）；S 的股本**不出现在**合并报表。

**⚠️易错**：把 S 的股本也相加；或漏掉商誉/NCI 行。

## 16.4 购买对价（Consideration）

* 对价按**收购日公允价值**计量，计入 P 单体"投资成本（cost of investment）"：

| **对价类型**              | **确认方式**                                                            |
| --------------------- | ------------------------------------------------------------------- |
| 现金对价                  | 实际支付现金                                                              |
| 债券/贷款票据对价（debenture）  | 收购日公允价值                                                             |
| 以股换股（share-for-share） | **发行给 S 股东的 P 股数 × 收购日 P 股价**                                       |
| **递延对价**（deferred）    | **收购日现值**（可含条件）；后续按**实际利率法滚利息**：`Dr 财务费用 / Dr 集团留存收益（P）/ Cr 递延对价负债` |
| **或有对价**（contingent）  | **收购日公允价值**；后续每期末**重新计量**，变动计入**当期损益/留存收益**                         |

* 递延对价折现率用**适当的折现率**（母公司资本成本 / 增量借款利率）；**不因市场利率变动而重估**。

**📌考点**：递延对价必须**折现**；或有对价按**收购日 FV** 计入对价；折现利息最终从**P 的留存收益**扣除并增加负债。

**⚠️易错**：用未折现的递延金额入对价；把递延对价利息计错（应同时影响 RE 与负债）；以股换股漏乘"发行股数/交易比例"。

## 16.5 编制七步法（Seven Steps）

* **Step 1 集团结构（W1）**：持股 %、**收购日**、收购日 S 的 RE 与 OCE、NCI FV。
* **Step 2 Pro forma SOFP**：删去"投资成本"，加入 **Goodwill、Investment in associate、NCI、递延对价**等行。
* **Step 3 填数**：资产/负债 = **P + S 100%**；股本/股本溢价 = **仅 P**。
* **Step 4 子公司净资产（W2）**：逐项列 **收购日 / 合并日 / 购后变动**。
* **Step 5 商誉（W3）**。
* **Step 6 NCI（W4/W6）**。
* **Step 7 集团留存收益（W5）+ 内部交易抵销**。

## 16.6 子公司净资产（W2）

```
                        收购日    合并日    购后变动
股本 / 股本溢价          X        X        0
留存收益                X        X        X
会计政策调整(policy)      X        X        X
差错更正(error)          X        X        X
FV 调整–PPE(HCA)        X        X        X
        –PPE(重估模型)   X        X        X
        –存货           X        X        X
        –或有负债        X        X        X
额外折旧(additional depn) 0     (X)      (X)
URP（S→P 逆流）          0       (X)      (X)
合计                    X1       X2       X3
```

* **FV 调整**：收购日资产 FV > 账面 → 调增收购日净资产；购后按剩余寿命**补提额外折旧**。
* **会计政策/差错**：统一为 P 政策、更正差错（**购后**影响属购后变动）。
* **URP**：**仅逆流（S→P）**&#x5728; W2 中扣减（因 S 是卖方，影响 S 利润）；顺流不减。

**📌考点**：W2 中"购后变动"决定**合并留存收益与 NCI**；收购日数决定**商誉**。

**⚠️易错**：把顺流 URP 也放进 W2；收购日与合并日的政策调整放错栏。

## 16.7 商誉（Goodwill — W3）

```
                                    $/$
Cost of investment（对价，W1）        X
+ 收购日 NCI 公允价值                  X      ← 仅"全部商誉法 FV method"
− 收购日 S 可辨认净资产 FV（W2 收购日） (X)
= 收购日商誉                          X
− 累计商誉减值                        (X)
= 合并日商誉                          X
```

* **FV method（全部商誉法 / full goodwill）**：NCI 含商誉部分（加入 NCI FV）。
* **Proportionate method（比例法 / partial goodwill）**：只按 P% 计，**不含 NCI 的商誉**。
* **负商誉（negative goodwill / bargain purchase）**：**计入当期损益（profit or loss）**，**不冲减正商誉**。
* 商誉**不摊销**，每年减值测试，减值**不可转回、不可重估增值**。
* 确认**资产 / 调增资产 FV** → 净资产↑ → **商誉↓**；确认**负债 / 调增负债 FV** → 净资产↓ → **商誉↑**。
* **内部产生的无形资产**（客户名单、品牌等）**不单独确认**，其价值**包含在商誉**中；**尚未存在/未来事项**（如尚在谈判的客户）不计入。

**📌考点**：两种方法的 NCI/商誉差异；收购完成后资产/负债 FV 调整对商誉的**方向**（资产↔商誉反向，负债↔商誉同向）。

**⚠️易错**：比例法下误将 NCI 商誉计入；把负商誉冲减正商誉（应进损益）；把内部产生的客户名单按专家估值单独确认。

## 16.8 合并留存收益与其他权益（W5）

```
P 单体留存收益                                   X
+ P% × S 购后留存收益（W2 购后变动中 RE 部分）    X
− P% × 累计商誉减值                              (X)
+ P% × 联营企业购后留存收益                       X
− 联营企业减值                                   (X)
− 顺流 URP（P→S）全额                            (X)
− 递延对价折现利息（unwinding interest）          (X)
= 合并留存收益                                   X
```

* 若只算"留存收益"→ 用 S 购后 **RE**；若算**其他权益成分/重估盈余**→ 用 S 购后 **OCE/重估盈余**×P%。
* 合并 OCE（重估盈余等）= **P 的 OCE + S 购后 OCE 变动 × P%**。

**📌考点**：`合并 RE = P RE ± 上述调整`；重估盈余/OCE 单独按 P% 加总。

**⚠️易错**：顺流 URP 未从 P 的 RE 中扣除；商誉减值未按 P% 扣；漏扣递延对价利息。

## 16.9 NCI（W6）

**FV method（一般考试指定）**：

```
收购日 NCI 公允价值                              X
+ NCI% × S 购后净资产变动（W2 购后变动，含 FV 调整、额外折旧、逆流 URP）  X
− NCI% × 商誉减值                                (X)
= 合并日 NCI                                     X
```

**Proportionate method**：`NCI = 购后 S 净资产 × NCI%`（**不含商誉**）。

* NCI 的**收购日 FV** 可用 S 股价×NCI 持股数等估计。
* **逆流（S→P）URP** 要**减少 S 购后利润**→ 进而减少 NCI；顺流不影响 NCI。
* **商誉减值**在 FV 法下按持股比例由 P 与 NCI 分担。

**📌考点**：NCI = 收购日 FV + NCI%×(购后 RE/OCE 变动 − 额外折旧 − 逆流 URP − 商誉减值)。

**⚠️易错**：NCI 用顺流 URP 调整；FV 法与比例法混用；漏掉购后重估盈余/OCE 的 NCI 份额。

## 16.10 内部交易抵销（Intra-group Adjustments）

**① 内部债权债务 / 在途现金（current account / cash in transit / goods in transit）**

* 内部应收 ↔ 内部应付：**全额抵消**（`Dr 应付 / Cr 应收`）。
* **在途现金**：付款方已付、收款方未收到 → 在**收款方（通常母公司）**&#x8C03;账 `Dr Bank / Cr 应收`（或反向）。
  * **调整在母公司** → 只是"应收 → 现金"的资产互换，**对流动资产净额影响为零**。
* 内部货物在途：把在途货物记入**买方**账（视作已在年前入账）。

**📌考点**：内部往来要按**净差额**抵消；现金在途调整改变"资产构成"而非总额。

**⚠️易错**：两边应收应付不等时直接对不齐（要先做在途调整）；把在途现金误当作流动资产总额增加。

**② 内部存货交易 — URP（Unrealised Profit）**

* 顺流（P→S）：`Dr 卖方(P) 留存收益 / Cr 存货（买方）` → **全额归 P，不影响 NCI**。
* 逆流（S→P）：`Dr 卖方(S) 购后利润 / Cr 存货（买方）` → **按比例影响 NCI**。

URP 计算：

* **gross margin（毛利率 = 毛利/售价）**：`URP = 期末存货价值 × 毛利率`
* **mark-up（成本加成率 = 毛利/成本）**：`URP = 期末存货价值 × [mark-up / (1 + mark-up)]`

**📌考点**：URP 只针对**期末仍未售出集团外部**的存货；方向决定是否动 NCI。

**⚠️易错**：把 mark-up 当 margin 用；顺流 URP 调了 NCI（不应调）；已全部对外售出仍提 URP。

**③ 内部 PPE（非流动资产）交易——两步调整**

```
Step 1 抵消出售方利得：Dr 出售方利得/RE  /  Cr 买方 PPE（= 售价 − 账面）
Step 2 转回买方多提折旧：Dr 买方 PPE  /  Cr 买方折旧/RE（= 利得 / 剩余寿命 × 购后期间）
```

* 顺流（P 卖给 S）：利得从 **P 的 RE** 扣（不影响 NCI）；
* 逆流（S 卖给 P）：利得从 **S 购后利润**扣（**影响 NCI**），第二步转回折旧**贷记买方 P**。

**📌考点**：两步缺一不可；合并 PPE = P + S − URP + 转回的多提折旧。

**⚠️易错**：只抵利润不转折旧（或反之）；逆流时未把利得从 S 购后利润中扣从而错算 NCI。

**④ 内部股利（intra-group dividend）**

* 只需抵消**应收股利 / 应付股利**；若股利**已实际支付**并已各自入账，则**无需**抵销。

**⑤ 内部贷款/票据**：抵消投资方"对内部贷款的投资/应收"与借款方的"内部借款负债"。

## 16.11 其他合并事项（Other Events）

* **年中收购（mid-year acquisition）**：资产负债表**全额（100%）并入** S 的资产与负债；**利润表只并入购后期间**（按 `n/12`）。影响比率分析（如 ROCE：资产全年、利润只含购后）。
* **处置子公司**：合并利润表**截至处置日**；合并 SOFP **不再包含**任何 S 资产/负债，也**无相应 NCI**；处置利得/损失归 P（不与 NCI 分配）。
* **子公司之间交易**：与 P–S 交易处理相同，**全额抵消**。

**📌考点**：年中收购对 SOFP（全额）与 SOPL（比例）的差异。

**⚠️易错**：年中收购时把 S 资产负债表按比例并入（应 100%）。

# 第17章 合并财务业绩表（Consolidated Statement of Financial Performance）

> 考试形式：Section A 选择 + Section C 编制大题（含处置/终止经营）。一句话重点：**P 100% + S 收购后 100%，按 NCI% 分配归母与少数股东，内部交易全额抵销、URP 方向决定是否动 NCI。**

## 17.1 基本原理与利润归属

* 合并利润表目的：把集团视为**单一经济实体（single entity）**&#x5217;报经营成果，展示母公司**通过控制**所实现的利润。
* 合并基础：**收入/费用 = P 100% + S 收购后期间 100%**（按时间比例 `n/12`）——因为控制的是全部资产与业务。
* 利润归属结构：

| **项目**                                 | **计算**                    |
| -------------------------------------- | ------------------------- |
| Profit attributable to Owner of Parent | **倒挤数（balancing figure）** |
| Profit attributable to NCI             | S 调整后 PFY × NCI%          |
| TCI attributable to Owner of Parent    | 倒挤数                       |
| TCI attributable to NCI                | S 调整后 TCI × NCI%          |

**📌考点**：合并逻辑起点是"控制"→ 100% 并入 S；归属调节（ownership reconciliation）列于表尾。

**⚠️易错**：年中收购时 S **只并入收购后期间**，绝不能全年合并。

## 17.2 编制步骤与利润表格式

* **Step 1** 画集团结构图 + 时间线（标注收购日/处置日）。
* **Step 2** 画 Pro forma：预留①商誉减值行 ②应占联营企业利润/OCI 行 ③表尾所有权调节。
* **Step 3** 按合并原则填数（收入费用 P 100% + S 购后 100%）。
* **Step 4\~7** 做调整 → 算 NCI PFY → 算 NCI TCI → 完成归属调节（母公司=倒挤）。
* 合并利润表（CSOPLOCI）行项目顺序：Revenue → Cost of sales → Gross profit → 各项费用 → **Goodwill impairment** → Operating profit → **Share of profit of associate** → Investment income → **PBFIT**（profit before financing and income taxes）→ Interest expense → PBT → Tax → **Profit for the year** → OCI → **TCI** → 归属调节。

**📌考点**：`Goodwill impairment` 列于 **Operating profit 之前**；`Share of profit of associate` 列于 **Operating profit 之后、PBT 之前**（属 investing 类别，IFRS 18）。

**⚠️易错**：把联营应占利润并入 operating profit 或收入费用中（应单列一行）。

## 17.3 集团内部交易抵销（Intra-group Elimination）

**① 内部购销**：`Dr 卖方 Revenue / Cr 买方 Cost of sales`**② 未实现利润 URP**（仅针对期末仍未售出集团外部的存货）：

* **顺流 P→S**：`Dr 卖方(P) Cost of sales / Cr 买方(S) Inventory` → **不影响 NCI**
* **逆流 S→P**：`Dr 卖方(S) Cost of sales / Cr 买方(P) Inventory` → **影响 NCI**

URP 公式：`URP = 内部销售利润 × 期末未对外售出比例`

* 按 **mark-up（成本加成率 = 毛利/成本）**：`URP = 售价 × [mark-up/(1+mark-up)] × 未售比例`
* 按 **gross margin（毛利率 = 毛利/售价）**：`URP = 售价 × gross margin × 未售比例`

**③ 内部应收应付**：`Dr 应付 / Cr 应收`**④ 内部股利**：`Dr Investment income (P) / Cr Dividend paid (S)`（P 收到 S 的股利在合并中全额抵销）

**⑤ 内部贷款利息**：`Dr 出借方 interest income / Cr 借入方 interest expense`（考官答案：**无后续影响**）

**📌考点**：URP 方向决定是否影响 NCI；mark-up 与 margin 的互换是计算关键。

**⚠️易错**：把 mark-up 当 gross margin 用；顺流 URP 调了 NCI（不应调）。

## 17.4 公允价值调整与补提折旧

* 收购日资产 FV > CV → 集团补提**额外折旧（additional depreciation）**：`(FV − CV) / 剩余使用寿命`，购后期间按 `n/12`；计入 Cost of sales 或 Operating expenses（视资产类别）。
* 或有负债 FV 调整（购后变动一般不再调整，除计量差错）。
* 存货 FV 调整：购后售出时转入 Cost of sales。
* 若 P 采用**重估模型**，需按 P 政策对 S 资产作相应处理（FV 调整部分入 OCE）。

**📌考点**：FV 调整影响 S 的购后利润，进而影响 NCI 应占额。

**⚠️易错**：漏补额外折旧，或未按购后期间比例分摊。

## 17.5 商誉减值（Goodwill Impairment）

* 商誉减值在合并利润表中作为**一项费用全额扣除**（full goodwill 法下损失全部计入集团 P/L）。
* 计算 NCI 应占利润时，再按 **NCI% 分摊**该减值（减少 NCI）。
* **减值不可转回**。

**📌考点**：full goodwill 法下商誉减值先在集团层面全额列示，再在 NCI working 中按 NCI% 扣除。

**⚠️易错**：漏按 NCI% 分摊；误以为减值可转回。

## 17.6 集团内部固定资产（PPE）交易——两步调整

1. **抵销卖方处置收益**：`Dr 卖方 gain on disposal（Cost of sales）/ Cr 买方 PPE`
2. **冲回买方多提折旧**：`Dr 买方 PPE（累计折旧）/ Cr 买方 Cost of sales`

**📌考点**：必须做**两步**。

**⚠️易错**：只抵消未实现收益而漏了买方多提折旧的冲回。

## 17.7 归属于少数股东的利润（Profit Attributable to NCI）

| **调整项**                                | **说明**                       |
| -------------------------------------- | ---------------------------- |
| S 的 PFY（按 `n/12`）                      | 年中收购的时间比例                    |
| ± Policy adjustment & error correction | 统一会计政策、前期差错更正                |
| ± FV adjustment                        | 公允价值调整                       |
| − Additional depreciation              | 补提额外折旧                       |
| − URP on sales **made by S**           | **仅逆流**才扣                    |
| − Goodwill impairment                  | 按 full goodwill 分摊给 NCI      |
| = 小计 × NCI%                            | = Profit attributable to NCI |

* TCI 归属 NCI 同理：用 S 的 TCI（含 S 的 OCI）调整后 × NCI%。

**📌考点**：NCI 只分 S 的**已实现**利润。

**⚠️易错**：顺流 URP 去扣 NCI；漏 FV 补提折旧或商誉减值。

## 17.8 子公司处置（Disposal）

* **个别报表**：处置损益 = 处置收入 − 投资账面价值（CV of investment）。
* **合并报表两大影响**：
  1. S 的经营成果**合并到处置日为止**；
  2. **处置损益计入合并利润表，全部归母公司（不与 NCI 分享）**。
* **合并处置分录**：

```
Dr Cash                        XX
Dr NCI at disposal date        XX
   Cr 处置日 S 净资产/负债          XX
   Cr 处置日 S 商誉               XX
   Cr Gain on disposal（倒挤）    XX
```

* **合并处置损益公式**：

`Gain/Loss = 处置收入 + 处置日 NCI − 处置日 S 净资产 − 处置日商誉`

**📌考点**：用公式计算，且**处置利得全归母公司**；处置日商誉 = 收购日商誉 − 已减值。

**⚠️易错**：用"售价 − 投资成本"简单计算；漏加 NCI 或漏减商誉；把处置利得分给 NCI。

## 17.9 终止经营（Discontinued Operations，IFRS 5）

* **定义**：符合下列**任一**的"业务组成部分"：①代表一项**独立的主要业务线或主要经营地区**；②作为单独主要业务处置计划的一部分；③**专为转售而取得的子公司**。
* **列报**：在利润表表内列报**一个单一金额（税后）**，含：①终止经营的**税后损益**；②**按公允价值减出售成本计量或处置时确认的税后利得/损失**。
* 需在附注**或表内**分析该金额：收入、费用、税前损益、所得税、处置税后损益。
* **比较期间数据需重述**为终止经营（continuing vs discontinued 分列）。

**📌考点**：单一税后金额 + 重述比较数。

**⚠️易错**：未重述比较数据；把金额拆成多行；混淆 continuing 与 discontinued。

## 17.10 高频考点 / 易错点速查

| **考点**       | **易错点**                              |
| ------------ | ------------------------------------ |
| 时间比例分摊       | 年中收购只并入购后 `n/12`，不能全年                |
| URP 方向影响 NCI | 顺流不影响 NCI；逆流影响 NCI                   |
| 内部股利         | P 收到的 S 股利全额抵销                       |
| 商誉减值         | 集团层面全额列示，NCI working 中按 NCI% 分摊；不可转回 |
| 内部 PPE       | 两步：抵销收益 + 冲回多提折旧                     |
| 处置利得         | 用公式；**全归母公司**；含 NCI 与商誉              |
| 终止经营         | 单一税后金额 + 重述比较数                       |
| 联营/子公司区分     | 联营 URP 按持股比例抵销（非全额）                  |

# 第18章 联营企业（Associates）

> 考试形式：Section A 计算 + 并入合并大题。一句话重点：**权益法单行列报，商誉内含于投资，URP 只按持股比例抵销。**

## 18.1 定义与判断

* **Associate**：集团对其施加**重大影响（significant influence）**&#x4F46;**不构成控制**的企业。
* **重大影响**：参与被投资方财务和经营政策决策的权力，但**不控制**这些政策。
* **推定规则**：持有 **20% 或以上**表决权 → **推定**具有重大影响（**可反驳**）。
* 表明重大影响的证据：在被投资方**董事会派驻代表**、参与政策制定、双方**重大交易**、**管理层互换**、提供**关键技术资料**。

| **投资类型**               | **判断标准**            | **会计处理**               |
| ---------------------- | ------------------- | ---------------------- |
| Subsidiary 子公司         | 控制（一般 >50%）         | 收购法（逐项合并）              |
| Associate 联营           | 重大影响（一般 20%≤持股≤50%） | **权益法（equity method）** |
| Equity investment 权益投资 | 有限影响（一般 \<20%）      | IFRS 9：FVTPL 或 FVTOCI  |

**📌考点**：20% 只是**推定**；即使 \<20%，有董事会席位等证据也可构成重大影响。

**⚠️易错**：把持股比例当作唯一/绝对标准。

## 18.2 合并财务状况表：对联营企业投资（Equity Method）

* **W1 联营企业净资产**：收购日 vs 合并日，得购后变动（Share capital/premium 变动为 0，RE 为购后变动）。
* **W2 联营企业商誉**：

`商誉 = 投资成本 − 集团应占收购日联营 FV 净资产 × A%`；再减**集团应占商誉减值** = 合并日商誉。

* **商誉必须包含在"Investment in associate"内列报，不单独列示为商誉。**
* **W3 对联营投资（两法，结果一致）**：
  * 方法一（净资产+商誉法）：`A% × 合并日净资产（W1） + 未减值商誉（W2） − URP × A%`
  * 方法二（成本推演法）：`收购日投资 FV + 应占购后净资产变动 − 投资减值 − URP × A%`
* **W4 集团留存收益**：P 的 RE + 应占 S 购后 RE − S 商誉减值 + 应占 A 购后 RE − 对联营投资减值 − URP × A%。

**📌考点**：两种方法结果一致，考试任选。

**⚠️易错**：把联营商誉单列在 Goodwill 行（应含在投资内）。

## 18.3 合并利润表：应占联营利润与 OCI

* `Share of profit of associate = 联营购后当期税后利润 × A%（× 时间比例）`
* `Share of OCI of associate = 联营购后当期 OCI × A%（× 时间比例）`
* 列示位置：**Share of profit 列于 Operating profit 之后、PBT 之前**；**Share of OCI 列于 OCI 部分**。

**📌考点**：单列一行，**不并入**集团收入/成本，不产生 NCI。

**⚠️易错**：放错位置（纳入 operating profit）。

## 18.4 三大核心调整

* **① 商誉减值**：按集团应占（A%）→ `Dr Share of profit of associate（或 Group RE）/ Cr Investment in associate`。
* **② URP（只按 A% 抵销）**：
  * **P→A（顺流）**：`Dr Group RE（P 的 RE）/ Cr Investment in associate`（全额计减 P 成本，但不影响 A 自身报表）
  * **A→P（逆流）**：`Dr Group RE（Share of profit of A）/ Cr Inventories (P)`
  * 公式：`URP = 内部销售利润 × 期末未售比例`；`应抵销 = URP × A%`
* **③ 联营向 P 分派股利**：`Dr Dividend income (P) / Cr Investment in associate`（冲减投资，不确认收入）；**若母、联营已各自记录该股利，则无需额外抵销**。

**📌考点**：联营 URP 按 **A% 抵销**（子公司才全额）。

**⚠️易错**：把联营 URP 当子公司全额抵销；把股利当收入。

## 18.5 时间比例与收购日判断

* 年中取得联营：应占利润/OCI 按收购后月份 `n/12`。
* 注意区分**收购前后**的股利与业绩：只应占购后期间利润；投资账面价值 = 成本 + 应占购后利润 − 收到股利 − 减值 − URP×A%。

**📌考点**：时间比例 + 股利冲减投资。

**⚠️易错**：把收购前利润/股利计入应占额。

## 18.6 高频考点 / 易错点速查

| **序号** | **考点**     | **易错点**                                      |
| ------ | ---------- | -------------------------------------------- |
| 1      | 重大影响判断     | ≤20% 不必然非联营；≥20% 需相反证据才推翻                    |
| 2      | 权益法 vs 收购法 | 联营单行列报，不逐项合并，无 NCI                           |
| 3      | 联营商誉       | 含在 Investment in associate，不单列               |
| 4      | URP        | 只按持股比例 A% 抵销                                 |
| 5      | 交易方向分录     | P→A：Dr 成本/Group RE、Cr 投资；A→P：Dr 应占利润、Cr 存货   |
| 6      | 时间比例       | 年中取得按 `n/12`                                 |
| 7      | 股利         | 冲减投资，不确认收入                                   |
| 8      | 投资账面价值     | 两种方法结果一致                                     |
| 9      | 商誉减值       | 不可转回，减少应占利润与投资                               |
| 10     | 列报位置       | Share of profit 在 operating profit 之后、PBT 之前 |

# 第19章 财务报表分析（Interpretation of Financial Statements）

> 考试形式：Section A 比率计算/判断 + Section C 大题（给报表算比率并评论）。一句话重点：**五类比率 + 杜邦分解 + 集团（年中收购/处置）系统性影响 + 比率局限。**

## 19.1 使用者与关注点

| **使用者**  | **关注点**           |
| -------- | ----------------- |
| 股东/潜在投资者 | 投资回报（回报率）、安全性、流动性 |
| 供应商/债权人  | 债务或贷款的安全性、偿付能力    |
| 管理层      | 经营效率、业绩评价、决策      |

## 19.2 盈利能力比率（Profitability）

* **ROCE 资本回报率**：`ROCE = PBFIT / Capital employed`；`Capital employed = 长期融资 = Equity + Debt = 总资产 − 非债务负债`（教材口径）。
* **ROCE 杜邦分解**：`ROCE = (PBFIT/Revenue) × (Revenue/Capital employed) = OPM × Asset turnover`
* **毛利率 GPM**：`Gross profit / Revenue × 100%`
* **营业利润率 OPM**：`Operating profit / Revenue × 100%`
* **资产周转率**：`Revenue / (Equity + Debt)`（次数）
* **ROE 净资产收益率**：`ROE = PAT / Equity × 100%`；杜邦：`ROE = Net profit margin × Equity turnover`（对股东比 ROCE 更相关）。

**GPM 影响因素**：售价变动（竞争）、生产成本（原材料/人工/制费）、**存货盘点错误（影响两年）**、存货跌价冲销、**产品组合（product mix）**、费用重分类入 COGS（如 R\&D）。（**销量本身不影响 GPM**）

**OPM 分析**：与 GPM 趋势是否一致；找**显著增减的单项费用**（广告费、裁员费）；一次性项目（NCA 处置损益）。

* ⚠️ 降低广告费副作用：销量与毛利率可能下降；裁员：节省成本但日后难复聘。

**资产周转率影响因素**：行业（制造业资本密集→低于服务业）、新 NCA 投资（资本立即增加但只贡献 `n` 个月收入→几乎必然下降）、产能未满负荷、**重估增值**（增加 PPE 账面值但不增产能→下降）、资产老化（PPECA 下降→比率上升，不代表变好）。

**📌考点**：ROCE 变动要分清是 **OPM** 还是 **asset turnover** 引起（杜邦）；年中资本注入与重估会使 ROCE 偏低。

**⚠️易错**：把利息费用变动当 OPM 变动（利息在 operating profit 之后，不影响 OPM）；忽略重估对分母的影响。

## 19.3 流动性比率（Liquidity）

* **流动比率**：`Current assets / Current liabilities`
* **速动比率**：`(Current assets − Inventories) / Current liabilities`
* **存货持有天数**：`Inventories / Cost of sales × 365`
* **应收周转天数 TR days**：`Trade receivables / Revenue × 365`（或 / Cost of sales × 365）
* **应付周转天数 TP days**：`Trade payables / Credit purchases × 365`（或 / Cost of sales × 365）
* **营运资金（现金）周期**：`= Inventory days + TR days − TP days`
* **现金状况**：发股利（对未来现金有信心的信号，但更耗现金）；PPE 处置（变卖资产）；售后回租（释放现金但增租赁负债）。

**存货增加的可能原因**：需求不足、控制不善、为折扣大量采购、防缺货、商品特性。

**📌考点**：现金周期、TR/TP days 的分母选择（分母不一致会失真）。

**⚠️易错**：

* 提高流动比率的口径题：**用现金退回存货** → CA 与 CL 等额同减少 → 比率**上升**（>1 时）；
* 用现金大量采购存货 → CA 与 CL 同增 → 比率**下降**；
* 提前支付应付 → CA 与 CL 同减 → 比率上升（=1 时不变，>1 时上升）；
* 应收周转天数计算可能受现金销售、销售税、保理（factoring with recourse）、季节性与年末余额代表性影响。

## 19.4 长期偿债能力（Long-term Solvency）

* **杠杆比率 Gearing**：`Long-term debt / Equity × 100%` 或 `Debt / (Debt + Equity) × 100%`
* **利息保障倍数 Interest cover**：`PBFIT / Interest expense`（次数）
* 高杠杆：固定回报资本占比高→**破产风险高**；`ROCE > 借款利率`时利润增长→股东回报**成比例放大**（财务杠杆效应）。
* 增权益路径（新发股、留存利润）→ 降低杠杆；还/借债→改变债务；**售后回租→杠杆更高**（可抵押资产减少）。

**利息费用上升原因**：市场利率上升（浮动利率贷款）、期间新增贷款/租赁负债。

**📌考点**：利息增加**不影响 OPM**，但降低 interest cover。

**⚠️易错**：把 gearing 分母口径与 ROCE 的 capital employed 混淆；忽略回租对杠杆的影响。

## 19.5 投资者比率（Investor's Ratio）

* **市盈率 P/E**：`Share price / EPS`（EPS 趋势可能比净利润趋势更能反映业绩）
* **股息率 Dividend yield**：`Dividend per share / Share price × 100%`
* **股利保障倍数 Dividend cover**：`Profit after tax / Dividend`（越高越能留利再投资）

**📌考点**：EPS 是 P/E 的分母；EPS 趋势受股数变化影响。

**⚠️易错**：红利/股数变化（如 bonus issue）需**重述比较期 EPS**（IAS 33）。

## 19.6 比率分析的局限性（Limitations）

* **信息问题**：信息过时、历史成本可能不相关、仅汇总信息、**只识别症状而非原因**。
* **趋势分析问题**：通胀未调整不可比、技术/环境变化无从体现、会计政策变更前后不可比、**基准年选择**困难。
* **跨公司比较问题**：会计政策不同、比率公式不一致、规模经济、行业相同但市场/产品组合不同、会计年末不同。

**📌考点**：分析只能说明"发生了（症状）"，不能说明"为什么（原因）"。

**⚠️易错**：直接拿不同口径/不同政策的比率作简单比较。

## 19.7 集团层面的分析要点（Group Aspects）

### 19.7.1 年中取得子公司（Subsidiary Acquired in the Year）

| **影响**           | **说明**                                              |
| ---------------- | --------------------------------------------------- |
| 收入/费用/资产/负债      | 合并后当年各项**上升**                                       |
| **ROCE / 资产周转率** | SOFP 含**全年资产**，SOPL 仅含**购后 `n` 个月利润** → 比率系统性**偏低** |
| 递延/或有对价          | 后续利息滚算或 FV 变动→减少集团利润                                |
| 收购相关费用           | 当期一次性费用→未来盈利改善可能被夸大                                 |
| 不同边际/运营周期        | 新旧实体毛利率、营运资本周期不同                                    |

* 集团层面 S 净资产与商誉按 **FV** 并入，可能**抬高 ROCE 分母**；S 的**购后补提折旧**会**压低集团回报**。

### 19.7.2 年中处置子公司（Subsidiary Disposed in the Year）

* SOPL 仅含**截至处置日**业绩；SOFP **不含**该 S 的资产负债与 NCI。
* SOPL 可能含**处置损益**及**一次性处置相关费用**（专业服务费、遣散费）。
* 集团可能**失去 S 带来的利益**（供应、管理技能）。

### 19.7.3 分析时调整对比数据

* 年中收购/处置时，应**剔除该 S 的影响**做 like-for-like 比较（如重算"假设未收购"的利润与利润率）。
* 集团层面分析与独立实体不可直接比较，需说明原因（收购/处置、FV 调整、NCI 等）。

**📌考点**：集团分析必须调整可比性；年中收购使 ROCE/周转率系统性偏低。

**⚠️易错**：忽略收购/处置期间与 FV 调整对可比性的影响。

## 19.8 现金流量表解读（跨章节关联）

* 将 **Cash generated from operations** 与 **Operating profit** 对比。
* **过度交易（overtrading）迹象**：高利润但低现金产生；存货、应收、应付**大幅增长**。
* 股利与利息支付能力：与经营活动现金比较，不足以覆盖→**持续经营问题**；覆盖后剩余→**自由现金流**（可购资产、还债、发股利）。
* 投资活动：出售资产可能是好事（替换旧资产），但**靠持续变卖资产维持经营或发股利是糟糕的现金管理**。
* 融资活动：新借款（未来利息增加、需偿还）；还款（释放未来现金流）；发股（无需偿还无利息，但股东期望持续分红）。
* 结论：现金减少可能有合理/时间性原因；现金流量表也有一定操纵空间，需结合报表其他部分判断。

## 19.9 高频考点 / 易错点速查

| **序号** | **考点**      | **易错点**                                           |
| ------ | ----------- | ------------------------------------------------- |
| 1      | ROCE 杜邦分解   | 分清是 OPM 还是 asset turnover 变化                      |
| 2      | 重估增值影响      | PPE 重估→ROCE↓、Asset turnover↓、**Gearing↓**（权益分母增大） |
| 3      | 年中收购影响      | 全额资产 vs 仅 `n` 个月收入→ROCE 与周转率**系统性偏低**             |
| 4      | 会计政策变更      | 如 FIFO→AVCO（通胀期成本↑→毛利率↓）                          |
| 5      | 费用重分类       | R\&D 从 COGS 改到 Admin→**毛利率人为提高**（OPM 不变）          |
| 6      | 现金周期        | 存货天数 + 应收天数 − 应付天数；注意分母                           |
| 7      | 流动比率口径题     | 退回现金购买的存货→CA/CL 同减→比率上升                           |
| 8      | 利息 vs 经营利润率 | 利息在 operating profit 之后，**不影响 OPM**               |
| 9      | 高杠杆双刃剑      | 利润增长放大股东回报，但破产风险更高                                |
| 10     | 症状 vs 原因    | 比率只反映"发生了什么"                                      |
