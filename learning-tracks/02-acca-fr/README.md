# ACCA FR：把英文教材翻成我看得懂的话

> **直接下载用**：[ACCA_FR_复习站.html](./ACCA_FR_复习站.html)（离线可开）
> 配套笔记：[ACCA_FR_考前速记笔记_化简版.md](./ACCA_FR_考前速记笔记_化简版.md)

## 我遇到的问题

FR (F7) 是 12 月全球统考的一门。教材是英文的，准则一条条列得很清楚，但我看完记不住，更不会用。而且这个学期竞赛、期末、ACCA 挤在一起，没时间把 19 章从头到尾啃两遍。

我需要的是：**用我自己的话把每个准则讲一遍**，讲到我能在题目里认出它为止；同时能在考前快速过一遍，而不是重新读一遍英文书。

## 我怎么提的需求

- 每个考点固定按五块写：**大白话解释 → 生活例子 → 逻辑串联 → 考点提示 → ⚠️易错辨析**。简单概念用日常类比，复杂概念就用一个小生意场景把它走一遍。
- 到了复习阶段要能一键变薄：只留正文考点和 ⚠️ 标记，**删掉大白话解释、例子和串联**，做成「精简版」背得快。
- 英文不能乱删：可能考简答题的原文和专业名词要留着，只去掉冗余注释。
- 按科目分章节存，方便和期末、竞赛的同一批知识点对照着看。

## 最后做成什么

- **一个离线复习站**：19 章知识框架、真题与解析、按小节查漏，双击就能开。
- **一套按同一模板重写的笔记**：全章通俗版、精编版、最终整合手册、真题反向查漏版、考前化简版——同一份知识按不同复习阶段切了五种厚薄。
- **方法复用到 PM**：FR 跑通的五块模板直接搬到 PM 笔记，没有重新设计一套。

## 怎么用 / 注意

考 FR 的话，先用复习站按章过一遍，考前换化简版速记笔记收尾。12 月统考还在备考，这个目录会继续补。

笔记是我个人的理解整理，**准则原文、考试口径以 ACCA 官方教材和考官报告为准**。题目与讲义原件不在仓库里。
