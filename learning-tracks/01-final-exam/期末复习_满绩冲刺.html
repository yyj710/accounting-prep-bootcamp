第1章 概述

1.1 会计概念与职能

  • 会计：以货币为主要计量单位，对经济活动进行核算和监督的经济管理活动。
  • 基本职能：核算（最基本）+ 监督；拓展职能：预测经济前景、参与经济决策、评价经营业绩。
  • 核算四环节：确认（定性）→ 计量（定量）→ 记录 → 报告。
  • 监督三部分：单位内部监督 + 国家监督（财政/审计/税务）+ 社会监督（注册会计师）＝"三位一体"。
  • 关系：核算是监督的基础，监督是核算质量的保障。

1.2 会计基本假设（4 个，必背）

假设一句话理解⚠️考点
会计主体为"谁"记账（空间范围）会计主体≠法律主体：法律主体必是会计主体；车间、分公司、企业集团是会计主体但不是法律主体
持续经营企业会一直开下去持续经营是会计分期的前提
会计分期把经营切成期间分期才产生权责发生制、应收应付、折旧摊销
货币计量用钱来量不排斥其他计量单位作补充

1.3 会计核算基础

对比权责发生制（企业用）收付实现制
收入确认取得收款权利时实际收到钱时
费用确认产生付款义务时实际付出钱时
  • ⚠️经典题：12 月租金 200 万，付了 180 万 → 权责发生制确认费用 200，收付实现制确认 180。
  • 口诀：权责看"该不该"，收付看"到没到"。
第2章 会计基础

2.1 会计要素（6 个）

资产负债表三要素（反映财务状况）：

要素定义关键词确认条件（除符合定义外）
资产过去交易形成、拥有或控制、预期带来经济利益流入①经济利益很可能流入 ②成本/价值能可靠计量
负债过去交易形成、现时义务、预期经济利益流出①很可能流出 ②金额能可靠计量
所有者权益资产扣除负债后的剩余权益依赖资产、负债的确认计量
  • 所有者权益来源：实收资本（股本）、资本公积、其他综合收益、盈余公积、未分配利润。
  • 债权人：优先索取权、风险小、固定收益；所有者：剩余索取权、风险大、变动收益。

利润表三要素（反映经营成果）：

要素定义关键词
收入日常活动形成、导致所有者权益增加、与投入资本无关的经济利益总流入（主营+其他业务收入）
费用日常活动发生、导致所有者权益减少、与分配利润无关的经济利益总流出
利润收入−费用 + 直接计入当期利润的利得和损失
  • ⚠️收入 vs 利得、费用 vs 损失：日常活动→收入/费用（总流入/流出）；非日常→利得/损失（净流入/流出，如营业外收支）。
  • 利润三层：营业利润 → 利润总额（＋营业外收支）→ 净利润（−所得税费用）。
  • ⚠️经典"不属于资产"：约定未来购入的存货、盘亏的固定资产、经营租赁临时租入的仓库（不属于）；委托加工物资、生产成本（属于，本质是在产品）。

2.2 计量属性（5 个，对号入座）

属性典型应用
历史成本（实际成本）大多数业务、固定资产初始入账（一般应当采用）
重置成本固定资产盘盈
可变现净值存货期末计量（预计售价−进一步加工成本−税费费用）
现值融资性质分期付款购固定资产
公允价值交易性金融资产期末计量

⚠️判断题陷阱："重置成本是预计售价减进一步加工成本…"（错，那是可变现净值）。

2.3 会计等式

  • 资产 = 负债 + 所有者权益（静态、财务状况等式、编制资产负债表依据、复式记账理论基础）
  • 收入 − 费用 = 利润（动态、经营成果等式、编制利润表依据）
  • 九类业务对等式的影响：等式一边内部 → 一增一减；等式两边 → 同增同减；恒等式永远平衡。

2.4 借贷记账法

账户类型增加记减少期末余额
资产类、成本类借贷借方
负债类、所有者权益类贷借贷方
收入类贷借结转后无余额
费用类借贷结转后无余额
  • 记账规则：有借必有贷，借贷必相等。
  • ⚠️备抵账户结构与被调整账户相反：坏账准备、存货跌价准备、累计折旧、固定资产减值准备——都是"贷加借减"。
  • 成本类科目：生产成本、制造费用、研发支出（主营业务成本/其他业务成本是损益类！）。

2.5 试算平衡

  • 发生额平衡依据：记账规则；余额平衡依据：会计等式。
  • ⚠️试算平衡≠记账一定正确。不影响平衡的错误 6 种：漏记、重记、双方同多记/少记、记错账户、颠倒方向、多记少记偶然抵销。
  • 口诀：不平衡必有错，平衡不一定对。
第3章 流动资产（全章重点，必考大题来源）

3.1 货币资金

库存现金清查（高频）：

情形批准前批准后
短缺借：待处理财产损溢 贷：库存现金责任人赔→其他应收款；查不出→管理费用
溢余借：库存现金 贷：待处理财产损溢应付他人→其他应付款；查不出→营业外收入

⚠️溢余查不出→营业外收入（不是冲管理费用）；短缺查不出→管理费用。

  • 现金限额按 3~5 天日常零星开支核定（边远地区不超 15 天）；不得坐支。
  • 银行存款日记账与对账单至少每月核对一次，差额编"银行存款余额调节表"；调节后余额=实际可动用金额。余额调节表不是原始凭证，不作记账依据。

其他货币资金（6 类）：银行汇票存款、银行本票存款、信用卡存款、信用证保证金存款、存出投资款、外埠存款。

  • 套路：存出 借"其他货币资金"贷"银行存款"；购货 借"原材料+进项税"贷"其他货币资金"；余额退回 借"银行存款"。
  • ⚠️辨析：收到银行汇票/本票结算款→借银行存款；收到商业汇票→应收票据；开出银行承兑汇票购货→应付票据。
  • ⚠️"货币资金总额是否减少"题：银行存款↔其他货币资金互转总额不变；用其他货币资金实际购物付款才减少。

3.2 应收及预付款项

增值税基础分录（通用）：采购 借 原材料＋应交税费—应交增值税（进项）贷 银行存款；销售 借 银行存款 贷 主营业务收入＋应交税费—应交增值税（销项）。增值税是价外税。

  • 应收票据＝商业汇票（付款期限最长不超过 6 个月）；银行承兑汇票手续费→财务费用。背书转让购材料 借原材料＋进项 贷应收票据。
  • 应收账款＝价款＋增值税＋代垫运杂费包装费（⚠️代垫运费记应收账款，不是其他应收款）。
  • 预付账款：预付不多可并入应付账款（口诀"付对负"）；期末贷方余额反映应补付款项（负债性质）。
  • 其他应收款内容必背：①应收赔款罚款 ②应收出租包装物租金 ③代职工垫付的医药费房租水电 ④存出保证金（付的押金）⑤备用金、职工预借差旅费。

应收款项减值（备抵法，计算必考）：

  • 核心公式：当期应计提 = 期末应有坏账准备 − 计提前"坏账准备"贷方余额（负数→转回）。
  • 应收账款账面价值 = 账面余额 − 坏账准备。
业务分录对账面价值影响
计提借信用减值损失 贷坏账准备减少
转回多提借坏账准备 贷信用减值损失增加
实际转销坏账借坏账准备 贷应收账款不影响（同减）
收回已转销坏账借应收账款 贷坏账准备；借坏账准备 贷信用减值损失；借银行存款 贷应收账款综合不影响

⚠️高频判断：转销坏账、收回已转销坏账都不影响账面价值；计提、转回影响。计提坏账准备记"信用减值损失"科目。

3.3 存货（最大重点）

初始计量：

计入成本不计入（计入当期损益）
购买价款、进口关税、运输费装卸费保险费、运输途中合理损耗、入库前挑选整理费、特定客户设计费非正常消耗（管理不善→管理费用；自然灾害→营业外支出）、入库后仓储费、入库后挑选整理费、采购人员差旅费、可抵扣增值税

四种发出计价法：

方法要点
个别计价法实物流转=成本流转；适用于珠宝名画等
先进先出法物价上升→发出成本低→高估利润和期末存货
月末一次加权平均单位成本=(月初成本+本月进货成本)÷(月初数量+本月进货数量)；平时无法提供发出/结存单价
移动加权平均每次进货后重算；能及时了解结存；工作量大

原材料实际成本法（4 种情形）：钱付货到→原材料；钱付货未到→在途物资；货到单到款未付→应付账款；货到单未到→月末按暂估价 借原材料 贷应付账款—暂估，下月初红字冲回（⚠️不暂估增值税）。

计划成本法（计算必考）：

  • 三科目：材料采购（实际）、原材料（计划）、材料成本差异（差额）。
  • 入库：超支差异记借方，节约差异记贷方。
  • 差异率 =（期初差异＋本期入库差异）÷（期初计划成本＋本期入库计划成本）（超支为正、节约为负）；发出材料实际成本 = 发出计划成本 ×（1＋差异率）。
  • ⚠️"材料成本差异"借方 = 入库的超支差异 + 发出的节约差异。

周转材料：生产领用包装物→生产成本；随商品出售不单独计价→销售费用；单独计价→收入记其他业务收入、成本记其他业务成本；出租包装物（租金/修理费/摊销）→其他业务成本；出借包装物→销售费用，押金（收）记其他应付款。低值易耗品摊销：一次摊销法/分次摊销法。

委托加工物资（计算必考）：成本 = 发出材料实际成本＋加工费＋运杂费＋（收回后直接出售时的消费税）。⚠️消费税：直接出售→计入成本；连续生产应税消费品→借"应交税费—应交消费税"（可抵扣），不计入成本。可抵扣增值税进项税始终不计入成本（小规模纳税人增值税计入成本）。

库存商品—商品流通企业两法：

  • 毛利率法：销售毛利=销售净额×毛利率；销售成本=销售净额−毛利；期末存货=期初＋购进−销售成本。
  • 售价金额核算法：差价率=(期初进销差价＋本期购进进销差价)÷(期初售价＋本期购进售价)；已销商品分摊差价=本期销售收入×差价率；销售成本=收入−分摊差价。
  • ⚠️已完成销售手续但月末未提货→代管商品，不作库存商品。

存货清查：

情形批准后处理
盘盈冲减管理费用（⚠️与固定资产盘盈不同！）
盘亏残料→原材料；赔款→其他应收款；管理不善→管理费用（且进项税额转出）；自然灾害→营业外支出（进项不转出）

存货减值：期末按成本与可变现净值孰低计量；当期应计提 =（成本−可变现净值）− 已有贷方余额，负数则在已提范围内转回。计提 借资产减值损失 贷存货跌价准备。可变现净值：直接出售 = 估计售价−销售费用税费；需加工 = 估计售价−至完工进一步加工成本−销售费用税费。出售存货时对应跌价准备一并结转。

第4章 非流动资产（必考）

4.1 固定资产

入账成本 = 买价＋相关税费（不含可抵扣增值税）＋运输费装卸费安装费专业人员服务费等使资产达到预定可使用状态前的支出。

  • ⚠️员工培训费→管理费用，不计入成本；一般纳税人进项税可抵扣不计入成本，小规模纳税人进项税计入成本。
  • 需安装→先"在建工程"，达到预定可使用状态转"固定资产"。
  • 一笔款项购入多项无单独标价固定资产→按公允价值比例分配总成本（专属费用直接计入对应设备）。
  • 自营工程：领用自产产品按成本结转（不确认收入）；出包工程按工程价款记在建工程。

折旧范围（高频）：

  • 不计提折旧的只有两类：①已提足折旧仍继续使用 ②单独计价入账的土地。
  • 当月增加当月不提、下月起提；当月减少当月照提、下月起不提。
  • 已达预定可使用状态未办竣工决算→按估计价值计提，决算后调整成本但不调整已提折旧。
  • 更新改造期间不提折旧；日常维修停用、大修理停用、未使用/不需用、暂时闲置的都要提。

折旧四法（计算必考）：

方法公式要点
年限平均法年折旧额=原价×(1−净残值率)÷预计年限（考虑净残值）
工作量法单位工作量折旧额=原价×(1−净残值率)÷总工作量（也考虑净残值）
双倍余额递减法年折旧率=2÷年限（前期不考虑净残值）；年折旧额=年初账面净值×年折旧率；最后两年改为(净值−净残值)÷2
年数总和法年折旧额=(原价−净残值)×尚可使用年限÷年数总和（净残值始终扣除，折旧率逐年递减→折旧额逐年递减）
  • ⚠️折旧年度≠会计年度：3 月购入，折旧年度=当年 4 月~次年 3 月。跨年度折旧题先算各折旧年度折旧额，再按月拆到会计年度。
  • 账面原值=入账价值；账面净值=原值−累计折旧；账面价值=原值−累计折旧−减值准备。

折旧去向：生产车间→制造费用；管理部门及未使用→管理费用（财务部门折旧也进管理费用，不是财务费用！）；销售部门→销售费用；经营租出→其他业务成本；在建工程用→在建工程；研发用→研发支出。

后续支出：

  • 资本化（更新改造）：账面价值转入在建工程；新成本 = 改造前账面价值＋资本化支出−被替换部分账面价值（⚠️扣的是被替换部分的账面价值，不是原价；被替换部分报废损失记营业外支出）。
  • 费用化（日常修理）：行政→管理费用；销售机构→销售费用；与存货生产相关→制造费用。

处置（固定资产清理五步）：①转入清理 借固定资产清理（账面价值）＋累计折旧＋减值准备 贷固定资产 ②清理费用 借固定资产清理 ③收价款/残料/变价收入 贷固定资产清理＋销项税 ④保险赔偿 借其他应收款 贷固定资产清理 ⑤结转净损益：出售/转让→资产处置损益；报废/毁损→营业外收支（⚠️高频辨析！）。

清查：

  • 盘盈：按重置成本 借固定资产 贷以前年度损益调整→结转盈余公积＋未分配利润（不影响当期损益，不影响留存收益总额的划分要会算）。
  • 盘亏：借待处理财产损溢（账面价值）＋累计折旧 贷固定资产；批准后 赔款→其他应收款，净损失→营业外支出。

减值：可收回金额（未来现金流量现值 与 公允价值减处置费用净额 孰高）＜账面价值→差额计提；借资产减值损失 贷固定资产减值准备。一经确认，以后期间不得转回；减值后按新账面价值和尚可使用年限重新计提折旧。

4.2 无形资产

  • 特征：无实物形态、可辨认性、非货币性。⚠️自创商誉、内部品牌不是无形资产。
  • 内容：专利权、非专利技术、商标权、著作权、土地使用权、特许权。

取得：外购成本 = 价款＋税费＋直接归属支出（专业服务费、测试费、注册费）。⚠️广告费→销售费用、培训费→管理费用，不计入。

自行研发（必考）：研究阶段支出→研发支出—费用化支出→期末转管理费用；开发阶段符合资本化条件→研发支出—资本化支出→达到预定用途转无形资产；无法区分研究/开发→全部费用化。

摊销：使用寿命有限→当月增加当月摊、当月处置当月不摊（⚠️与固定资产折旧相反！）；使用寿命不确定→不摊销，但每期减值测试；残值一般为零（可能有残值）。去向：管理用→管理费用；出租→其他业务成本；生产用→生产成本/制造费用。

出售 vs 报废：出售净损益→资产处置损益；报废转销→营业外支出。出租收入→其他业务收入。减值不得转回。

4.3 长期待摊费用

分摊期限1 年以上的费用（如租入固定资产改良支出、装修支出）。发生 借长期待摊费用；摊销 借管理费用等 贷长期待摊费用；期末余额在借方。

第5章 负债（part1 范围）

5.1 短期借款

期限 ≤1 年。利息：预提（按季付/到期还本付息且数额大）→借财务费用 贷应付利息；直接支付（按月付/数额小）→借财务费用 贷银行存款。

5.2 应付及预收账款

  • 应付票据（付款期限≤6 个月）：⚠️商业承兑汇票到期无力支付→转应付账款；银行承兑汇票→转短期借款（银行代付）。银行承兑手续费：借财务费用＋进项税 贷银行存款。
  • 应付账款：入账金额=价款＋增值税＋对方代垫运杂费。确实无法支付转销→营业外收入。
  • 合同负债：已收/应收客户对价但尚未转让商品的义务。收款 借银行存款 贷合同负债；履约 借合同负债 贷主营业务收入。不适用收入准则的预收款用"预收账款"（如预收短期租出固定资产租金→其他应付款）。
  • 应付利息：已过付息期尚未支付的利息。
  • 应付股利：股东大会批准的现金股利分配方案→借利润分配 贷应付股利。⚠️董事会拟分配方案：不进行账务处理；股票股利宣告和发放都不通过应付股利。
  • 其他应付款：应付短期租赁固定资产租金、低价值资产租赁租金、租入包装物租金、收到的押金（存入保证金）、代扣职工个人社保公积金。⚠️付出去的押金→其他应收款；收进来的押金→其他应付款。

5.3 应付职工薪酬

职工三类：劳动合同职工（含全职兼职临时）、正式任命的董监高、劳务派遣/类似服务人员。

类别内容
短期薪酬工资奖金津贴补贴、职工福利费、医疗/工伤/生育保险、住房公积金、工会经费(2%)、职工教育经费(8%)、短期带薪缺勤、短期利润分享计划、非货币性福利
离职后福利基本养老保险、失业保险（设定提存计划）
辞退福利解除劳动关系或鼓励自愿裁减的补偿（一律计入管理费用，不计资产成本）
其他长期职工福利长期带薪缺勤、长期残疾福利、长期利润分享计划
  • ⚠️职工出差预借差旅费不属于职工薪酬（其他应收款）；代扣代缴个人所得税不是给职工的报酬。

货币性薪酬：计提按受益对象（生产成本/制造费用/管理费用/销售费用/研发支出/在建工程）。发放扣款：借应付职工薪酬 贷其他应收款（代垫款）＋应交税费—应交个人所得税＋其他应付款（代扣社保）＋银行存款。

非货币性福利（自产产品发福利=视同销售，计算必考）：

  • 计提：借生产成本/管理费用等 贷应付职工薪酬—非货币性福利（含税公允价值=人数×售价×(1+13%)）。
  • 发放：借应付职工薪酬 贷主营业务收入（公允价值）＋销项税额；同时结转成本 借主营业务成本 贷库存商品。
  • 自有资产无偿用（如汽车）：计提薪酬同时 借应付职工薪酬 贷累计折旧；租赁住房按租金确认。

设定提存计划（养老保险 16%）：计提 借生产成本等 贷应付职工薪酬—设定提存计划。

考前速记：全套辨析对照（13 条全覆盖）
  1. 盘盈三兄弟：现金盘盈→营业外收入；存货盘盈→冲管理费用；固定资产盘盈→以前年度损益调整（留存收益增加）。
  2. 盘亏：现金盘亏查不出→管理费用；存货管理不善→管理费用（进项转出）、自然灾害→营业外支出（不转出）；固定资产盘亏净损失→营业外支出。
  3. 汇票无力支付：买方商业承兑→应付账款；银行承兑→短期借款；卖方持有商业承兑汇票收不回→应收账款。
  4. 净损益去向：出售固定资产/无形资产→资产处置损益；报废毁损→营业外收支。
  5. 折旧"当月增加不提"；摊销"当月增加当月提、处置当月不提"。
  6. 双倍余额递减法前期不考虑净残值、最后两年扣；年数总和法、工作量法、年限平均法一直扣净残值。
  7. 委托加工消费税：直接出售→入成本；连续生产→应交税费借方。
  8. 材料成本差异借方=入库超支＋发出节约；超支为正、节约为负。
  9. 跌价准备可转回（限已提金额内）：存货、应收账款；不得转回：固定资产、无形资产、成本模式投资性房地产。
  10. 坏账：转销、收回已转销→不影响应收账款账面价值；计提、转回→影响。
  11. 股利：董事会方案不做账；股票股利不做应付股利；股东大会批准的现金股利才确认应付股利。
  12. 包装物：生产领用→生产成本；不单独计价→销售费用；单独计价/出租→其他业务收入/成本；出借→销售费用。
  13. 押金：付出去→其他应收款；收进来→其他应付款。代垫运费（购货方）→应收账款/应付账款，不进其他应收/应付。

✅ 必背结论（左：结论／右：记忆锚与口诀）

结论记忆锚 / 口诀
四大基本假设口诀「主、持、分、币」：会计主体定空间、持续经营定时间、会计分期切时段、货币计量定尺度。
会计主体 ≠ 法律主体法律主体必是会计主体；会计主体不一定是法律主体（分公司、企业年金基金、合并集团都是会计主体）。
八项信息质量要求口诀「靠、相、懂、比、实、重、谨、快」＝可靠、相关、可理解、可比、实质重于形式、重要、谨慎、及时。
六大会计要素静态三要素：资产、负债、所有者权益（进资产负债表）；动态三要素：收入、费用、利润（进利润表）。
五个计量属性历史成本（买时花了多少）、重置成本（现在重买要多少）、可变现净值（卖出去净得多少）、现值（折现后）、公允价值（有序交易价）。
两大会计等式资产 = 负债 + 所有者权益；收入 − 费用 = 利润。扩展式：资产 = 负债 + 所有者权益 +（收入 − 费用）。

✅ 必背结论（左：结论／右：记忆锚与口诀）

结论记忆锚 / 口诀
权责发生制凡是当期已实现的收入、已发生或应负担的费用，不论款项是否收付，都作为当期收入费用；反之则不算。
借贷记账口诀「资费借加，权收贷加」：资产、费用借方记增加；负债、所有者权益、收入贷方记增加。
账户余额方向资产类余额在借方；负债/所有者权益类在贷方；收入费用类期末结转后无余额。
记账规则有借必有贷、借贷必相等。
试算平衡借方发生额合计 = 贷方发生额合计；但平衡不等于没记错：漏记、重记、科目用错、借贷方向同时记反，试算仍平衡。
会计循环原始凭证 → 记账凭证 → 日记账/明细账/总账 → 对账结账 → 财务报表。
错账更正三法划线更正（凭证对、账簿写错）；红字更正（科目用错或金额多记）；补充登记（金额少记）。

✅ 必背结论（左：结论／右：记忆锚与口诀）

结论记忆锚 / 口诀
其他货币资金六项口诀「外、汇、本、卡、证、投」＝外埠存款、银行汇票、银行本票、信用卡、信用证保证金、存出投资款。
现金清查盘盈无法查明原因 → 营业外收入；盘亏无法查明原因 → 管理费用。
银行存款余额调节表只调节未达账项（企业已收银行未收 / 企业已付银行未付 / 银行已收企业未收 / 银行已付企业未付）；不作账务处理，调节后双方余额应相等。
应收账款入账价值价款 + 增值税销项税额 + 代垫包装费/运杂费。商业折扣按净额入账；现金折扣按总价法，实际享受时进「财务费用」。
坏账备抵法计提：借「信用减值损失」、贷「坏账准备」；本期应提 = 期末应保留余额 − 计提前余额。核销：借坏账准备、贷应收账款（账面价值不变）。
已核销坏账又收回先恢复（借应收账款、贷坏账准备），再收款（借银行存款、贷应收账款）。
票据贴现贴现息 = 到期值 × 贴现率 × 剩余期限；附追索权不终止确认应收票据，贷记短期借款。
存货成本构成采购成本 + 加工成本 + 其他成本。不计入：非正常损耗、非生产必需的仓储费、广告营销费。合理损耗计入成本（抬高单位成本）。
发出计价与计划成本法四种：个别计价、先进先出、月末一次加权平均、移动加权平均。差异率 =（月初差异 + 本月收入差异）÷（月初计划成本 + 本月收入计划成本）；发出负担差异 = 发出计划成本 × 差异率。
存货期末计量成本与可变现净值孰低。可变现净值 = 估计售价 − 至完工尚须发生的成本 − 估计销售费用 − 相关税费。跌价准备可以转回（在原计提金额内）。
委托加工消费税收回后直接出售 → 消费税计入委托加工物资成本；用于连续生产应税消费品 → 借「应交税费——应交消费税」可抵扣。
毛利率法 / 售价金额法销售成本 = 销售收入 ×（1 − 毛利率）；进销差价率 =（期初差价 + 本期购入差价）÷（期初售价 + 本期购入售价）。
存货清查盘盈 → 冲减管理费用；计量差错/管理不善盘亏 → 管理费用；自然灾害净损失 → 营业外支出。

考点一句话结论
可变现净值：先看持有目的直接出售 → 自身估计售价 − 销售税费；加工成产成品再出售 → 产成品售价 − 将要发生的加工成本 − 销售税费（先判断产成品是否已减值）。已发生的加工成本已在存货成本里，别重复扣。
合理损耗 vs 非合理损耗合理损耗计入存货总成本（数量减少 → 单位成本上升）；非合理损耗不计入成本，进当期损益。
移动加权平均法每次进货都重算一次加权平均单位成本；每次发出用「最新」的单价，但发出本身不改变该单价。
有合同 / 无合同分别算合同数量内按合同价，超出部分按市场价，分别确定、不得相互抵销。跌价准备期末余额 = 成本 − 可变现净值，再倒挤本期计提（贷方）或转回（借方）。
存货确认两问① 是否以出售为目的？② 是否为日常活动中的出售？两问都满足才是存货（工程物资、自用设备不是）。
清查盘点去向自然溢余 → 调数量与单位成本；计量收发差错/管理不善净损失 → 管理费用（进项税额需转出）；自然灾害净损失 → 营业外支出（进项税额不用转出）。
第4章 非流动资产必背 13 条 · 易错 6 组
一句话主线：入账成本 → 折旧/摊销 → 后续支出 → 减值 → 处置与清查。固定资产和无形资产最忌「记混」。

✅ 必背结论（左：结论／右：记忆锚与口诀）

结论记忆锚 / 口诀
固定资产入账成本买价 + 相关税费 + 达到预定可使用状态前的一切必要支出（运输、装卸、安装、调试、专业人员服务费）。员工培训费不计入。
一笔款购多项资产没有单独标价的，按各项资产公允价值比例分摊总成本。
折旧四种方法年限平均法、工作量法、双倍余额递减法、年数总和法。
折旧起止时点当月增加当月不提、下月起提；当月减少当月照提、下月停提。
加速折旧两个公式双倍余额：年折旧率 = 2 ÷ 预计使用年限，前期不扣净残值，最后两年改直线并扣残值；年数总和：分母 = 1+2+…+n。
更新改造资本化的后续支出要扣除被替换部分的账面价值（题目给原价要先换算）；改造期间停提折旧，完工后重新确定使用寿命、净残值、折旧方法。
处置与报废出售、转让净损益 →「资产处置损益」；报废、毁损净损益 → 营业外收入/支出。都通过「固定资产清理」。
固定资产盘盈按重置成本入账，贷记「以前年度损益调整」（属前期差错，不是营业外收入）。
固定资产减值可收回金额低于账面价值的差额计提减值准备，一经计提不得转回；以后按新账面价值重新计算折旧。
研发支出两阶段研究阶段全部费用化；开发阶段满足五个条件才资本化；无法区分的，全部费用化，已费用化的不得再转回资本化。
无形资产摊销寿命有限→摊销（一般直线法，残值通常为零）；寿命不确定→不摊销但每年年末必须减值测试。
摊销起止时点当月增加当月开始摊销、当月减少当月不再摊销——与固定资产折旧正好相反。
土地使用权一般单独确认为无形资产；外购房屋建筑物价款含土地使用权的，能合理分配就分开，不能分开的整体作固定资产。房企用于建出售商品房的土地使用权计入存货。

易错点正确口径常见错答
折旧 vs 摊销的当月规则固定资产：增加当月不提、减少当月照提；无形资产：增加当月即摊、减少当月不摊。两者记反（超高频）
盘盈科目固定资产盘盈 → 以前年度损益调整；存货盘盈 → 冲减管理费用；现金盘盈 → 营业外收入。一律答营业外收入
减值能否转回长期资产减值不得转回；存货跌价准备可转回。一律答可转回
研究 vs 开发研究阶段全费用化；开发阶段符合条件才资本化；培训支出、广告费不进无形资产成本。误把培训费/广告费资本化
出售 vs 报废出售转让 → 资产处置损益；报废毁损 → 营业外收支。一律答营业外收支
被替换部分更新改造要扣的是「账面价值」，不是原价；给原价要扣掉对应累计折旧再算。直接减原价

考点一句话结论
双倍余额递减法折旧年限内前期不考虑净残值，到期前两年改年限平均法时才考虑净残值；更新改良期间停止计提折旧。
被替换部分要按账面价值扣给的是原价要先换算：被替换部分账面价值 = 更新改造时资产账面价值 × 被替换部分原价 ÷ 资产原价。
工程物资盘盈盘亏建设期间：盘亏进在建工程、盘盈冲减在建工程；完工后：一律进当期损益；自然灾害导致的盘亏净损失，不分期间一律进营业外支出。
处置 vs 清查（科目对照）出售/转让 → 固定资产清理 → 资产处置损益；报废/毁损 → 营业外收支；盘盈 → 以前年度损益调整；盘亏 → 待处理财产损溢 → 营业外支出。
测试成本 vs 试运行销售测试资产能否正常运转的支出 → 计入固定资产成本；达到预定可使用状态前产出的产品/副产品对外销售 → 收入与成本分别计入当期损益（不冲减资产成本）。
土地使用权四种去向房企用于建出售商品房 → 存货（不摊销）；自用且无法单独计量 → 固定资产（随房折旧）；自用且可单独计量 → 无形资产（建造期间摊销额进在建工程）；赚租金或等增值 → 投资性房地产。
无形资产寿命孰短法律保护期、剩余期限、预期带来经济利益期间、管理层使用计划，取孰短；已费用化的研发支出以后不再调整回资本化。
第5章 负债必背 12 条 · 易错 5 组
一句话主线：流动负债（短借 / 应付预收 / 职工薪酬 / 应交税费）→ 非流动负债（长期借款 / 应付债券）。

✅ 必背结论（左：结论／右：记忆锚与口诀）

结论记忆锚 / 口诀
应付职工薪酬范围工资、奖金、津贴补贴、福利费、社保（医疗/养老/失业/工伤/生育）、住房公积金、工会经费、职工教育经费、非货币性福利、辞退福利、带薪缺勤。
谁受益谁承担生产工人→生产成本；车间管理→制造费用；管理人员→管理费用；销售人员→销售费用；在建工程人员→在建工程。
非货币性福利以自产产品发放的，按公允价值（含增值税销项）确认应付职工薪酬，同时确认收入、结转成本。
辞退福利一律计入管理费用，不计入产品成本；确认时点为「解除劳动关系计划不可撤销」与「确认重组相关成本」两者孰早。
增值税专栏应交税费——应交增值税：进项税额、销项税额、进项税额转出、已交税金、转出未交增值税等。
视同销售（计销项）自产/委托加工货物用于集体福利、个人消费、无偿赠送、分配股利等。
进项税额不予抵扣用于简易计税项目、免征增值税项目、集体福利或个人消费，以及非正常损失对应的进项税额。
消费税（委托加工）直接出售→计入委托加工物资成本；连续生产应税消费品→借「应交税费——应交消费税」待抵扣。
不通过「应交税费」的税印花税、耕地占用税、契税、车辆购置税：直接计入相关成本费用或资产成本。
其他应付款装「应付租入包装物租金、存入保证金（押金）、代垫暂收款、应付暂收其他单位款项」。
长期借款利息去向筹建期间→管理费用；生产经营期间→财务费用；购建符合资本化条件的资产在达到预定可使用状态前→在建工程（资本化）。
应付债券设「面值、利息调整、应计利息」明细；按实际利率法摊销利息调整，利息费用 = 期初摊余成本 × 实际利率。

考点一句话结论
视同应税交易 vs 进项不予抵扣视同应税交易：自产/委托加工货物用于集体福利或个人消费、无偿赠送；进项不予抵扣：用于简易计税、免税项目、集体福利/个人消费、非正常损失，以及购进的餐饮/居民日常/娱乐服务。
委托加工消费税连续生产应税消费品 → 借记「应交税费——应交消费税」，不计入成本；收回后直接出售 → 计入委托加工物资成本。
房地产相关税费去向耕地占用税 → 资产成本；房产税、城镇土地使用税 → 税金及附加；土地增值税：存货/投资性房地产 → 税金及附加，固定资产/无形资产 → 资产处置损益。
应付债券摊余成本期末摊余成本 = 期初摊余成本 ×（1 + 实际利率）− 现金流出；到期一次还本付息的债券，现金流出发生在到期日。
补贴出售商品给职工附服务期限 → 售价与公允价值之差作「长期待摊费用」，在服务年限内摊销；无服务期限 → 直接按受益对象计入当期成本费用。
辞退福利内退人员正式退休前比照辞退福利；补偿款一律进管理费用；自愿接受裁减的要按预计接受人数计提应付职工薪酬。
