## 一、2026 版和旧口径不一样的地方（最容易丢分，先看这里）

这几处是讲义特意强调、而旧题/旧笔记里口径不同的地方。考试按 **2026 讲义**答。

### 1. 收回已转销的坏账：三步法（2026 新增一步冲回）

讲义 L2 例3-30 原文分录：

```
借：应收账款        20 000
  贷：坏账准备        20 000
借：坏账准备        20 000        ← 2026 新增的冲回一步
  贷：信用减值损失    20 000
借：银行存款        20 000
  贷：应收账款        20 000
```

**关键**：第①②步一贷一借，`坏账准备` 净额**不变**。所以"收回已转销坏账后再算期末补提"时，别把这笔当成坏账准备增加了——按旧两步法会算错。
> 例：期初贷 10，收回已转销 5，期末要保贷 18 → 补提 **18−10＝8**，不是 3。

### 2. 转销坏账：可能要补一笔信用减值损失

```
借：坏账准备
    信用减值损失    ← 核销金额大于已提坏账准备时，按差额（2026 新增）
  贷：应收账款
```

### 3. 计提减值的科目，别混

| 资产 | 减值走哪个科目 |
|---|---|
| 应收款项（坏账） | **信用减值损失** |
| 存货、固定资产、无形资产 | **资产减值损失** |

讲义例3-31：应收款项 2300 万、坏账准备贷 184 万，期末要保持贷 115 万 → 应**冲回** 69 万：借坏账准备 69 / 贷信用减值损失 69。答案 **B**。

### 4. 产品设计费

- 为**特定客户**设计、可直接认定的产品设计费 → 计入存货成本
- 企业**自己设计**产品发生的一般设计费 → 计入当期损益

### 5. 固定资产盘亏 vs 存货盘亏，科目不同

| 情形 | 批准后计入 |
|---|---|
| 固定资产盘亏/被盗净损失 | **营业外支出**（不管是不是保管不善） |
| 存货因管理不善盘亏 | **管理费用** |
| 存货因自然灾害毁损 | **营业外支出** |
| 现金短缺查不出原因 | **管理费用** |
| 现金溢余查不出原因 | **营业外收入** |

讲义 L7 例4-34：盘亏笔记本原价 10000、已提折旧 7000、进项税 1300 → 进项转出 (10000−7000)×13%＝390，最终营业外支出 3390。

### 6. 折旧的"当月"规则

当月**增加**的固定资产 → 当月不提，下月起提；
当月**减少**（含盘亏、处置）的 → 当月**照提**，下月停提。
不提折旧只有两种：已提足仍使用、单独计价入账的土地。

## 二、货币资金（L1）

### 现金使用范围
对个人支付（工资、津贴、奖金、劳保福利、收购农副产品、差旅费）＋结算起点 **1000 元**以下零星支出＋央行确定的其他支出。**对单位大额支付必须转账**。

- 库存限额：按 **3–5 天**日常零星开支核定；交通不便可放宽，但**不超过 15 天**。
- 现金收入**当日送存**；不得**坐支**（从现金收入直接支付），特殊情况需银行审批。
- 备用金：可单独设"备用金"科目，**不是库存现金，也不是其他货币资金**。

**讲义例题**：向外单位支付机器设备款 25 万 → 不能用现金。**答案 C**。

### 现金清查
先走 `待处理财产损溢`，批准后：

| 情形 | 借方/贷方 |
|---|---|
| 短缺·责任人/保险赔 | 借其他应收款 |
| 短缺·查不出 | 借管理费用 |
| 溢余·应付有关单位 | 贷其他应付款 |
| 溢余·查不出 | 贷营业外收入 |

**讲义例题**：无法查明原因的现金短缺，批准后 → 管理费用。**答案 A**。

### 银行存款余额调节表
调节公式：

```
企业日记账余额 + 银行已收企业未收 − 银行已付企业未付
= 银行对账单余额 + 企业已收银行未收 − 企业已付银行未付
```

**只会核对，不能作为记账依据**。调节后余额才是可实际动用的存款。
**讲义例题**：使企业日记账余额**大于**对账单的是"银行已付企业未付"。**答案 A**。

### 其他货币资金（6 项）
银行汇票、银行本票、信用卡、信用证保证金、存出投资款、外埠存款。
- **商业汇票（银行承兑/商业承兑）→ 应收票据，不是其他货币资金**；支票、银行汇票收到时进银行存款。
- 信用证保证金**只转账、不支取现金**。
- 外埠存款：不计利息、只付不收、付完清户，除采购人员少量现金外一律转账。

**讲义例题**：存入证券公司投资专户 → 其他货币资金。**答案 D**；多选 BCD（为购买股票划出资金、汇往外地采购专户、申请银行本票拨付资金）。

**例3-1（银行汇票购料）**：
```
申请：借 其他货币资金——银行汇票 250000 / 贷 银行存款 250000
结算：借 原材料 200000 + 进项 26000 / 贷 其他货币资金——银行汇票 226000
退回：借 银行存款 24000 / 贷 其他货币资金——银行汇票 24000
```
**例3-2（银行本票购办公用品）**：申请 11300；使用 借管理费用 10000＋进项 1300 / 贷其他货币资金 11300。
**例3-3（信用卡购书）**：申请 50000；使用 借管理费用 3000＋进项 270 / 贷其他货币资金 3270。
**例3-4**：其他货币资金核算 → **答案 ABCD**。

## 三、应收及预付款项（L1–L2）

### 应收票据
因销售商品/提供服务收到的**商业汇票**，按承兑人分银行承兑、财务公司承兑、商业承兑。
- 取得：借应收票据 / 贷主营业务收入＋销项；抵偿前欠货款则贷应收账款。
- 背书转让购料：借原材料＋进项 / 贷应收票据（差额进银行存款）。
- 贴现利息 → **财务费用**；不符合终止确认条件时贷"短期借款"。
- 到期无力支付：**商业承兑 → 应收账款；银行承兑 → 短期借款**。

### 应收账款
包括合同价款、增值税、**代购货单位垫付的包装费运杂费**。
**讲义例题（例3-18/19）**：价款 30 万＋税 3.9 万 → 应收账款 33.9 万；改商业汇票结算则借应收票据 33.9 万 / 贷应收账款 33.9 万。

### 预付账款（资产类）
借方记预付/补付，贷方记收到货物冲减、收回多付款。
**讲义例题**：预付供货方材料款 → 预付账款**借方**。**答案 B**。
**例3-20**：采购 5000kg×10 元，预付 50%＝25000；收货时借原材料 50000＋进项 6500 / 贷预付账款 56500，再补付 31500。

### 其他应收款
非营业性的各种应收暂付款：赔款罚款、出租包装物租金、职工垫付款（水电/医药/房租）、存出保证金（押金）、其他暂付款。
**讲义例题**：销售商品应收取的包装物租金 → 其他应收款。**答案 B**（注意"应付租金"才是其他应付款）。
**例3-25** 替职工垫付医疗费 5000：垫付时借其他应收款 / 贷银行存款；扣款时借应付职工薪酬 / 贷其他应收款。

### 应收款项减值（重点，见前文 2026 新口径）
计提公式：`当期应计提 = 期末应保持贷方余额 − 计提前贷方余额`（若为借余则相加）。
**讲义例题**：年初贷 10、发生坏账 5、期末要贷 16 → 补提 16−(10−5)＝11。**答案 A**。

## 四、存货（L2–L5）

### 采购成本 = 价 + 税 + 费
- 含：买价、进口关税/消费税/资源税、不能抵扣的进项税、运输/装卸/保险费、运输途中**合理损耗**、入库前挑选整理费。
- 不含：可抵扣进项税、采购人员差旅费（→管理费用）、入库后仓储费（→管理费用）。
- 商品流通企业进货费用：金额小的可直接计入销售费用。

### 发出计价四法
| 方法 | 要点 |
|---|---|
| 个别计价 | 逐一辨认批次，准确但工作量大；适合定制/贵重物品 |
| 先进先出 | 可随时结转；物价上升时发出成本偏低、高估利润 |
| 月末一次加权平均 | 月末算一次，简化；平时查不到结存金额 |
| 移动加权平均 | 每次进货重算单价，可及时了解结存 |

**例3-32**（D 商品，150@10、购入100@12、200@14、100@15，发出共 400 件）：个别计价法发出 4850 元、期末 2150 元。

### 计划成本法（材料成本差异）
```
实际成本 = 计划成本 + 超支 − 节约
材料成本差异：借方＝入库超支 + 发出节约；贷方＝入库节约 + 发出超支
采购：借 材料采购(实际) + 进项 / 贷 银行存款
入库：借 原材料(计划) / 贷 材料采购(实际) + 材料成本差异(差额，或借方)
```
**讲义例题**：材料成本差异**贷方**登记 → 入库节约、发出超支。**答案 BC**。

### 周转材料
= 包装物 + 低值易耗品（多次使用、不符固定资产定义、逐渐转移价值但保持形态）。
包装物四条去向：
- 生产领用 → 生产成本
- 随商品出售**不单独计价** → 销售费用
- 随商品出售**单独计价** → 其他业务成本（同时确认其他业务收入）
- 出租 → 其他业务成本；出借 → 销售费用

### 委托加工物资
成本 = 发出材料成本 + 加工费 + 运杂费 + 相关税费。
| 消费税 | 收回后**直接销售** | 收回后**连续生产应税消费品** |
|---|---|---|
| 处理 | 计入委托加工物资成本 | 借应交税费——应交消费税（可抵扣） |

**例3-62**：计划成本 70000、差异率 4% → 借委托加工物资 72800 / 贷原材料 70000＋材料成本差异 2800。

### 库存商品
- 已办妥销售手续但购买单位**月末未提取** → 代管商品，备查簿登记，**不属于本企业库存商品**。
- 发出展览、门市部商品、代制品 → 属于库存商品。
- 商品流通企业：毛利率法、售价金额核算法倒算成本。

### 存货清查
| 情形 | 批准后 |
|---|---|
| 盘盈 | 冲减管理费用 |
| 管理不善盘亏 | 管理费用（进项需转出） |
| 自然灾害毁损 | 营业外支出（进项不转出） |

### 存货减值
`可变现净值 = 估计售价 − 至完工估计成本 − 估计销售费用 − 相关税费`
成本与可变现净值**孰低**；计提借资产减值损失/贷存货跌价准备；**在原计提金额内可转回**。
结转销售成本时，已计提跌价准备要同时冲减主营业务成本。

## 五、固定资产（L5–L7）

### 取得
- 外购：成本 = 买价 + 相关税费 + 运输/装卸/安装/专业人员服务费；**一般纳税人进项可抵扣，小规模纳税人进项计入成本**。
- 一揽子购入不同设备：按**公允价值比例**分摊总成本，再加各自安装费。
- 自行建造：自营工程 vs 出包工程；领用材料/自产产品、试运转净支出都进在建工程成本。

### 折旧
四种方法：年限平均、工作量、双倍余额递减、年数总和。
- 双倍余额递减：年折旧率＝2/年限，**前期不扣净残值**；最后两年改直线、扣净残值。
- 不提折旧的只有两种：已提足仍使用、单独计价土地。
- 当月增加当月不提、当月减少当月照提。

### 后续支出
- 符合资本化条件（改扩建）→ 计入在建工程；改造后入账价值 = 原账面价值 − 拆除部分账面价值 + 改造支出。
- 日常修理 → 费用化：管理部门计管理费用、专设销售机构计**销售费用**。

### 处置、清查、减值
- 出售/报废/毁损 → 通过**固定资产清理**（盘盈盘亏不通过）。
- 处置净损益 → 资产处置损益或营业外收支，视原因而定。
- 盘盈 → 重置成本，走**以前年度损益调整**（不是待处理财产损溢）。
- 盘亏 → 待处理财产损溢，净损失进**营业外支出**。
- 减值 → 资产减值损失，**一经计提不得转回**。
