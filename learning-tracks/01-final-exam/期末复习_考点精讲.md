# 第1章 概述

## 1.1 会计概念与职能
- 会计：以**货币为主要计量单位**，对经济活动进行**核算和监督**的经济管理活动。
- **基本职能：核算（最基本）+ 监督**；拓展职能：预测经济前景、参与经济决策、评价经营业绩。
- 核算四环节：确认（定性）→ 计量（定量）→ 记录 → 报告。
- 监督三部分：单位内部监督 + 国家监督（财政/审计/税务）+ 社会监督（注册会计师）＝"三位一体"。
- 关系：**核算是监督的基础，监督是核算质量的保障**。

## 1.2 会计基本假设（4个，必背）

| 假设 | 一句话理解 | ⚠️考点 |
|---|---|---|
| 会计主体 | 为"谁"记账（**空间**范围） | 会计主体≠法律主体：法律主体必是会计主体；车间、分公司、企业集团是会计主体但不是法律主体 |
| 持续经营 | 企业会一直开下去 | 持续经营是**会计分期的前提** |
| 会计分期 | 把经营切成期间 | 分期才产生权责发生制、应收应付、折旧摊销 |
| 货币计量 | 用钱来量 | 不排斥其他计量单位作补充 |

## 1.3 会计核算基础

| 对比 | 权责发生制（企业用） | 收付实现制 |
|---|---|---|
| 收入确认 | 取得**收款权利**时 | 实际收到钱时 |
| 费用确认 | 产生**付款义务**时 | 实际付出钱时 |

- ⚠️经典题：12月租金200万，付了180万 → 权责发生制确认费用 **200**，收付实现制确认 **180**。
- 口诀：**权责看"该不该"，收付看"到没到"**。

# 第2章 会计基础

## 2.1 会计要素（6个）

**资产负债表三要素**（反映财务状况）：

| 要素 | 定义关键词 | 确认条件（除符合定义外） |
|---|---|---|
| 资产 | **过去**交易形成、拥有或**控制**、预期带来经济利益**流入** | ①经济利益很可能流入 ②成本/价值能可靠计量 |
| 负债 | **过去**交易形成、**现时义务**、预期经济利益**流出** | ①很可能流出 ②金额能可靠计量 |
| 所有者权益 | 资产扣除负债后的**剩余权益** | 依赖资产、负债的确认计量 |

- 所有者权益来源：**实收资本（股本）、资本公积、其他综合收益、盈余公积、未分配利润**。
- 债权人：优先索取权、风险小、固定收益；所有者：剩余索取权、风险大、变动收益。

**利润表三要素**（反映经营成果）：

| 要素 | 定义关键词 |
|---|---|
| 收入 | **日常活动**形成、导致所有者权益**增加**、与投入资本无关的经济利益**总流入**（主营+其他业务收入） |
| 费用 | **日常活动**发生、导致所有者权益**减少**、与分配利润无关的经济利益**总流出** |
| 利润 | 收入−费用 + 直接计入当期利润的利得和损失 |

- ⚠️**收入 vs 利得、费用 vs 损失**：日常活动→收入/费用（总流入/流出）；非日常→利得/损失（净流入/流出，如营业外收支）。
- 利润三层：营业利润 → 利润总额（＋营业外收支）→ 净利润（−所得税费用）。
- ⚠️经典"不属于资产"：约定未来购入的存货、盘亏的固定资产、经营租赁临时租入的仓库（不属于）；委托加工物资、生产成本（属于，本质是在产品）。

## 2.2 计量属性（5个，对号入座）

| 属性 | 典型应用 |
|---|---|
| 历史成本（实际成本） | 大多数业务、固定资产初始入账（**一般应当采用**） |
| 重置成本 | **固定资产盘盈** |
| 可变现净值 | **存货期末计量**（预计售价− further 加工成本−税费费用） |
| 现值 | 融资性质分期付款购固定资产 |
| 公允价值 | 交易性金融资产期末计量 |

⚠️判断题陷阱："重置成本是预计售价减进一步加工成本…"（错，那是可变现净值）。

## 2.3 会计等式

- **资产 = 负债 + 所有者权益**（静态、财务状况等式、编制**资产负债表**依据、复式记账理论基础）
- **收入 − 费用 = 利润**（动态、经营成果等式、编制**利润表**依据）

九类业务对等式的影响（背规律）：**等式一边内部 → 一增一减；等式两边 → 同增同减；恒等式永远平衡。**

## 2.4 借贷记账法

| 账户类型 | 增加记 | 减少 | 期末余额 |
|---|---|---|---|
| 资产类、成本类 | 借 | 贷 | 借方 |
| 负债类、所有者权益类 | 贷 | 借 | 贷方 |
| 收入类 | 贷 | 借 | 结转后无余额 |
| 费用类 | 借 | 贷 | 结转后无余额 |

- 记账规则：**有借必有贷，借贷必相等**。
- ⚠️备抵账户结构与被调整账户**相反**：坏账准备（对 Sawtooth 应收账款）、存货跌价准备、累计折旧、固定资产减值准备——都是"贷加借减"。
- 成本类科目：**生产成本、制造费用、研发支出**（⚠️主营业务成本/其他业务成本是**损益类**！）。

## 2.5 试算平衡

- 发生额平衡依据：记账规则；余额平衡依据：会计等式。
- ⚠️**试算平衡≠记账一定正确**。不影响平衡的错误6种：漏记、重记、双方同多记/少记、记错账户、颠倒方向、多记少记偶然抵销。
- 口诀：**不平衡必有错，平衡不一定对**。

# 第3章 流动资产（全章重点，必考大题来源）

## 3.1 货币资金

**库存现金清查（高频）**：

| 情形 | 批准前 | 批准后 |
|---|---|---|
| 短缺 | 借：待处理财产损溢 贷：库存现金 | 责任人赔→**其他应收款**；查不出→**管理费用** |
| 溢余 | 借：库存现金 贷：待处理财产损溢 | 应付他人→**其他应付款**；查不出→**营业外收入** |

⚠️**溢余查不出→营业外收入（不是冲管理费用）**；短缺查不出→管理费用。

现金管理制度要点：现金限额按 3~5 天日常零星开支核定（边远地区不超 15 天）；**不得坐支**（不能直接用现金收入支付现金支出）。

**银行存款**：日记账与对账单**至少每月核对一次**，差额编"银行存款余额调节表"；调节后余额 = 实际可动用金额。银行存款余额调节表**不是原始凭证，不作记账依据**。

**其他货币资金（6类，常考"哪个计入"）**：银行汇票存款、银行本票存款、信用卡存款、信用证保证金存款、存出投资款、外埠存款。
- 账务套路：存出时 借"其他货币资金"贷"银行存款"；购货时 借"原材料+进项税" 贷"其他货币资金"；余额退回 借"银行存款"。
- ⚠️辨析：收到银行汇票/本票结算销售款 → 借**银行存款**；收到**商业汇票** → 应收票据；开出银行承兑汇票购货 → 应付票据。
- ⚠️"货币资金总额是否减少"题：银行存款↔其他货币资金互转**总额不变**；用其他货币资金实际购物付款才减少。

## 3.2 应收及预付款项

**增值税基础分录（所有业务通用）**：
- 采购：借 原材料（价款）＋应交税费—应交增值税（进项税额）贷 银行存款（价税合计）
- 销售：借 银行存款（价税合计）贷 主营业务收入（不含税价）＋应交税费—应交增值税（销项税额）
- 应纳增值税 = 销项 − 进项。增值税是**价外税**，最终由消费者承担。

**应收票据**：商业汇票（付款期限**最长不超过6个月**）；银行承兑汇票手续费→**财务费用**。
- 关键分录：收票 借应收票据 贷应收账款；**背书转让购材料** 借原材料＋进项 贷应收票据；到期收款 借银行存款 贷应收票据。

**应收账款**：内容包括价款、增值税、**代垫运杂费包装费**（⚠️代垫运费记应收账款，不是其他应收款）。

**预付账款**：预付不多可不设科目，并入**应付账款**核算（口诀：**付对负**）。
- 收货时 借原材料＋进项 贷预付账款；补付 借预付账款 贷银行存款。
- 期末**贷方余额**反映应补付的款项（性质转为负债）。

**其他应收款（内容必背）**：①应收赔款罚款 ②应收出租包装物租金 ③**代职工垫付**的医药费房租水电 ④**存出保证金**（付的押金）⑤备用金、职工预借差旅费。

**应收款项减值（备抵法，计算必考）**：
- 我国企业准则用**备抵法**（小企业准则用直接转销法）。
- 核心公式：**当期应计提坏账准备 = 期末应有坏账准备余额 − 计提前"坏账准备"贷方余额**（若为负→转回；若有借方余额则加上）。
- **应收账款账面价值 = 账面余额 − 坏账准备**。

| 业务 | 分录 | 对账面价值影响 |
|---|---|---|
| 计提 | 借信用减值损失 贷坏账准备 | **减少** |
| 转回多提 | 借坏账准备 贷信用减值损失 | **增加** |
| 实际转销坏账 | 借坏账准备 贷应收账款 | **不影响**（同减） |
| 收回已转销坏账 | 借应收账款 贷坏账准备；借坏账准备 贷信用减值损失；借银行存款 贷应收账款 | **综合不影响** |

⚠️高频判断：**转销坏账、收回已转销坏账都不影响应收账款账面价值**；计提、转回影响。

## 3.3 存货（最大重点）

**初始计量——计入 vs 不计入存货成本**：

| 计入成本 | 不计入（计入当期损益） |
|---|---|
| 购买价款、进口关税、运输费装卸费保险费、**运输途中合理损耗**、入库**前**挑选整理费、特定客户设计费 | 非正常消耗（自然灾害→营业外支出；管理不善→管理费用）、**入库后**仓储费、入库**后**挑选整理费、采购人员差旅费、可抵扣增值税 |

**四种发出计价法**（结合例题掌握计算）：

| 方法 | 特点/公式 | 优缺点 |
|---|---|---|
| 个别计价法 | 实物流转=成本流转 | 准确；适用于珠宝名画等 |
| 先进先出法 | 先购先发 | 物价上升→发出成本低→**高估利润和存货** |
| 月末一次加权平均 | 单位成本=(月初成本+本月进货成本)÷(月初数量+本月进货数量) | 简单；**平时无法**提供发出/结存单价 |
| 移动加权平均 | 每次进货后重算一次单位成本 | 及时了解结存；工作量大 |

**原材料——实际成本法**（4种到货付款情形）：

| 情形 | 科目 |
|---|---|
| 钱付了，货到了 | 借原材料 贷银行存款等 |
| 钱付了，货没到 | 借**在途物资** → 到货后 借原材料 贷在途物资 |
| 货到了，钱没付（单已到） | 贷**应付账款** |
| 货到了，单没到 | 月末按暂估价 借原材料 贷**应付账款—暂估**；下月初**红字冲回**（⚠️不暂估增值税） |

发出材料按用途：生产成本（生产工人）/制造费用（车间管理）/管理费用/销售费用/在建工程/研发支出/其他业务成本（出售）→ 贷原材料。

**计划成本法（计算必考）**：
- 三科目：**材料采购**（实际成本）、**原材料**（计划成本）、**材料成本差异**（差额）。
- 入库：超支差异记**借方**，节约差异记**贷方**。
- 差异率 =（期初差异＋本期入库差异）÷（期初计划成本＋本期入库计划成本）×100%（**超支为正、节约为负**）
- **发出材料实际成本 = 发出计划成本 ×（1＋差异率）**；结存同理。
- 分摊差异：结转超支 借生产成本等 贷材料成本差异；结转节约相反。
- ⚠️"材料成本差异借方"核算：**入库的超支差异 + 发出的节约差异**。

**周转材料**：
- 生产领用包装物 → **生产成本**；随商品出售**不单独计价** → **销售费用**；**单独计价** → 收入记**其他业务收入**、成本记**其他业务成本**；出租包装物（租金/修理费/摊销）→ **其他业务成本**；出借包装物（摊销/修理费）→ **销售费用**，押金记**其他应付款**。
- 低值易耗品摊销：一次摊销法 / 分次摊销法（在库→在用→摊销）。

**委托加工物资（计算必考）**：
- 成本 = 发出材料实际成本 ＋ 加工费 ＋ 运杂费 ＋（**收回后直接出售**时的消费税）。
- ⚠️消费税：收回后**直接出售**→计入成本（借委托加工物资）；收回后**连续生产应税消费品**→借**应交税费—应交消费税**（可抵扣），不计入成本。
- 可抵扣增值税进项税额**始终不计入成本**。

**库存商品——商品流通企业两法**：
- **毛利率法**：销售毛利=销售净额×毛利率；销售成本=销售净额−毛利；期末存货=期初＋购进−销售成本。
- **售价金额核算法**：差价率=(期初进销差价＋本期购进进销差价)÷(期初售价＋本期购进售价)；已销商品分摊差价=本期销售收入×差价率；销售成本=收入−分摊差价。
- ⚠️已完成销售手续但月末未提货 → 代管商品，不作库存商品。

**存货清查**：

| 情形 | 批准后处理 |
|---|---|
| 盘盈 | 冲减**管理费用**（⚠️与固定资产盘盈不同！） |
| 盘亏 | 残料→原材料；赔款→其他应收款；管理不善→**管理费用**（且**进项税额要转出**）；自然灾害→**营业外支出**（进项**不转出**） |

**存货减值**：
- 期末按**成本与可变现净值孰低**计量；成本＞可变现净值→计提跌价准备。
- 可变现净值：直接出售 = 估计售价−销售费用税费；需加工 = 估计售价−**至完工进一步加工成本**−销售费用税费。
- 当期应计提 =（成本−可变现净值）− 已有贷方余额；负数则在已提范围内**转回**（⚠️跌价准备可以转回，最多转回到余额为0）。
- 计提：借**资产减值损失** 贷存货跌价准备；转回相反。

# 第4章 非流动资产

## 4.1 固定资产（必考）

**入账成本** = 买价 ＋ 相关税费（不含可抵扣增值税）＋ 运输费装卸费安装费专业人员服务费等使资产达到预定可使用状态前的支出。
- ⚠️**员工培训费**→管理费用，不计入成本；**一般纳税人**进项税可抵扣不计入成本，**小规模纳税人**进项税计入成本。
- 需安装 → 先"**在建工程**"，达到预定可使用状态转"固定资产"。
- 一笔款项购入多项无单独标价固定资产 → 按**公允价值比例**分配总成本。

**自营工程**：购工程物资→领用→（领用自产产品按**成本**记库存商品转出）→ 工资 → 完工转固定资产。
**出包工程**：按结算的工程价款记在建工程。

**折旧范围（高频选择题）**：
- 不计提折旧的只有两类：①**已提足折旧仍继续使用** ②**单独计价入账的土地**。
- 按月计提：**当月增加当月不提、下月起提；当月减少当月照提、下月起不提**。
- 已达预定可使用状态未办竣工决算 → 按估计价值计提，决算后调整成本**但不调整已提折旧**。
- 更新改造（改扩建）期间不提折旧；日常维修、未使用不需用、暂时闲置的都要提。

**折旧四法（计算必考）**：

| 方法 | 公式要点 |
|---|---|
| 年限平均法 | 年折旧额=原价×(1−净残值率)÷预计年限 |
| 工作量法 | 单位工作量折旧额=原价×(1−净残值率)÷总工作量 |
| 双倍余额递减法 | 年折旧率=2÷年限（**不考虑净残值**）；年折旧额=年初账面净值×年折旧率；**最后两年**改为（净值−净残值）÷2 |
| 年数总和法 | 年折旧额=(原价−净残值)×尚可使用年限÷年数总和（**净残值始终扣除**，折旧率逐年递减） |

⚠️折旧年度≠会计年度：3月购入，折旧年度=当年4月~次年3月。跨年度折旧题先算各折旧年度折旧额，再按月拆到会计年度。
账面原值=入账价值；账面净值=原值−累计折旧；**账面价值=原值−累计折旧−减值准备**。

折旧去向：生产车间→**制造费用**；管理部门及**未使用**→管理费用；销售部门→销售费用；经营租出→**其他业务成本**；在建工程用→在建工程；研发用→研发支出。

**后续支出**：
- 资本化（更新改造）：账面价值转入在建工程；新成本 = 改造前账面价值 ＋ 资本化支出 − **被替换部分账面价值**（⚠️变价收入不冲减在建工程，报废部分账面价值记营业外支出）。
- 费用化（日常修理）：行政部门→**管理费用**；销售机构→销售费用；与存货生产相关→制造费用。

**处置（固定资产清理五步）**：
1. 转入清理：借固定资产清理（账面价值）＋累计折旧＋减值准备 贷固定资产
2. 清理费用：借固定资产清理 贷银行存款
3. 收价款/残料/变价收入：借银行存款/原材料 贷固定资产清理＋销项税
4. 保险赔偿：借其他应收款 贷固定资产清理
5. 结转净损益：**出售/转让→资产处置损益；报废/毁损→营业外收支**（⚠️高频辨析！）

**清查**：
- **盘盈**：按重置成本 借固定资产 贷**以前年度损益调整** → 结转**盈余公积＋未分配利润**（不影响当期损益！）
- **盘亏**：借待处理财产损溢（账面价值）＋累计折旧 贷固定资产（进项转出，自然灾害除外）；批准后 赔款→其他应收款，净损失→**营业外支出**。

**减值**：可收回金额＜账面价值 → 差额计提；借资产减值损失 贷固定资产减值准备。**一经确认，以后期间不得转回**。

## 4.2 无形资产

- 特征：无实物形态、**可辨认性**（能分离/源自合同或法定权利）、非货币性。⚠️**自创商誉、内部品牌不是无形资产**。
- 内容：专利权、非专利技术、商标权、著作权、土地使用权、特许权。

**取得**：
- 外购成本 = 价款＋税费＋直接归属支出（专业服务费、测试费、注册费）。⚠️**广告费→销售费用、培训费→管理费用**，不计入。
- **自行研发（必考）**：研究阶段支出 → **研发支出—费用化支出** → 期末转**管理费用**；开发阶段符合资本化条件 → **研发支出—资本化支出** → 达到预定用途转**无形资产**；**无法区分研究/开发 → 全部费用化**。

**摊销**：使用寿命有限 → **当月增加当月摊、当月处置当月不摊**（⚠️与固定资产折旧相反！）；使用寿命不确定 → **不摊销**，但每期减值测试；残值一般为零。去向：管理用→管理费用；出租→其他业务成本；生产用→生产成本/制造费用。

**出售 vs 报废**：出售净损益→**资产处置损益**；报废转销→**营业外支出**。

**减值**：与固定资产相同，**不得转回**。

## 4.3 长期待摊费用
- 分摊期限**1年以上**的费用（如租入固定资产改良支出）。发生：借长期待摊费用 贷银行存款等；摊销：借管理费用等 贷长期待摊费用。

# 第5章 负债（part1 范围）

## 5.1 短期借款
- 期限 ≤1年。利息：**预提**（按季付/到期还本付息且数额大）→ 借财务费用 贷**应付利息**；直接支付（按月付/数额小）→ 借财务费用 贷银行存款。

## 5.2 应付及预收账款
- **应付票据**（付款期限≤6个月）：
  - **商业承兑汇票到期无力支付 → 转应付账款**；**银行承兑汇票到期无力支付 → 转短期借款**（银行代付）⚠️必考辨析！
  - 银行承兑手续费：借财务费用＋进项税 贷银行存款。
- **应付账款**：入账金额 = 价款＋增值税＋**对方代垫运杂费**。确实无法支付转销 → **营业外收入**。外购电力燃气先通过应付账款暂付，月末按用途分配。
- **合同负债**：已收/应收客户对价但尚未转让商品的义务。收款 借银行存款 贷合同负债；履约 借合同负债 贷主营业务收入。⚠️不含增值税部分（记应交税费—待转销项税额）。不适用收入准则的预收款用"预收账款"。
- **应付利息**：已过付息期尚未支付的利息。
- **应付股利**：股东大会**批准**的现金股利分配方案 → 借利润分配 贷应付股利。⚠️**董事会**拟分配方案：**不进行账务处理**，附注披露；**股票股利：宣告和实际发放都不通过应付股利**（实际发放借利润分配 贷股本）。
- **其他应付款**：应付短期租赁固定资产租金、低价值资产租赁租金、**租入包装物租金**、**出租/出借包装物收的押金（存入保证金）**、代扣职工个人社保公积金。
  - ⚠️对比记忆：**付出去的押金→其他应收款；收进来的押金→其他应付款**。

## 5.3 应付职工薪酬

**职工三类**：劳动合同职工（含全职兼职临时）、正式任命的董监高、劳务派遣/类似服务人员。

**四大类（分类必考）**：

| 类别 | 内容 |
|---|---|
| 短期薪酬 | 工资奖金津贴补贴、职工福利费、**医疗/工伤/生育**保险、住房公积金、工会经费(2%)、职工教育经费(8%)、短期带薪缺勤、短期利润分享计划、**非货币性福利** |
| 离职后福利 | **基本养老保险、失业保险**（设定提存计划：缴存固定费用后不再承担进一步义务） |
| 辞退福利 | 解除劳动关系或鼓励自愿裁减的补偿（**一律计入管理费用**，不计资产成本） |
| 其他长期职工福利 | 长期带薪缺勤、长期残疾福利、长期利润分享计划 |

- ⚠️**职工出差预借差旅费不属于职工薪酬**（其他应收款）；**个人承担的社保公积金**不是企业薪酬，但通过应付职工薪酬借方代扣 → 贷**其他应付款**。

**货币性薪酬**：计提按受益对象：生产工人→生产成本；车间管理→制造费用；行政→管理费用；销售→销售费用；研发→研发支出；工程→在建工程。发放时扣款：借应付职工薪酬 贷其他应收款（代垫款项）＋应交税费—应交个人所得税＋银行存款。

**非货币性福利（自产产品发福利 = 视同销售，计算必考）**：
1. 计提：借生产成本/管理费用等 贷应付职工薪酬—非货币性福利（**含税公允价值** = 人数×售价×(1+13%)）
2. 发放：借应付职工薪酬 贷主营业务收入（公允价值）＋销项税额；同时结转成本 借主营业务成本 贷库存商品
3. 自有资产无偿用（如汽车）：计提薪酬同时 借应付职工薪酬 贷累计折旧；租赁住房：按租金确认，支付时冲应付职工薪酬。

**设定提存计划**（养老保险16%）：计提 借生产成本等 贷应付职工薪酬—设定提存计划。

# 考前速记：高频易错辨析 TOP12

1. 现金盘盈→营业外收入；**存货盘盈→冲管理费用**；**固定资产盘盈→以前年度损益调整**（三兄弟各不同）
2. 现金盘亏查不出→管理费用；存货盘亏管理不善→管理费用（进项转出）；自然灾害→营业外支出（不转出）
3. 商业承兑汇票买方无力付→应付账款；银行承兑→短期借款
4. 出售固定资产/无形资产净损益→资产处置损益；报废毁损→营业外收支
5. 折旧：当月增加不提；摊销：**当月增加当月提、处置当月不提**
6. 双倍余额递减法**前期不考虑净残值**、最后两年扣；年数总和法**一直扣净残值**
7. 委托加工消费税：直接出售→入成本；连续生产→应交税费借方
8. 材料成本差异借方=入库超支＋发出节约；超支为正、节约为负
9. 存货跌价准备**可转回**（限已提金额内）；固定资产/无形资产减值**不得转回**
10. 坏账：转销、收回已转销 → 不影响应收账款账面价值；计提、转回 → 影响
11. 股票股利不做账（发放时贷股本）；董事会方案不做账；**股东大会批准的现金股利**才确认应付股利
12. 包装物：生产领用→生产成本；不单独计价→销售费用；单独计价/出租→其他业务收入/成本
