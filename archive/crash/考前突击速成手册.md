> 考前冲刺专用。**不追求学完，只求三件事：看得懂题、记得住判断、不会也能蒙。**
> 内容全部来自你这 13 个文件的题目。考前 30 分钟重点看：第一部分表格 + 第二部分加粗项 + 第三部分数字。

## 一、读不懂题？三步拆题法

竞赛题翻来覆去就一个套路：**用固定问法考不同知识点**。看不懂时拆三步：

**第 1 步 找主体**——这题问的是谁？
常见主体：单位负责人 / 会计机构 / 出纳 / 董事会 / 财政部门 / 人民代表大会 / 国务院财政部门。
**主体认错，答案必错。** 万能记法：责任类题，第一责任人永远是「**单位负责人**」。

**第 2 步 找动作**——在问"能不能 / 该不该 / 由谁做"？
盯住这几对词：**应当 vs 可以**、**必须 vs 鼓励**、**不得 vs 需要**。这类题的坑 90% 就在这一对词上。

**第 3 步 找数字**——题干里有没有时间 / 金额 / 比例？
有数字的题，答案往往就是那个数字，先去第三部分扫一眼。

### 三种题型，题眼不一样

| 题型 | 常见问法 | 怎么下手 |
|---|---|---|
| 单选 | 「下列各项中，属于 / 正确的是」「……为（　）」 | 四选一。先划掉明显错的，剩两个再比 |
| 多选 | 「下列说法正确的有」「包括」「符合……的有」 | **大概率 2–4 个对！只选一个通常就丢分** |
| 判断 | 一句陈述句，判断对错 | **先找绝对词**（见下） |

### 绝对词 / 柔性词 —— 判断题的命门

| 题干里出现 | 大概率的答案 |
|---|---|
| 都、全部、一律、任何、必须、只能、一定、绝不 | **错**（太绝对） |
| 可以、应当、原则上、一般、通常 | 先按「对」考虑，再看有没有被偷换 |
| 选项里出现 仅 / 只 / 均 / 唯一 | 该选项**大概率错** |

> 一句话：**绝对化 = 陷阱。** 出题人最爱把「可以」改成「必须」、把「部分」改成「全部」。

### 实在不会怎么蒙

1. **单选**：选表述最平实、最不像废话的；两个选项意思相反时，答案常在这两个里。
2. **多选**：先删掉带绝对词的项，剩下的能选几个选几个，**宁多不少**。
3. **判断**：不会就**判错**（把对的改错，比把错的改对更容易）。
4. **数字题**：选中间值（给了 5 万 / 20 万 / 50 万，猜 20 万）。

## 二、记住就能判断的硬规则（按模块）

> ★ = 更该先记的。考前把加粗的看两遍。

### 01 会计法
- ★ 会计工作第一责任人 = **单位负责人**（不是财务总监、不是总会计师）
- ★ 记账本位币：可选外币记账，但**报告必须折算人民币**
- 原始凭证：不真实 / 不合法 → 拒收并报单位负责人；不准确 / 不完整 → 退回补正
- ★ 原始凭证**金额错只能由出具单位重开**，不得在凭证上更正；其他内容不得涂改
- 账簿更正盖章 = 会计人员 + 会计机构负责人（**不是单位负责人**）
- 内部会计监督主体 = 会计机构、会计人员（**不是纪检部门**）
- ★ 罚款两档：个人一般 ≤5 万 / 严重 5 万–50 万；单位一般 ≤20 万 / 严重 20 万–100 万
- 隐匿、销毁凭证账簿（严重）：个人 **50 万–200 万**
- ★ 禁业：违法未犯罪 **5 年**；构成犯罪 **终身**
- 交接监交：一般人员由会计机构负责人监交，机构负责人由单位负责人监交

### 02 企业会计准则
- 会计信息质量 8 要求：可靠、相关、可理解、可比、实质重于形式、重要、谨慎、及时
- ★ **减值：流动可转回（存货 / 应收 / 合同资产）；长期不能回（固资 / 无形 / 长投 / 商誉 / 成本模式投房）**
- 盘盈盘亏：存货盘盈 → 冲管理费用；固资盘盈 → 以前年度损益调整；现金溢余 → 营业外收入
- ★ 折旧起算：企业固资**当月增不提、次月起提**；政府资产**当月增当月折**
- ★ 投资性房地产：**成本模式能转公允，公允模式不能转回成本**
- 内部研发：研究阶段**费用化**，开发阶段符合条件才**资本化**
- 政府补助（与收益相关）：补以后的 → 递延收益；补已发生的 → 直接进损益
- 股份支付：**市场条件不管账**，非市场条件才管成本确认
- 售后回购：回购价 **≥** 原售价 → 按**融资**；回购价 **<** 原售价 → 按**租赁**
- 合并直接费用（审计 / 评估 / 法律费）→ **一律进管理费用**

### 03 政府会计准则
- ★ **双基础**：财务会计 = 权责发生制；预算会计 = 收付实现制
- ★ **双报告**：决算报告给人大；财务报告给公众
- 平行记账只针对**纳入部门预算管理的现金收支**
- 政府叫「**净资产**」「投资损益」；企业才叫「所有者权益」「投资收益」
- 政府资产折旧：**当月增加当月提**
- 结转按原用途继续用；结余可重新安排

### 04 内部控制规范
- ★ 五要素：内部环境、风险评估、控制活动、信息与沟通、内部监督（"环境评估控活动，信息沟通加监督"）
- 五原则：全面性、重要性、制衡性、适应性、成本效益（"全重制适本"）
- ★ 风险应对四策略：**规避 = 放弃停止；降低 = 控制减少；分担 = 转移；承受 = 不采取措施**
- ★ **出纳管钱不管账**：不得兼管稽核、会计档案、收入 / 费用 / 债权债务登记；**可以**登记现金 / 银行日记账
- 内控评价报告：基准日 12 月 31 日，**4 个月内**报出

### 05 会计信息化
- 第一责任人 = **单位负责人**
- ★ 云端数据归**用户（单位）**所有，不归服务商
- ★ 境外服务器部署 → 必须**境内备份，每月不低于一次**
- 电子凭证打印件报销 → 必须**同时保存电子原文件**
- 建设原则是「**鼓励**」不是「必须」；云计算非强制

### 06 管理会计
- ★ 服务**内部管理层**，不做外部报告（"内政不对外"）
- 核心功能 = 提供决策支持；核心领域 = 成本控制与优化
- 指引体系 = 基本指引 + 应用指引 + 案例库
- 职能里**不含财务审计**
- 作业成本法：**资源动因 → 作业，作业动因 → 产品**

### 07 税法相关
- ★ 增值税视同销售：**自产 / 委托加工 → 对外投资、分配、赠送、集体福利全部视同；外购 → 用于集体福利 / 个人消费不视同（作进项转出）**
- ★ **商业折扣先打折**（直接减收入）；**现金折扣后入账**（实际发生时进财务费用）
- ★ 税金去向：契税、耕地占用税、车购税、进口关税 → **进成本**；消费税、印花税、房产税、城建税 → **当期（税金及附加）**；企业所得税本身、可抵扣增值税 → **不得扣**
- 个税看雇佣关系：本单位发 → 工资薪金；无雇佣 → 劳务报酬；专利 / 商标使用权 → 特许权使用费
- 不征税的补贴：独生子女补贴、托儿补助、差旅津贴、误餐补助（"独托差误不征税"）
- 大病医疗扣除：只能扣本人、配偶、未成年子女，**不能扣父母**

### 08 预算法
- ★ 预算批准主体 = **人民代表大会**
- ★ **超收收入只有两个用途：冲减赤字、补充预算稳定调节基金**
- 全部收支纳入预算；各级政府**不得向部门下达收入指标**
- **派出机关不是一级预算**，其收支纳入本级
- ★ 时限：财政批部门 **20 日**；部门批单位 **15 日**；预决算批复后 **20 日内**公开
- 实行国库集中收付

### 09 会计档案管理办法
- ★ 保管期限：年报 **永久**；凭证 / 账簿 **30 年**；固定资产卡片 **报废清理后 5 年**；定期最低 **10 年**
- 归档范围四类：会计凭证、会计账簿、财务会计报告、其他会计资料
- ★ **未结清债权债务的凭证不得销毁**，保管至未了事项完结
- 出纳不得兼管会计档案
- 移交保持原封装；销毁三条件 = 期满、审核、合法

### 10 会计基础工作规范
- ★ 会计机构负责人任职：会计师以上资格 **或** 从事会计工作满 3 年（是「或」，不是「且」）
- 原始凭证只认**报销联**；记账凭证填写人承担法律责任
- ★ 财报由**单位负责人 + 主管会计工作负责人 + 会计机构负责人**签名**并**盖章
- 回避：会计主管的亲属不得在本单位担任**出纳**
- 交接未办清，**不得调动或离职**；接替人继续用原账簿
- 错账更正：划线、红字、补充登记（**没有"蓝字"法**）

### 11 会计职业道德
- ★ 三条核心：**坚持诚信守法奉公（自律）／坚持准则守责敬业（履职）／坚持学习守正创新（发展）**
- ★ 制定依据 =《会计法》+《会计基础工作规范》（**不是《民法典》**）
- 保密不是绝对的：法律规定或单位负责人同意可提供
- 保密是「**最基本**」的职业道德要求

### 12 数据资产管理
- ★ 治理模式：**市场主导、政府引导、多方共建**
- 收益分配原则：**谁投入、谁贡献、谁受益**
- ★ 配置方式 = 自主采集、生产加工、购置（**没有"投资"**）
- ★ 公益事业 → **无偿**使用；产业发展 → **有偿**使用
- 数据资产**不得用于担保**
- 研发：研究阶段费用化，开发阶段符合条件才资本化

### 13 综合法规
- ★ 法律效力层级：**法律 ＞ 行政法规 ＞ 部门规章 ＞ 规范性文件**
- ★ **起征点 = 全额征；免征额 = 超额征**
- 会计政策变更 → 追溯调整；会计估计变更 → **未来适用**
- 营业外支出属**损失**，不属于费用
- 现金流量：税费返还 / 销售收现 → 经营；偿还债务 → 筹资；收股利 / 处置资产 → 投资
- ★ 政府采购：公开招标是主要方式；**招标到投标截止 ≥20 日；质疑答复 7 个工作日；投诉 15 个工作日**；履约保证金 ≤ 合同金额 10%
- 公积金弥补亏损：先法定、任意，后资本公积（**无 25% 限制**）
- 减资弥补亏损：不得向股东分配，也不得免除股东出资义务

## 三、常见术语一句话翻译（看不懂题名就查这里）

| 术语 | 大白话 |
|---|---|
| 权责发生制 | 业务一发生就记账，不管钱到没到 |
| 收付实现制 | 钱实际收 / 付了才记账 |
| 谨慎性 | 不高估资产收益、不低估负债费用 |
| 实质重于形式 | 看经济实质，不看合同表面（如售后回购） |
| 视同销售 | 不是销售，但按销售交税 |
| 递延收益 | 现在收了钱先挂账，以后再算收益 |
| 公允价值 / 账面价值 | 市场能卖多少 / 账上记了多少 |
| 追溯调整 vs 未来适用 | 改以前年度的账 / 只改以后 |
| 资本化 vs 费用化 | 计入资产成本分期摊 / 直接算当期费用 |
| 平行记账 | 一笔业务同时记财务会计和预算会计两套账 |
| 结转 / 结余 | 专款专用接着用 / 年底剩的钱可重新安排 |
| 商誉 | 买公司多付的那部分钱 |
| 履约进度 | 活干完了百分之多少 |

## 五、考场策略（照做）

1. **先通做一遍**：会做的立刻做，不确定的标记后跳，别在一题上卡住。
2. **判断题绝不空**：不会就按「绝对词 = 错」判，蒙也有 50%。
3. **多选题宁多不少**：拿不准的项倾向选。少选必丢分，多选还有可能对。
4. **数字题先回忆模式**：罚款记两档、期限记「20 / 15 / 7」、比例记关键几个。
5. **主体先对再选**：拿不准时先问自己"这题问的是谁的责任"。
6. **留 5 分钟复查多选题**：最容易漏项，回头把多选题扫一遍。
