**1. 会计机构与人员配备（共7题：单选3 / 多选2 / 判断2）**
- 会计机构设置：各单位按会计业务需要设置会计机构；不具备条件的在有关机构配备专职会计人员
- 岗位设置形式：会计工作岗位可一人一岗、一人多岗或一岗多人
- 岗位轮换：会计工作岗位应实行有计划的轮换
- 稽核制度：出纳可登记现金/银行存款日记账，但不得兼管稽核、档案保管及收支债账登记
- 回避制度：会计主管的三代以内旁系血亲及直系亲属不得担任本单位出纳
- 总会计师条件：总会计师由具有会计师以上专业技术资格的人员担任
- 人员素质与奖励：会计人员须具备专业会计能力；做出显著成绩者给予奖励

**2. 会计人员任职与代理记账管理（共8题：单选1 / 多选1 / 判断6）**
- 会计主管任职条件：具有会计师以上资格或从事会计工作三年以上经历（二者满足其一）
- 会计主管基本条件：坚持原则廉洁奉公、熟悉法规掌握业务、组织能力强、身体适应工作
- 代理记账组织方式：未设会计机构或岗位的单位可委托代理记账机构或财政部规定其他方式
- 行政单位代理记账：行政单位不具备配备条件的，可委托经批准的中介机构代理记账
- 代理记账负责人条件：须有会计师以上资格或从事会计工作不少于3年，且为专职从业人员
- 委托合同形式：委托人与代理记账机构应订立书面合同，不得以口头形式订立

**3. 会计核算基本规范（共6题：单选3 / 多选2 / 判断1）**
- 规范主要内容：涵盖会计凭证、账簿、档案、核算、监督等，不含"会计人员职务说明书"
- 核算事项范围：款项有价证券收付、财物收发增减、债权债务结算、资本基金增减应办会计手续
- 禁止行为：会计人员不得伪造、变造、篡改财务数据
- 违反规范处罚：可能面临行政处分、罚款、解雇乃至法律责任
- 适用范围：国家机关、企业、事业单位、社会团体均应执行会计基础工作规范
- 保密义务：应保守商业秘密，但法律规定或经单位负责人同意可对外提供

**4. 会计凭证填制、审核与保管（共11题：单选8 / 多选2 / 判断1）**
- 凭证填制原则：按真实性、完整性（及时性）原则填制
- 原始凭证联次：一式几联的应注明各联用途，只能以报销联作为报销凭证
- 凭证填制要求：不得涂改挖补，字迹清晰工整；机制凭证应认真审核
- 记账凭证填制：填制（未入账）时错误应重新填制；应连续编号，可据同类原始凭证汇总填制
- 附凭证例外：结账和更正错误的记账凭证可不附原始凭证
- 原始凭证必备内容：日期、经济业务内容、数量单价金额、填制单位或人员签章
- 凭证审核签署：由会计主管（财务主管）审核签字，须经稽核、复核
- 凭证保管期限：会计凭证保管期限最短10年（现行为30年），不少于10年

**5. 会计账簿登记（共6题：单选2 / 多选1 / 判断3）**
- 日记账簿形式：现金及银行存款日记账必须采用订本式，不得用银行对账单代替
- 订本式编号：启用订本式账簿应从第一页到最后一页顺序编号，不得跳页缺号
- 错账更正方法：只有划线更正法、红字更正法、补充登记法，无"蓝字更正法"
- 账证核对：账证核对即账簿记录与会计凭证核对（如日记账与收付款凭证）
- 账簿管理：凭证及时归档、账簿按规定登记并妥善保管，不得由外部人员代管

**6. 财务会计报告编制与签署（共5题：单选2 / 多选2 / 判断1）**
- 报告编制要求：数字真实、计算准确、内容完整、说明清楚
- 报告编制准则：遵循会计准则和法规，不能无审核自行编制，需披露详细数据
- 报表审核：会计报表必须由财务负责人审核并签字
- 报告签署方式：单位负责人、主管会计工作负责人、会计机构负责人签名并盖章
- 代理记账报告签署：由代理机构负责人和委托人负责人签名并盖章后对外提供

**7. 会计工作交接与会计监督（共5题：单选0 / 多选2 / 判断3）**
- 交接前工作：编制移交清册；未登记账目登记完毕并在最后一笔余额后盖章
- 未了事项说明：未了事项应作书面说明（非口头）
- 已受理未填制凭证：移交前已受理未填制的凭证应由移交人填制完毕，非接替人
- 监交规定：一般会计人员交接由会计机构负责人监交；会计主管交接由单位负责人监交
- 交接后离职：会计人员调动或离职须全部移交，未办清交接手续不得调动或离职
- 财会监督：会计机构人员对本单位经济活动监督，自行确定内部监督检查方法范围频率
