**1. 会计基本准则与会计信息质量（共40题：单选23 / 多选11 / 判断6）**
- 会计信息质量要求：可靠性、相关性、可理解性、可比性、实质重于形式、重要性、谨慎性、及时性
- 可靠性：以实际发生的交易或事项为依据，保证真实可靠、内容完整
- 相关性：会计信息应与使用者经济决策需要相关，有助于评价或预测
- 谨慎性：不高估资产收益、不低估负债费用，如计提减值、孰低计量、确认预计负债
- 会计计量属性五种：历史成本、重置成本、可变现净值、现值、公允价值（权责发生制不是）
- 会计政策变更用追溯调整法；会计估计变更用未来适用法计入当期
- 折旧方法、计提比例、估值方法属会计估计；计价方法、计量模式属会计政策
- 收入为日常活动经济利益总流入，利得为非日常净流入；费用化使资产与所有者权益同减

**2. 存货、固定资产与无形资产（共41题：单选20 / 多选10 / 判断11）**
- 存货盘盈冲减管理费用；盘亏正常或计量差错计入管理费用，自然灾害计入营业外支出
- 存货可变现净值=估计售价−至完工成本−销售费用−相关税费；小规模纳税人进项税计入存货成本
- 固定资产盘盈走以前年度损益调整、盘亏走待处理财产损溢、报废毁损走固定资产清理
- 固定资产取得成本=达到预定可使用状态前的必要支出；日常维护费、预计报废清理费费用化
- 折旧规则：当月增下月提、当月减当月提；提足、单独计价土地、提前报废、持有待售不提
- 折旧方法：双倍余额递减法前期不考虑净残值、各年折旧额逐年减小；年数总和法折旧率逐年变小
- 内部研发：研究阶段全部费用化，开发阶段满足条件资本化，无法区分一律费用化
- 无形资产当月起摊销、处置当月停摊；寿命不确定不摊销但每年减值测试，残值一般零

**3. 投资性房地产（共12题：单选8 / 多选1 / 判断3）**
- 投资性房地产范围：已出租的土地使用权或建筑物、持有并准备增值后转让的土地使用权
- 只有土地使用权可"持有准备增值后转让"属投房，建筑物不算；自用→固资、待售商品房→存货
- 计量模式：成本模式或公允价值模式，同一企业只能选一种，不得同时采用
- 成本模式：计提折旧或摊销，有减值迹象需确认减值损失且不得转回
- 公允价值模式：不折旧、不摊销、不减值，公允价值变动计入公允价值变动损益
- 模式转换：成本模式可转公允价值模式，公允价值模式不得转回成本模式
- 自用或存货转公允模式投房，公允>账面的差额进其他综合收益，<的进公允价值变动损益
- 投房租金进其他业务收入、维护费进其他业务成本；改扩建期间记投房——在建且不折旧摊销

**4. 金融工具（共16题：单选6 / 多选5 / 判断5）**
- 金融资产三分类：摊余成本、FVOCI（变动进其他综合收益）、FVTPL（变动进当期损益）
- 摊余成本计量条件：业务模式为收取合同现金流，且现金流仅为本金和利息（SPPI）
- 债性FVOCI需双目标+SPPI；非交易性权益工具可指定为FVOCI且不可撤销
- 交易性金融资产交易费用计入当期损益；其余金融资产交易费用计入初始确认金额
- 其他权益工具投资公允价值变动计入其他综合收益，持有期间现金股利计入投资收益
- 业务模式变更才可重分类，持有意图改变、市场暂时消失、不同部门间转移均不算变更
- 金融资产转移：已转移几乎全部风险报酬（深度价外期权）→终止确认；重大价内期权→继续确认
- 金融负债是合同性支付义务（合同负债、预计负债、应交所得税不是）；自身权益工具不能作套期工具

**5. 长期股权投资与企业合并（共24题：单选9 / 多选4 / 判断11）**
- 长投核算范围：控制（子公司）、共同控制（合营）、重大影响（联营）
- 权益法：长投随被投资单位所有者权益总额变动调整；初始成本<份额的差额计入营业外收入
- 权益法超额亏损：确认损失以长投及其他长期权益减记至零为限
- 成本法：被投资单位盈亏分配均不调整长投，只有增减资、减值、处置才变；长投需计提减值
- 同一控制合并：按被合并方原账面价值入账，差额调整所有者权益，不产生新商誉
- 非同一控制合并：取得的资产负债按公允价值计量；合并成本>可辨认净资产公允价值份额为商誉
- 合并直接费用（审计、评估、法律费）：不论同一控制还是非同一控制，一律计入当期损益
- 共同控制要求控制组合唯一；两个以上组合能集体控制则不构成共同控制；合营安排属共同控制

**6. 收入（共26题：单选10 / 多选5 / 判断11）**
- 收入五步法：识别合同、识别单项履约义务、确定交易价格、分摊交易价格、履行时确认收入
- 收入确认时点：客户取得相关商品控制权时确认（既非发货也非收款）
- 时段履约义务三条件（满足其一）：边履约边受益、客户控制在建商品、不可替代用途且有权收款
- 履约进度指标分产出法（实际测量完工进度、已完工产品）与投入法（材料数量、人工工时）
- 时段履约：收入=合同交易价格×履约进度−以前期间已确认收入；进度不能合理确定不确认
- 交易价格四因素：可变对价、重大融资成分、非现金对价、应付客户对价
- 合同取得成本：仅"增量成本且预期能收回"才资本化（如佣金）；投标费、差旅费当期费用化
- 合同履约成本=与履行合同直接相关且预期能收回的成本；代收、待退款项作负债不计入交易价格

**7. 租赁（共9题：单选6 / 多选1 / 判断2）**
- 短期租赁指租赁期不超过12个月；短期租赁和低价值资产租赁可不确认使用权资产和租赁负债
- 使用权资产成本=租赁负债现值+预付租赁款−租赁激励+初始直接费用+拆卸复原成本现值
- 使用权资产后续计量一律采用成本模式，自租赁期开始日起计提折旧并按规定计提减值
- 租赁负债后续：确认利息增加负债、支付租赁付款额减少负债，变动生效时才重新计量
- 调减租赁负债以使用权资产账面价值调减至零为限，超出部分计入当期损益
- 租赁期开始日以取得使用权控制为准，可早于起租日或租金起付日
- 纳入租赁负债的可变租赁付款额仅限取决于指数或比率的部分，与销售收入挂钩的计入损益

**8. 职工薪酬与股份支付（共14题：单选6 / 多选4 / 判断4）**
- 职工薪酬四类：短期薪酬、离职后福利、辞退福利、其他长期职工福利；差旅费不属职工薪酬
- 股份支付：以现金结算（模拟股票、现金增值权）与以权益结算（限制性股票、股票期权）
- 权益结算股份支付按授予权益工具公允价值计量，授予日后不再调整
- 股份支付确认：市场条件不影响成本费用确认，只要满足非市场条件即确认成本费用
- 设定受益计划：服务成本与利息净额计入当期损益，重新计量（精算损益）计入其他综合收益
- 带薪缺勤：累积带薪缺勤在职工提供服务时确认，非累积在实际缺勤时确认
- 辞退福利、内退职工工资一律计入管理费用；职工生活困难补助按受益对象计入
- 现金结算改权益结算：修改日按权益工具公允价值计入资本公积，终止确认原负债，差额计入当期损益

**9. 借款费用、政府补助与所得税（共16题：单选5 / 多选3 / 判断8）**
- 借款费用含利息、折溢价摊销、辅助费用、外币借款汇兑差额；权益性融资费用不属借款费用
- 借款费用资本化资产门槛：需相当长时间（一年或一年以上）购建或生产
- 暂停资本化条件：非正常中断且连续超过3个月；资本化利息不超过当期实际发生利息
- 与收益相关政府补助：补偿以后期间费用的先计入递延收益，补偿已发生的直接计入当期损益
- 直接减征、免征、增加计税抵扣额、抵免税额，及政府以投资者身份投入资本，均不属政府补助
- 递延所得税资产和负债不折现；贷方发生额增加所得税费用，借方减少
- 其他权益工具投资相关的递延所得税计入其他综合收益，不计入所得税费用
- 总额法下与资产相关政府补助：固定资产按取得成本计提折旧，补助确认递延收益并摊销

**10. 或有事项、债务重组与非货币性资产交换（共14题：单选6 / 多选5 / 判断3）**
- 或有事项：由过去交易或事项形成，结果由未来事项发生或不发生决定；亏损合同属或有事项
- 或有负债可为潜在义务或现时义务；为现时义务还需"很可能流出+金额可靠计量"才确认预计负债
- 亏损合同有标的资产的先进行减值测试，预计亏损超过减值损失的部分再确认预计负债
- 非货币性资产：预付账款属非货币性；债权投资、应收票据、其他应收款属货币性
- 债务重组方式：以资产清偿、债务转为权益工具、修改其他条款及组合；出售债权不属债务重组
- 以资产清偿债务：债务人按"所清偿债务账面价值−转让资产账面价值"的差额计入当期损益
- 以存货换入资产按收入准则；非货币性资产交换按公允价值计量需具备商业实质且公允可靠计量
- 非货币性资产交换按账面价值计量时不确认损益

**11. 资产减值与持有待售（共15题：单选7 / 多选3 / 判断5）**
- 资产减值准则规范固定资产、无形资产、成本模式投房、商誉；应收账款减值适用金融工具准则
- 可收回金额=公允价值减处置费用净额与未来现金流量现值两者中的较高者
- 未来现金流量现值三要素：预计未来现金流量、使用寿命、折现率；折现率采用税前利率
- 每年年末必测减值：尚未达用途的无形资产、企业合并形成的商誉、使用寿命不确定的无形资产
- 减值分摊先抵减资产组中商誉的账面价值，再按比例分摊；资产组一经确定不得随意变更
- 资产减值损失一经确认，持有期间不得转回（商誉、长投、固定资产、成本模式投房、无形资产）
- 可转回的减值：存货、合同履约成本、合同资产、应收账款等流动资产类
- 持有待售停止计提折旧；划分前确认的减值不得转回，划分后确认的减值可在已确认金额内转回

**12. 财务报告与特殊列报事项（共25题：单选12 / 多选2 / 判断11）**
- 现金流量分类：投资活动=购建或处置长期资产、取得子公司；筹资活动=举债、吸收投资、分配股利
- 支付在建工程人员工资列投资活动；收到政府补助列经营活动；偿还租赁负债本息列筹资活动
- 非现金交易（承兑汇票背书、计提减值与摊销）不列示于现金流量表
- 基本每股收益仅考虑实际发行在外普通股；稀释每股收益才考虑潜在普通股
- 认股权证、股份期权行权价低于当期普通股平均市价时才具有稀释性
- 需重述比较期每股收益：股票股利/转增/拆并股、同一控制企业合并、追溯重述；非同一控制合并不需重述
- 日后调整事项调整资产负债表、利润表、所有者权益变动表，但不调整货币资金和现金流量表
- 日后宣告发放的现金股利不确认为表日负债，但应在附注中单独披露（属非调整事项）
