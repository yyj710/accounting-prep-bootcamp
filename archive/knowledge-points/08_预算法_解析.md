**1. 预算管理职权（共4题：单选0 / 多选0 / 判断4）**
- 中央预算报告主体：由国务院向全国人民代表大会作预算草案及执行情况报告
- 地方预算报告主体：由本级政府向本级人民代表大会作预算草案及执行情况报告
- 预算执行情况报告主体：由本级政府财政部门定期报告并提出政策建议
- 派出机关预算地位：不作为一级预算，其收支纳入本级预算

**2. 预算收支范围与四本预算（共5题：单选0 / 多选3 / 判断2）**
- 政府性基金预算收入：包括政府性基金各项目收入和转移性收入
- 一般公共预算支出经济分类：含工资福利支出、商品和服务支出、资本性支出、其他支出
- 地方一般公共预算组成：含本级各部门预算、税收返还预算、转移支付预算、直属单位预算
- 一般性转移支付范围：含均衡性转移支付及对革命老区等财力补助，基础设施转移支付属专项
- 外币折算：预算收支以人民币以外货币收纳和支付的，应当折合成人民币计算

**3. 预算编制与审批（共4题：单选0 / 多选1 / 判断3）**
- 预算支出标准：包括基本支出标准和项目支出标准两类
- 支出科目级次：分为类、款、项、目四级，项比款更细
- 支出编列级次：按功能分类编列到项，按经济性质分类基本支出编列到款
- 预算备案：下级预算汇总后报上一级政府备案，不是报上级人大常委会
- 预算批复时限：财政部门20日内批复各部门，各部门15日内向所属单位批复

**4. 部门与单位预算管理（共4题：单选0 / 多选1 / 判断3）**
- 部门预算收入构成：本级财政安排给本部门及其所属各单位的预算拨款收入和其他收入
- 部门单位预算收入编制内容：本级预算拨款收入、预算拨款结转和其他收入
- 部门预算办法制定：由本级政府财政部门依法作出规定，非各部门自定
- 事业单位预算管理：自求收支平衡、不得编列赤字，非财政补助收入大于支出较多的应上缴
- 派出机关预算地位：不作为一级预算，其收支纳入本级预算

**5. 预算执行与调整（共11题：单选0 / 多选4 / 判断7）**
- 资金拨付三原则：按预算、按规定的预算级次和程序、按进度拨付
- 预算执行主体：由本级政府组织执行、财政部门负责；转移支付下达拨付由财政部门办理
- 预算执行报送内容：含旬报/月报/季报、政府债务余额报告、国库库款报告及文字说明
- 不得下达收入指标：各级政府不得向预算收入征收部门和单位下达收入指标
- 超收收入与预算稳定调节基金：超收只能冲减赤字或补充基金，年终预算周转金亦可补充
- 超收短收计算范围：计算时不包括转移性收入和政府债务收入
- 预备费：动用方案由财政部门提出报本级政府决定，不足时县级以上政府可先安排支出
- 预算调整：经人民代表大会批准的预算，非经法定程序不得调整

**6. 国库集中收付（共4题：单选0 / 多选1 / 判断3）**
- 国库设立：县级以上各级预算必须设立，具备条件的乡、民族乡、镇也应当设立
- 国库集中收付制度：对政府全部收入和支出实行国库集中收付管理
- 退库款项用途：应直接退给申请单位或申请个人，并按国家规定用途使用
- 违法支配国库库款：含未经财政部门同意冻结动用、挪用库款、占压拨付资金、延解占压库款

**7. 决算与预算公开（共4题：单选1 / 多选0 / 判断3）**
- 决算报告：反映预算执行结果，为后续年度预算编制提供参考和依据
- 事业单位决算：指预算收支和结余的年度执行结果，非"年度总额"
- 单位预决算公开：应当公开基本支出和项目支出
- 部门预决算公开时限：批复后二十日内由各部门向社会公开

**8. 其他法规（共4题：单选1 / 多选0 / 判断3）**
- 借款费用资本化条件：须同时满足资产支出已发生、借款费用已发生、购建活动已开始
- 资本化停止时点：达到预定可使用状态时停止，竣工决算不影响停止时点
- 政府转贷债务：接受转贷并向下级转贷的政府应将转贷债务纳入本级预算管理
- 暂估固定资产：办理竣工决算后调整暂估价值，不调整原已计提的折旧额
- 政府采购计划备案：报本级人民政府财政部门备案，非报上级
