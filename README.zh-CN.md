**一句话**：2026 年秋天我同时在做三件事——第七届粤港澳会计知识竞赛（队长，11 月 28 日决赛）、初级财务会计学期末（目标**满绩**）、12 月 ACCA FR / FM 全球统考。时间不够分成三份复习，而这三条线用的是同一套会计知识，所以我把它们做成**一套能反复用的资料 + 四个双击就能打开的刷题网页**，靠和 AI 一句句对话磨出来。

## 这个仓库从哪来：竞赛备赛工程

第七届粤港澳会计知识竞赛的备赛资料仓库。我们从广东省 32 所学校、200 支队伍中进入前五，晋级 2026 年 11 月 28 日的决赛。我担任队长，负责备赛资料的生产和分发。

仓库里除了 13 个模块的复习文档，还保留了资料的制作过程：1,472 道题的结构化数据、24 个处理脚本、以及中间产物。发出来是因为这套方法对任何"有大量题目要短期内消化"的考试都适用。

## 做法

题目来自公开渠道的历届题库，两个来源（1,000 题和 483 题）合并去重后共 1,472 道。

备考分几条线推进：

1. **定重点**。统计题目分布后发现企业会计准则和政府会计准则占了一半以上，复习策略从"全看"改成"重点突破"。
2. **补解析**。官方答案只有一行，看不懂。我让 Claude Code 逐题生成解析和记忆口诀，同时自己刷完初级会计实务 700 题打基础。
3. **排顺序**。给每道题打上知识点标签，同类聚合后按出现频次排序，高频考点先学。
4. **改结构**。部分知识点光看题还是不懂，就把文档改成"先集中讲解（口诀 + 生活化例子），再做对应例题"的形式，题库变成了教材。
5. **分阶段**。考前把内容拆成两套：需要理解的平时攻克，纯记忆的留到考前突击，另做一页纸的高频规则汇总。长投、租赁这类难且低频的考点直接放弃。
6. **发全队**。所有文档导出 Word 版同步给队友，统一口径复习。

## 文档结构

每个模块的文档分五部分：

1. 知识框架总览
2. 核心考点精讲（定义 + 对比表格 + 记忆口诀）
3. 易错陷阱 TOP 10（错误说法 vs 正确说法）
4. 要点速查表（数字 / 比例 / 期限）
5. 全部题目练习（附答案和出处）

## 仓库结构

- `markdown/` — 13 份模块文档 + 总复习，Markdown 源文件
- `word/` — 发给队友的 Word 版，含考前突击速成手册和"先讲解后刷题"样板
- `archive/` — 制作过程存档
  - `scripts/` — 24 个 Python 脚本：题目解析（parse）、归类拼装（build）、逐字校验（validate）、Markdown 转 Word（md2docx）
  - `data/` — 1,472 题的结构化 JSON（题号 / 标签 / 题型 / 题干 / 答案）
  - `knowledge-points/`、`review-cards/`、`lectures/` — 知识点清单、模块复习卡、企业会计准则 12 讲讲解稿
  - `master/`、`crash/`、`sample/` — 全模块汇总、速成手册、讲解样板的 Markdown 源

质量校验：按知识点重排后与原题库逐字比对零差异（validate.py 独立校验）；每道题恰好归属一个模块；原文件中错放在"单选题"章节的判断题已按标签前缀校正。细节见 [archive/README.md](./archive/README.md)。
