## 这个故事

本届是第七届比赛，官方不给题库。我的解法是一条流水线：

```
找到第四届竞赛题库（1000题 + 483题两个来源）
  → 合并去重成 1472 题
  → 做成 Anki 卡片自己刷
  → 整理成 xlsx 结构化
  → 用 Claude + WorkBuddy 批量生成 13 份带解析的学习文档
  → 导出 Word 版发给全队复习
```

一个人备赛是学习，**把全队武装起来才是队长的工作**。

## 每份文档的 5 段结构（`markdown/`）

1. **知识框架总览** — 思维导图式全貌
2. **核心考点精讲** — 定义 + 对比表格 + 记忆口诀
3. **易错陷阱 TOP 10** — "错误说法 vs 正确说法"对比
4. **核心要点速查表** — 关键数字/比例/期限，考前速刷
5. **全部题目练习** — 附答案和出处
